# AI 禁词库（book-knowledge-card）

> 本库记录知识卡片创作中**应谨慎使用的词汇与表达**。核心原则：写给普通人看，用大白话，不断句、不缩写、不堆书面词、不喊营销口号。
> ⚠️ **本库不是一刀切硬禁，分两级**（见「零、使用层级」）：🔴 硬禁级无条件删；🟡 尽量少用级在知识卡片里读着顺就可用，别看到就删。

## 〇、根本铁律：内容以书为准，严禁自造比喻（2026-08-17 新增 · 最高优先级）

> 这条是做知识卡片的**根**，不是某条具体禁词。之前反复踩坑（防疫系统 / 食果机制 / 投资账单 / 公示牌 / 军备竞赛 / 基因账 / 算账 / 本钱 / 行为库 / 一副看清自己的眼镜 / 写进偏好 / 环境跑得太快机制没跟上 / 同一套底层逻辑）全是因为没守住它：**AI 自己编浮夸比喻，把作者写简单的事越比喻越让人发懵**。
>
> ⚠️ **关键校准（2026-08-17 用户二次澄清）：禁的是"脱离物体真实使用场景的浮夸比喻"，不是禁词本身。**
> - 🔴 **禁**：把 A 领域/物体的词硬套到 B 领域去打比方，且这个比方脱离了该词本来的使用场景。例如用"账单 / 会计 / 算账"形容基因、用"跑得太快没跟上"形容机制、"同一套底层逻辑"形容不同事物——这些才是踩坑的"浮夸比喻"。
> - 🟢 **不禁（正常表达，别硬删）**：① **正常用词**——`止损`（"要及时止损"是正常说法）、`投资`、`收益` 在各自本义场景里正常用，没问题；② **真实物体的真实场景字面描述**——"兔子跑得太快""人怕蛇"是字面陈述事实，不是比喻，没问题。
> - **判断口诀**：这个词/句是不是在把"不属于此物场景的东西"硬拉来打比方？是 → 浮夸比喻 → 删；否 → 正常用词或字面描述 → 留。

1. **内容以书为准。** 卡片讲的必须是书里真正讲的内容，按书里的方式去讲（书的框架、书的模块、书的论证顺序）。书里没有的"洞见""升华""我的理解"，不准塞进卡片。
2. **直白陈述事实，不自己打比方。** 把机制、研究、结论用大白话直接说出来。宁可多写一句解释，也不要用一个比喻去"帮助理解"——你以为比喻好懂，其实两个比喻一通篇，读者更懵。
3. **书里原有的比喻可以留**（如巴斯书里的"烟雾报警器""白板说""心理机制=信息加工程序"），那是书的表达方式，不是你编的。但**你自己新造的浮夸比喻一律禁止**——拿不准是不是书里的，就当自己编的，删。（注意：正常用词如"止损"、真实物体的字面描述如"兔子跑得快"不算比喻，不在禁止范围。）
4. **翻译拗口 / 表述别扭的地方可以改写**，但改写是"换成更顺的大白话"，不是"换成更花的比喻"。
5. **自检硬闸门**：写完逐段问"这句是书里的内容，还是我自己编的修辞？" 任何把 A 说成 B 的句式（A 是 X / A 像 X / A 是 X 的 Y / A 写进了 B / A 跑得太快 B 没跟上 / A 和 B 是同一套），只要 A、B 不是书里的原意，就是自造比喻，删。

🔴 硬禁词（浮夸比喻典型代表，命中即删，不分语境）：`一副眼镜|底图|本钱|行为库|写进偏好|写进基因|跑得太快|没跟上时代|没跟上机制|同一套底层逻辑|基因收益|基因账|算账|凑出来|拼凑|水晶球|铠甲|防线|发芽|长出来|长出|养成|磨合`。

> 📌 **`止损` 已从硬禁词移除**：它是正常用词（"要及时止损"），只有被硬套去比喻非财务事物（如"基因止损""进化止损"）才算浮夸比喻。这类误用靠上面的"判断口诀"人工识别，不再用整词硬禁——否则会误伤正常表达。

## 零、使用层级（重要校准 · 2026-08-16）

- **🔴 硬禁（知识卡片也绝不许出现）**：① 元话语（书里/原话/点题/点破/点明/原文写/书中提到…）② 卷章指称（第X章/卷一/车里的男人）③ 中英混杂（greed/peer/ROI/leverage）④ 生造拗口短语（第七节，书里无原话、读着绕）⑤ 抽象拟人"长出来/长出"（非实体事物）⑥ 吊胃口营销狠话（最狠的判断/藏在最后/戳破真相/原来如此/看完你就懂了）⑦ **划线/热评陈列（热门划线墙/很多人划下的句子/被划最多/划线人数/读者评论）——用户划线是输入素材，必须消化后重述，禁止原样贴出**。这几类无论什么场景都删。
- **🟡 尽量少用、但知识卡片里可用（别硬删）**：书面语（迭代/赋予/匮乏…按读着顺不选）、AI 虚词（底层逻辑/方法论/赛道/痛点/认知升级/底层框架…）、部分金句式开头（一个被低估的真相/这才是/真正的高手）。判断标准：读者读着顺、书里本来就有这词、大白话优先；**短视频口播里更克制，知识卡片可放宽**。

> 下方第一、三、四节的很多词属于「🟡 可用」级，不是禁用。写卡片时不要看到就删——先看语境。

## 五、断句 / 碎句（必须改连贯）

以下不是词，而是**句式病**，必须改：

- ❌ "标签：词"（如"财富的来源：分工"） → ✅ "财富来源于社会分工"。
- ❌ 超短句堆叠、让读者补主语 → ✅ 每句补全主语和谓语。
- ❌ "虽然今天没有老虎了，但是。还有房贷…" → ✅ "虽然今天没有老虎了，但是还有房贷、社交媒体等等各种压力…"
- ❌ "所以。人们天生就会在乎…" → ✅ "所以人们天生就会在乎…"

## 六、使用方式

每次生成/修改卡片文案后，用 `grep` 或肉眼扫一遍本表。命中任何一项，立刻替换为右侧表达。不确定某个词是否"太书面"时，默认：用你妈妈也能看懂的词。

## 七、AI 自造生硬拗口短语（最该警惕 · 本轮头号翻车点）

> 这是整套卡片反复翻车的根：**AI 为了求"精炼/有文采"，自己造出书里没有、读起来拗口、普通人看不懂的短语**。用户原话："拗口的你自己瞎编的那种，读都读不懂，太拗口了。"——宁可啰嗦大白话，绝不用伪精炼。

| 禁用（AI 自造，书里无原话） | 改为（大白话/书里原意） |
|------|------|
| 把"人数"堆起来 | 让人类的数量有了爆发式的发展 |
| 宇宙里并没有它们 | 实际上并不真实存在 |
| 别把"人类很厉害"自动当成"我一定过得好" | 直接说"社会进步不代表我个人过得好"，或展开二八法则论述 |
| 给了合作的能力（缺主语） | 让人类拥有了合作的能力 |
| 又给了探索未知的勇气（缺主语） | 又给了人类探索未知的勇气 |
| 人口的"总账" / 演化只数物种总数（AI 自造比喻） | 直接用书里原话，不造会计/数学比喻 |
| 长出来 / 长出（抽象比喻滥用） | **凡是制度、秩序、规则、体系、市场、习惯、文化、关系这类非实体的东西，一律不用"长出来/长出"**。制度"形成"、秩序"磨合出来"、规则"定出来"、市场"自己运转"、习惯"养成"。只有字面意义上的植物/庄稼"长出来"才可用，但知识卡片基本不涉及具体植物，故卡片正文里"长出来"应视为默认禁用。 |
| 防疫系统 / 食果机制 / 投资账单 / 公示牌 / 被 X 逼大 / 军备竞赛 / 基因账算得长远 / 先算账的（AI 自造具象化比喻） | 这些全是 AI 为了"显得有文采"自造的比喻——书里没有原话，普通人读着磕，违反"小白能读懂"基调。**卡片正文里遇到机制/关系/制度/演化/竞争等抽象对象，全部用大白话或书里原话，禁止造任何"拟物化的形象比喻"**。要形容就直说："对带菌、腐败物质的反感"（不写"防疫系统"）、"采集者对成熟果实的偏好"（不写"食果机制"）、"公开双方配偶关系"（不写"公示牌"）、"智力进化的主要压力是社会关系"（不写"被社会竞争逼大"）、"双方各自在算投入和回报"（不写"先算账的"）。 |
| 底层不满足上层就塌（自造因果） | 直接说"越往下越基础"，不编"塌/崩"的伪逻辑链 |
| 先图活命、再图面子、最后图自己（笼统套话） | 用具体例子：穷人先顾生理、富人不差钱才做公益，不编口号式排比 |

**自判标准**：写完后逐句问——"这句话书里有原话吗？没有的话，它读着顺吗、我妈能秒懂吗？"只要有一丝"绕/拗/像在掉书袋"，立刻换成大白话。确定性低于 100% 的短语，默认不用。

| 禁用（AI 造词绕弯，书里无原话） | 改为（大白话） |
|------|------|
| 把高收入绑在"你必须一直在场"上 | 高收入不会永远存在，一旦收入断了，消费就大过支出（直接说结果，不造"牌桌/在场"比喻） |
| 牌桌上 / 一直站在牌桌上 | 不写这类比喻，直接说"停下来收入就没了" |
| 追高杀跌 | 不写股市黑话，改成"市场大跌时跟着慌、高位时跟着冲"或干脆不提 |
| 把钱"锁死" / 现金流"锁死" | 钱被开销占满、每个月入不敷出 |
| 被生活方式"绑架" | 被越来越高的开销套住，不敢停下 |

## 八、因果 / 逻辑必须顺（高频翻车点）

- 论述书里的机制时，**原因要归到书里讲的机制本身**，不能把现代现象倒因为果。
  - ❌ "今天超市里全是高糖高脂食品，所以很多人控制不住自己"（把"今天有食品"当成因）
  - ✅ "远古时糖和脂肪极度稀缺，见到就多吃是保命本能 → 所以今天很多人控制不住、总想吃高糖高脂的东西"（因在远古本能）
- 每个"所以"前后的逻辑要真能接住，不跳步、不偷换概念。
- 新概念第一次出现，先在上一句铺垫"它指的是…"，不凭空冒出（见 SKILL 语言铁律「板块级承上启下」）。

## 九、中英混杂 / 夹生英文（禁用）

中文卡片里**不许夹英文词**，专有名词也优先给中文。夹英文是最容易被骂的"AI 腔"之一。

| 禁用 | 替换为 |
|------|--------|
| greed | 贪婪 |
| peer 压力 / peer pressure | 身边人的比较 / 同龄人的压力 |
| ROI | 收益（直接说"这笔投资划算不划算"） |
| leverage | 杠杆（书里若有"杠杆"是中文，直接用中文；不写英文） |
| 硬科学 / 软技能 | 仅在**引用书里原话**时带双引号出现一处（如"财务成功是一种软技能"），且不可当框架反复提、不可造"硬知识"变体 |

**原则**：写完扫一遍，凡中文句子里混了英文单词，一律翻成中文；书里确有英文概念（如 leverage）也用中文译名呈现。

## 十、自造术语替代书里已有定义（禁用 · 本轮高频翻车）

书里**已经有明确术语/概念**时，AI 不许另造一个近义词去"替换"它——既多余、又往往不准，还显得在掉书袋。

| 禁用（AI 自造） | 改为（用书里本身的定义词） |
|------|------|
| 真正的富裕 | 财富自由（书里明确定义就是"财富自由 = 时间自由"，不要造"真正的富裕"） |
| 真正的满足 / 真正的富有 | 用书里原词（知足 / 财富自由），不另造 |
| 把钱"当地位" / 把消费当地位 | 直接说"想让别人羡慕自己" |

**自判标准**：写到某个关键词时，先问"书里是不是已经有一个现成词讲这个？"有就直接用书的词，不要自己换个近义词显得"高级"。

## 十一、前言不搭后语的断裂罗列（句式病 · 本轮高频翻车）

同一句话里前半讲 A、突然用"因为/还能/于是"跳到毫不相干的 B，读着前言不搭后语、信息堆砌。必须写成**一句完整连贯的人话**，不中途换行主题、不把两个不挨着的结论用"因为…还能…"硬串。

- ❌ "真正的富裕，是别人看不出你多有钱——因为钱还在账户里，还能换成选择权和自由。"（前半说"看不出有钱"，突然跳"因为…还能换成选择权"，逻辑断裂）
- ✅ "财富自由，不是你买了什么让人看见，而是你没花掉的钱还在手里。别人看不出你多有钱，那才是真的富。"（两句都围绕"没花掉的钱=自由"，不跳主题）
- ❌ "高收入如果绑在'你必须一直在场'上，停下来就没了；高消费又把现金流锁死，让人更不敢停。"（造比喻 + 堆术语）
- ✅ "但高收入不会永远存在。一旦收入断了，消费就会大过支出。再碰上失业或者生病这种意外，那收入就更扛不住了。"（短句直推，不绕）

**自判标准**：写完一句话，读一遍看"中间有没有突然拐到另一个不相干的点？"有就拆成两句各说各的，或重写成同一逻辑链。

## 十二、同一事实两处重复 / 滥竽充数（结构病 · 本轮高频翻车）

核心内容里讲透的点，核心价值/其他节**不要再讲一遍**——读者不傻，重复只会显得凑数。

- ❌ 核心内容第⑤点"给计划留足容错空间"，核心价值第④点又写"给计划留足容错空间"（完全重复）
- ✅ 容错空间只在核心内容讲一次；核心价值只讲"读完能带走哪几个判断"，不回头复述已展开的论证

**对应纪律**：SKILL.md 语言铁律已有「信息一位置：同一事实只在一处讲透，不各处重复」。本条是卡片级的具体化——尤其"核心内容"和"核心价值"两块，必须分工：核心内容负责**展开论证**，核心价值负责**收束判断**，不重叠。

## 十三、抽象空话 / 标签化缩句（禁用 · 本轮高频翻车）

总结节、价值节里最容易出现"看起来有道理、其实什么都没说"的抽象句和标签堆。必须写成**带例子或具体机制的完整判断句**。

| 禁用（空话/标签） | 改为（完整判断 + 例子） |
|------|------|
| 行为比知识管用 | "管钱难在心态不在智商：懂了一堆道理，真碰到大跌、被别人比下去、又贪又怕，照样做傻事。"（补全机制） |
| 钱是为了自由 | "钱最大的作用不是买更多东西，而是让你有选择权——被动收入能覆盖开支，你就不必为了生存出卖时间。"（落地） |
| 知足、存钱、留容错 | 不堆三个词，各自展开一句：知足=不跟别人比排场；存钱=为存钱本身而存；留容错=留安全边际扛意外 |
| 他最该带走的 3 点 / 带走 | 直接说"几个最值得记住的判断"，每点一句完整话，不写"带走" |

**自判标准**：每张价值卡/总结句，问自己"这句话删掉例子后还剩什么信息？"如果只剩一个词或一句正确的废话，就重写。

## 十四、论文式过渡词（禁用）

卡片是给活人讲的，不是写论文。以下过渡表达一律删，同主题内直接一句人话说完，跨主题只用"所以/但是/也就是说/换个角度看"。

| 禁用 | 说明 |
|------|------|
| 这正好接上… / 正好接上 | 不要写"这正好接上财富的看不见"，直接接着讲 |
| 由此引出… | 删 |
| 反观… | 删，用"但/换个角度看" |
| 落脚到… | 删 |
| 顺带一提 / 值得一提的是 | 删 |
| 换言之（句首口头禅） | 可用"换句话说就是"，但不放句首当套话 |

## 十五、AI 造词造句的根因与纠错规律（类别级 · 比单词重要）

> 本节是给"为什么总被纠 AI 腔"做的根因总结。用户原话："你不要一个词一个词改，你经常一大段话驴唇不对马嘴，犯的错是同一类。" 所以：**被纠正一次 = 发现一条类别规则，必须全篇（含同类卡）复扫这一类，不是改那个 token。**

### 根因（我为什么总写成这样）
我在用"AI 总结腔"写作：不假思索地"概括"，而不是"把事讲清楚"。具体表现为把动作压成抽象名词、给抽象事物套错位的比喻、用错语态把"被拿走"写成"主动让出"、在内容外裹一层元话语、用废话前缀先评论概念再讲内容。

### 六类反复犯的错（每次纠错基本落在这六类之一）

| 类别 | 特征 | 例子（我写过的） |
|------|------|------|
| ① 抽象名词化 | 把"谁比谁、谁留下"压成一个看不见的抽象标签 | 发现工具 / 试错能力 / 发现机制 / 底层逻辑 / 支点 |
| ② 喻体错位 | 把 A 比作不该比的 B（关系/庄稼/物理/工具喻体用于制度/权力） | 合不来（人际→制度）/ 长出来（庄稼→制度）/ 撞到一起（物理→制度）/ 缰绳（工具→权力） |
| ③ 语态错位·施受颠倒 | 把"被拿走"写成"主动给"，歪曲原意（驴唇不对马嘴）；或把"剥夺"写成轻飘飘的"收走/收光" | 让出自由 / 把自由交给国家 / 经济自由一旦让光 / 自由被一点点收走 |
| ④ 元话语包裹 | 把注意力引向"书"这个客体，而不是内容 | 书里说 / 被反复引用的话才成立 / 前面那句 |
| ⑤ 废话前缀 | 先评论词或概念，再讲内容，绕一圈；为了凑格式拆出多个并列问题；或画蛇添足地给作者观点加"反复区分""特意替…说好话"等修饰 | 竞争不是坏词 / 默认设定 / 底层逻辑 / 这正是一个被低估的真相 / 核心问题可以简化成两个 / 哈耶克反复区分 / 特意替"竞争"说好话 |
| ⑥ 自造拗口短语 | 书里没有、读着绕、信息为零的总结句；或词性不一致的硬凑并列 | 把谁更对试出来的工具 / 用中央计划安排一切这件事 / 把A交给B，和C、和D根本不能共存 |

### 我的坏 vs 用户的好的差异（逐对对照，记住这个"手感"）

| 我写的（抽象/错位/绕） | 用户改的（直陈/字面/动词） | 改了什么 |
|------|------|------|
| 竞争是发现工具 | 谁更能满足需求、效率更高，谁就留下；谁不行，就被淘汰 | 拆成"谁做什么、结果怎样"，不给抽象标签 |
| 优胜劣汰的发现机制 | 市场用公平规则筛选——更好的留下，更差的退出 | 同上 |
| 试错能力 | 计划者没法让事实自己说话 | 动词句，不造名词 |
| 合不来 | 根本不能共存 | 直陈，不用人际关系比喻 |
| 长出来（制度/秩序） | 从实践中磨出来 / 慢慢形成 | 字面动词，不拟人 |
| 撞到一起 | 要同时搞 | 直陈，不用物理碰撞比喻 |
| 让出自由 / 把自由交给国家 | 自由被一点点剥夺 | 被动，施受归位；用"剥夺"不用轻飘飘的"收走" |
| 自由被一点点收走 | 自由却被剥夺了 | 加了转折"却"，动词用"剥夺"，语义和语气都对 |

| 谁都得守 | 谁都得遵守 | 口语省略在书面卡里显得草率，补全动词 |
| 从实践中磨出来的 | 从实践中形成的 | "磨"是口语且多义，"形成"更直接 |
| 哈耶克特意替"竞争"说好话 | 哈耶克认为，竞争不是… | 别替作者"说好话"，直接陈述作者观点 |
| 哈耶克反复区分 | （删） | 观点是哈耶克自己的，不需要"反复区分"这种画蛇添足的修饰 |
| 竞争不是坏词，是… | 哈耶克替"竞争"说好话：… | 删废话前缀，直接讲 |

### 新增第七条规律（模板惯性，最容易被忽略）
用户反复骂"我照搬上一本书的结构"——这不是词的问题，是**格式惯性**：上一本书写"两个核心问题"，下一本也硬拆两个；上一本先讲"旧认知"，下一本不管核心逻辑是否一样也照搬。

**规则**：
- 每本书的"核心问题"必须从**这本书的核心论点**自己长出来，不能为了套模板硬拆成"两个""三个"。
- 《通往奴役之路》的核心论点是"计划经济不可行，因为它导致权力过度集中、剥夺自由"，所以只问一个核心问题就够了。
- 换书先问：这本书真正想回答的**一句话**是什么？然后用那一句话当核心问题，不要先数"几个"。

### 一句话总规律（写完每句自问四个"有没有"）
1. 有没有一个我**看不见、画不出**的抽象名词？（→拆成谁做什么、结果怎样）
2. 有没有把 A 比作**不该比的 B**？（→换直陈或同域比喻）
3. 有没有把"**被拿走**"写成了"主动给"？（→改被动，施受归位）
4. 有没有在内容外面**多裹了一层"书里说"**？（→删元话语，直接讲或用"作者写/作者说"归因）

任一命中就改。读者读着顺、书里本来就有这词、大白话优先；短视频口播更克制，知识卡片放宽（见零级）。

### 流程纪律（防复发的关键，必须执行）
用户每纠正一处，**不要只改那个词**：
1. 判断它属于上面六类里的哪一类；
2. 全篇（含本卡所有 section、以及同类书的其他卡）复扫这一类；
3. 把同病句子一起改掉，再 present。
被纠正 = 发现一条规则，不是修一个 token。

## 二十、原作者核查：所有比喻/术语必须有原文出处（流程级 · 2026-08-17）

## 〇-2、禁"完整但不人话"——tdef/cone 无主语 + prose 因果链糊成一句（2026-08-18 用户骂"什么叫投入越多越挑剔越少越广撒网？""一个主语都没有吗？""什么叫父母想平分子女想独占？"后立）

**原则**：D11 把"严谨科学语言"误升级成"机械工整语言"，导致"完整但不像活人说话"。两类典型病：
- 速览卡 tdef / 概念卡 cone 精简到没主语，读者不知道"谁、做什么、平分什么、独占什么"；
- prose 段落里"现象+推理+结论"糊成一长串不断句，读着像机器报词条。

### ① tdef / cone 写无主语精简句（"X 是 Y" / "A → B" / "X 多 Y 多"）

禁：
- "投入越多越挑剔，越少越广撒网"（无主语）→ ✅"雌孔雀投入大，所以它必须挑；雄孔雀投入小，所以它可以广撒网"
- "愿帮谁，看基因上有多亲"（主语暗）→ ✅"你愿不愿意帮一个人，看他跟你基因上有多亲"
- "父母想平分，子女想独占"（主语宾语都简省）→ ✅"父母想把资源均分给所有子女，子女想独占全部资源"
- "陌生人合作靠互换帮助"（无主语）→ ✅"互惠利他：你帮我一次，我帮你一次，这次欠的账下次还"
- "雄孔雀的尾羽不是为活下来，是为被选中"（"被"字主语暗）→ ✅"雄孔雀的大尾羽不是为了活命，是为了被雌孔雀选中"
- "宁可误报，不能漏报"（主语暗；用"主语 + 报警器"显化更稳）→ ✅"情绪报警器宁可误报，不能漏报"

**判断口诀**：写完每个 tdef / cone 自问"这句话去掉了谁？谁在做这件事？"——找不到主语就重写。

### ② prose 因果链糊成一句不断开

禁（现象+推理+结论糊一段）：
- "烟感不等确认才响，宁可误报也不能漏报，漏报代价是烧房子，误报只是白忙活——宁可错杀不要放过"
- "焦虑是宁误勿漏的报警器，把无关的事当有关，把无害的当危险"

要（用"因为…所以…这就是…"分步骤断开）：
- "烟雾报警器不是等着火了以后才响，而是在冒烟的时候就响了。**因为**漏报的代价是烧掉房子，误报的代价只是白忙活一场。**所以**，宁可误报，也不能漏报。**这就是**：宁可错杀，不要放过。"

**判断口诀**：prose 段落里"先点现象，再说代价，再说推理，最后给结论"——四步用连接词断开，每步独立一句。

### ③ tcard 标题未居中

- 视觉上别扭（左右不对齐看着不舒服）也算"不人话"的一种；
- CSS `.tcard .thead` 必须 `justify-content: center`（不止 ctitle，连同 svg 一起居中呈现）。

### ④ "X，是 Y"式缩句要拆开

- "更多基因传给后代，胜者的特征在种群中越来越普遍"（"胜者的特征"是哪个？"越来越普遍"到底是什么趋势？没主体）→ ✅"胜出那方的特征在下一代身上越来越多"（让"特征"指"在同性竞争中胜出的特征"，更明确）
- "情绪是过度敏感的报警系统"（"过度敏感"形容的是谁的状态？暗）→ ✅"情绪系统被设计成过度敏感"或"情绪是按'宁误勿漏'原则设计的报警系统"

### ⑤ 把"具体的谁"压成"普遍的趋势/特征/机制"

- "机制让人做出自私行为"（哪个机制？谁的自私？）→ ✅"亲代投资机制让人在择偶时更挑剔，是因为它要保护自己那一份不可逆的投入"

- 主题 = 看问题框架；反常识 = "兵法不只用于军事"；方法 = 道天地将法 = 价值共识 / 趋势时机 / 资源环境 / 团队能力 / 组织方法

### ② s5 每条必须有四件套（机制 → 主题 → 反常识 → 方法）

写 s5 前**先**列每条的四件套，再写 prose。少一件就改。

| 件 | 写什么 | 失败模式 |
|---|---|---|
| ① 机制 | 这条延伸来自书的哪个/哪些机制 | 没机制 = 跑题，没关联书 |
| ② 主题 | 延伸出书外的哪个具体主题（人性/钱/进步/决策/消费/学习/工作/关系/健康/自由...） | 主题是"机制" = 停在机制内自说自话 |
| ③ 反常识判断 | 一句话站队，让人眼前一亮（"不是...而是..."结构） | 没反常识 = 老生常谈 |
| ④ 具体方法 | 看完能照着做的步骤/操作/对照 | 没方法 = "我懂了"但不知道怎么做 |

### ③ s5 局限段不能空话免责

❌ **空话反例**：
- "它解释的是群体层面的平均趋势，不擅长预测下一步，作为参考就好"（说了等于没说）
- "它只能作为参考，每个人情况不同"（标配免责结尾）

✅ **正确反例**——三件套：
- ① 它**能**做什么：擅长解释"为什么这样" / 解释行为来历 / 看清群体倾向
- ② 它**不能**做什么：不擅长预测具体下一步 / 不能给个人行为指南 / 不能解释个体差异的具体原因
- ③ 它**适合怎么用**：当看清自己和别人的参考书来用，不要当行为指南照搬

### ④ 写 s5 必跑的判断口诀

- [ ] 三条是不是同一句话的三种说法？**是 → 改**
- [ ] 每条有没有「机制 → 书外主题 → 反常识判断 → 具体方法」四件套？**少一件 → 改**
- [ ] 读者读完能不能拿去解决一个具体问题？**答不上来 → 改**
- [ ] 局限段是具体说清"能/不能/怎么用"三件事，还是只说"参考就好"这种空话？**空话 → 改**
- [ ] 每条是不是关联到书里具体的机制（亲代投资/性选择/互惠利他/广义适合度/亲子冲突/烟雾报警器）？**没关联 → 改**
