# 逻辑核查闸门 · 复盘与强制纪律

> **本文件是 discipline，不是建议。** 进化心理学卡片前后改了 15+ 轮，用户每次抓一类新问题（自创样式 / 口水造词 / 断句无因果 / 图文字重复 / 主线写成研究问题…），我就在 skill 里加一条 RC/D 或禁词。但规则越加越长，**同样的病还在犯**——根因不是"没有规则"，是"规则没在交付前被强制逐节执行、也没把结果亮出来"。本文件做两件事：①把 15+ 轮的问题按类复盘，看清复发模式；②立一道**交付前必须逐节跑、必须把 PASS/FAIL 表贴出来**的闸门。任何一节 FAIL，先改再 present，绝不许"先交付再说"。

---

## 一、复盘：15+ 轮踩坑的 7 类复发问题

> 规律一句话：**被纠正一次 = 发现一条类别规则，全篇复扫这一类**（见 ai-banned-words.md 十五节流程纪律）。但光"复扫"不够，要在**生成时就拦**，不是写完等骂。

### 类别 1 · 自创样式、不守标杆
- **表现**：s3 自造 `.roadmap / rm-row / rm-num / rm-q / rm-a / rm-role` 一整套（应为纳瓦尔 `.points`）；s4 顶部理论卡用 2 列（应为 3 列）；s3 写"论断 N：机制的本质"标签框、单列"作用：/为什么："。
- **根因**：动笔前没打开标杆源码对照，凭记忆"觉得这样也行"。
- **预防（对应闸门步 5）**：做卡前先打开标杆（国富论/纳瓦尔宝典/人类简史）看真实 class 与布局；s3 一律 `.points`，s4 顶部一律 3 列，结构件只用 levels/mini-vs/tags/example/cline，不自造。

### 类别 2 · AI 造词 / 口水 / 装深刻
- **表现**："代价是账本必须算清 / 你帮我下次我帮你 / 有人混水摸鱼整张网就崩 / 识别欺骗者让你远离只蹭不付出的人 / 在心里盘算 / 表征"；"性别差异的总开关 / 投入不对称→挑剔不对称 / 决定性变量 / 底层密码"。
- **根因**：想"显得有文采/深刻"，用拟人比喻和压缩伪术语替代大白话。
- **预防（对应闸门步 3）**：每句写前问"严谨科学语言还是 AI 腔"；账本/算账/总开关/底层逻辑/表征(未解释)/"是…的信号"一律删；学术 jargon 首次出现给大白话（表征→评估，亲缘系数→基因相同比例）。

### 类别 3 · 断句、缺连接词、无因果（最高频）
- **表现**："往那个方向推""越选越夸张""越传越广""越变越大"等模糊句不交代因果；一句话前半讲 A 突然跳 B（如"被多人选中本身就是一种认可"孤零零）；5 点列表"突然冒出来"无过渡；"是…的信号"拗口。
- **根因**：追求"精炼/对称"，把因果链压成标签或模糊词；连接词（所以/但是/因为/而）缺失，读者"字字懂、连不起来"。
- **预防（对应闸门步 1、2、4）**：① 每段"因→果"逐环讲透，凡"留下来了/越X越Y/往那个方向"都换成完整因果（"让拥有该特征的个体繁殖更成功，从而该特征在种群中越来越普遍"）；② 每句有主谓宾+承接词，破折号<15，不句号硬断连贯句；③ 凡编号列表，前一句说清"由 X 推出 N 个现象 / 维持 X 需要 N 项能力"，每点"因为…所以…"完整因果。

### 类别 4 · 视觉与文字过度重复
- **表现**：SVG 图里写了内容，下方文字又写一遍（如"误报vs漏报代价"图已示、文字再写）；速览卡堆具体例子（"孔雀尾巴不是为了活下来"）。
- **根因**：图与文职责没分开，同一信息两处呈现。
- **预防（对应闸门步 6）**：视觉在前、文字在后、层层递进；图已表达的内容文字删；速览卡只放机制名+一句话定义，不堆例子（例子放 concept 卡）。

### 类别 5 · 结构错置（主线=研究问题、prose=研究过程）
- **表现**：s3 写成"研究几类问题 / 怎么得出的"；s4 prose 写"巴斯跨 37 个文化测了一万多人""Hamilton 的答案"；顶部卡带 Trivers/Darwin/Hamilton 学者名、带"书中核心比喻"元标签。
- **根因**：把"怎么研究出来的"当成"结论"呈现，读者要的是"为什么是这样"。
- **预防（对应闸门步 7）**：s3 = 作者核心论断清单（一句话判断，非研究问题列表）；s4 prose 讲"为什么"，不写跨文化测几人/学者名/研究设计；顶部卡标题结论型、不带学者名（DNA 这类常识除外）、不带元标签。

### 类别 6 · 纯文字墙 vs 纯条目两个极端
- **表现**：一版 7 段纯 prose 墙；另一版纯条目堆叠无叙述（ 早期）。
- **根因**：只会一端，不会"连贯 prose + 结构件拎重点"叠加。
- **预防（对应闸门步 5）**：纳瓦尔式——每张概念卡 = 编号+红名+灰cone+连贯 prose+结构件（levels/mini-vs/tags/example/cline 选 1-3）。人类简史教"连着说"，纳瓦尔教"拎重点"，两者叠加。

### 类别 7 · 编造数据 / 编造内容（最该零容忍）
- **表现**：s5 写"这 6 个框架能解释你日常生活里 **80%** 的心理现象"——书里从没说过 80%，是我自己编的。
- **根因**：想让结论"更有力"，随手编数字/编例子，违反 内容以书为准。
- **预防（对应闸门步 3 + 根因 /D1）**：任何数字、例子、统计必须来自书（微信读书/原书）；拿不准的不编，要么删要么标"这是延伸理解"。自检三问："书里有这句吗？读者能回到某章吗？撕掉卡片用户会觉得书没讲过吗？"

### 类别 8 · s5 价值写成"给"句而非判断句
- **表现**：「给你一套"机制视角"，看人不再只看表面。」「给你 6 个可用的解释框架。」「帮你把自己从"本能的奴隶"变成"本能的鉴赏者"。」——AI 把自己当给予者。
- **根因**：把"价值"理解为"我给读者一个东西"，而不是"读者读完后形成的判断"（参纳瓦尔宝典 s5 / 金钱心理学 s5：每条都是**价值判断句** + 展开，不是"给你XX"的祈使句）。
- **预防（对应闸门步 8）**：s5 每条 = **价值判断句**（直陈一个读者读完后应持有的判断）+ 一段展开（不"给谁"，不"帮你把A变成B"）。"给你一套机制视角" → 「用机制视角看人，看人不再只看表面」。

### 类别 9 · prose 与对比框重复举例 / 例子不归位
- **表现**：s4·② prose 里讲了孔雀+鹿，异性选择对比框又举一次孔雀尾羽——同一例子出现两次；鹿的"同性竞争"例子挤在 prose 里而不是放进"例子"框。
- **根因**：prose、对比框、例子框没分工——prose 讲机制，例子用具体的实例讲，对比框用抽象对比讲。三处堆同一个例子。
- **预防（对应闸门步 9）**：每个例子**只出现一次**。prose 举孔雀讲完整因→果机制 → 对比框就**写抽象机制句**（不重复孔雀）→ 例子框集中放社会版本（选美、肌肉、彩礼、雄鹿角等）；其他社会例挪进例子框。

### 类别 10 · 标题超行 / 问句化
- **表现**：⑥ 标题「情绪为什么总是过度敏感」——折成两行显示（情绪/为什么/总是/过度敏感），问句化，又没用了；用户在纳瓦尔宝典看其他几本书检查有没有"超一行"标题。
- **根因**：标题当 prose 写，又问又长。
- **预防（对应闸门步 10）**：tcard/ccard 标题**视觉宽度 ≤ 22**（中文字符按 2、英文/数字按 1 估，> 22 视为超行）；超行的要么精简为机制名（"情绪为什么总是过度敏感"→"情绪机制"），要么改陈述句（"为什么" → 直接命名）。**写完横向扫一遍所有 tcard 标题，超行的就改**。

### 类别 11 · cline 自指累赘 / 重复 prose
- **表现**：cline 内容「看清它：机制不为任何一方辩护，但看清它，就能理解家里拉锯背后的内在逻辑」——「看清它」重复三次，"内在逻辑"已是 prose 讲过的，整句再写一遍。
- **根因**：把 cline 当成"对正文做总结"的容器，结果就是用另一堆字重说同一个意思。
- **预防（对应闸门步 11）**：cline 写**新一层含义**（如机制本身的伦理边界、读者应持有的态度、与常识的差异），不重复 prose 已经讲过的判断；不用「看清它」「回头看」「所以」这种指向正文的不自指标签。

### 类别 12 · 卡片文字"完整但不人话"——tdef/cohe 无主语 / prose 因果链糊成一句
- **表现**：
 ① tdef / cone 精简到没主语——读者读完不知道"谁挑剔、谁广撒网、谁想平分、谁想独占、平分什么、独占什么"：❌"投入越多越挑剔，越少越广撒网"（主语暗，谁多谁少？）、❌"愿帮谁，看基因上有多亲"（主语"我"暗，被帮的人"谁"主语也暗）、❌"父母想平分，子女想独占"（主语和宾语都简省）。
 ② prose 因果链不一步步断开——"烟感不等确认才响，宁可误报也不能漏报，漏报代价是烧房子，误报只是白忙活——宁可错杀不要放过"→ 句子里现象 + 推理 + 结论糊成一段，虽然写得"严密"但读着像机器报词条。
 ③ tcard 标题不居中——看着别扭但读着不影响，但视觉别扭也是 一种。
- **根因**：D11"严谨科学语言"误升级成"机械工整语言"；tdef / cone 当"标签"写而非"一句话讲清一句话事实"写；prose 当"一段话塞满所有逻辑"写而非"一句一层一层讲"写。
- **预防（对应闸门步 12）**：① tdef / cone 必须"一句人话 + 有主语"——每句能答出"谁，做什么，为什么"；② prose 因果链用"因为…所以…这就是…"分步骤断开，让读者能跟着你的因果链一句一句读；③ tcard 标题居中（不只是 ctitle，连同 svg 一起居中呈现）。具体写法参 SKILL.md / D12 节。

### 类别 13 · s5 = "用机制看机制"无日常问题 / "机制视角"未落到生物进化
- **表现**：
 ① s5 ① 写"用机制视角/用机制读人"——把"机制"说成"视角"，但机制只是生物进化的一个产物，视角应该是"生物进化的视角"。
 ② s5 三条全在复述机制本身（"用机制视角看人/用6个机制解释冲动/看清机制不被控制"），没给读者 1 个具体的"日常问题 → 哪个机制能解释"对号入座。读者看完不知道跟我有啥关系。
 ③ tdef ②③ 写"我帮你你帮我"段子和"雄孔雀被选中"段子，没回到"生物进化为了生存和繁衍"这条底层逻辑。
 ④ 子女侧写"想独占，因为自己只有一套基因要传"——"基因要传"是学术腔，没说清"自己跟孩子 100% 相同，跟父母只 50% 相同"这个机制。
- **根因**：把 s5 当"3 个机制的口号总结"写而非"读者能用机制解决哪些日常问题"写；每个机制只停在"具体例子"层面（孔雀、互惠），没回到"生存和繁衍"这条底层逻辑。
- **预防（对应闸门步 13）**：① s5 ① 标题写"用生物进化的视角"而非"用机制视角"——机制=生物进化的固化产物；② s5 三条必须给至少 3 个"日常问题 → 机制 → 想通"对号入座（八卦拉帮派=互惠利他+同性竞争 / 怕出错焦虑=烟雾报警器 / 父母催婚起冲突=亲子冲突+广义适合度）；③ tdef 必须落到"生物进化为了生存和繁衍"这条底层逻辑，不写"我帮你你帮我"这种拟人段子和"雄孔雀被选中"这种过于具象的判断；④ 子女侧"基因要传"换成"和自己 100% 相同 / 和父母 50% 相同"的具体机制。

### 类别 14 · s5 三条是"同一句话的三种说法" / s5 局限段写空话免责
- **表现**：
 ① s5 三条全在说"用机制看人/看日常/不被机制控制"，本质上是同一件事的三种说法。读者读完"跟我有什么关系？我学它干啥？"。缺反常识判断、缺具体方法论、缺一个延伸到书外的主题（人性/钱/进步/决策/消费/学习/工作/关系 等）。
 ② s5 局限段写"它解释的是群体层面的平均趋势，不擅长预测下一步，作为参考就好"——空话，没讲清书做到了什么、没做到什么、怎么用。"作为参考"是 AI 标配免责结尾，不传达任何信息。
- **根因**：把 s5 当"3 个机制的口号总结"而非"3 个延伸出书外的思考"写；把局限段当"避坑免责"而非"方法论边界+怎么用"写。
- **预防（对应闸门步 14）**——s5 每条必须有**四件套**：
 ① **关联一个/多个机制**（说明这个延伸来自书的哪些机制）；
 ② **延伸出一个书外主题**（人性 / 钱 / 进步 / 决策 / 学习 / 工作 / 关系 / 消费 等具体主题，不能停在"机制"本身）；
 ③ **一个反常识判断**（一句话站队，让人眼前一亮，如"人性不是抽象本质，是可拆解的来历" / "不消费，要生产" / "不该用道德评判人，用机制读人" / "进步不等于幸福" / "用钱投资不要只消费"）；
 ④ **具体方法论**（看完能照着做的步骤或作，如"识别行为→追机制→看代价"三步法 / "能识别机制是否错位就用机制安慰自己" / "先当生产者后当消费者"）。
 三条之间必须是**不同的主题、不同的反常识、不同的方法**，不能是同一句话的三种说法。
- **标杆参照**（来自）：
 - 人类简史 ③ 进步不等于幸福（反常识+大主题）
 - 孙子兵法 大局观·道天地将法=看问题框架（方法论）
 - 纳瓦尔宝典 ② 用钱投资而不是只消费（反常识+对比）
 - 纳瓦尔宝典 ③ 先当生产者不是消费者（反常识+对比）
- **s5 局限段铁律**（对应闸门步 14）：s5 局限段必须**具体说清**——
 ① 它**能**做什么（擅长解释"为什么这样" / 解释行为的来历和机制 / 看清群体倾向）；
 ② 它**不能**做什么（不擅长预测具体下一步 / 不能给个人行为指南 / 不能解释个体差异的具体原因）；
 ③ 它**适合怎么用**（当看清自己和别人的参考书来用，不要当行为指南照搬）。
 三段都要落到具体，不能空说"群体""个体""参考"。
- **判断口诀**：写 s5 前先问——"这三条是不是同一句话的三种说法？"是的话就是类别 14；写完 s5 后再问——"每条有没有「机制→书外主题→反常识判断→具体方法」四件套？"少一件就是类别 14；最后问——"读者读完能不能拿去解决一个具体问题？"答不上来就是类别 14。s5 局限段写完自问——"这段是具体说清「能/不能/怎么用」三件事，还是只说了'参考就好'这种空话？"是空话就是类别 14。

### 类别 15 · s5 浮夸 AI 词族 —— 把"机制"包装成"程序库/视角/读人方法/工程师牢笼/工具箱"

- **表现**：s5 三条全用 AI 自造的高级比喻代替大白话：
 ① **程序库 / 抽象本质 / 可拆解的来历** —— ❌"人是为生存繁衍而设计的程序库，不是抽象本质"❌"人性不是抽象本质，是可拆解的来历"❌"取而代之的是一个个能被追问的机制"——把机制升级成"程序库"是 AI 包装过的概念，本来"每一个行为都有一个当初帮祖先活下来的原因"就能说清。
 ② **错配 / 远古机制和现代环境的错配** —— ❌"社会在飞速进步，机制却没跟上——错配带来了普遍的不安"❌"不是个体问题，是远古机制和现代环境的错配"——"错配"二字是大词压住事实，事实就是"今天的小事被远古机制当大事对待"。
 ③ **用机制读人 / 工程师视角 / 道德牢笼 / 圈套** —— ❌"别用道德评判人，用机制读人"❌"你就跳出了「该不该」的道德牢笼，进了另一个圈套"❌"进入「它在跑什么、代价是什么、能不能绕开」的工程师视角"——把"机制"升级成"读人方法"是 AI 造的职业比喻，机制只是生物进化的产物。
 ④ **工具箱 / 工具不是答案** —— ❌"它给你一套机制工具箱，但工具不是答案"——"工具-答案"二分是 AI 标配废话。
- **根因**：把"机制"当成一个需要被包装的核心词，结果越包越浮夸；忘了机制只是生物进化的一个结果，不要把"机制"包装成工具/视角/方法等高级名词。
- **预防（对应闸门步 15）**：写 s5 时每次想用"机制"前先问"机制在这里能不能被替换成大白话"——
 - ❌"人是程序库" → ✅"过去说人性自私、人心难测，是给'人'贴标签；书里讲的是：每一个具体行为都有一个当初帮祖先活下来的原因"
 - ❌"错配" → ✅"今天的小事被远古机制当'真危险'对待"
 - ❌"用机制读人" → ✅"看到一个行为，多问一句'它当初是为了帮我们祖先解决什么事而存在的'"
 - ❌"工程师视角/道德牢笼" → ✅"用不着老在心里掂量'该不该'，可以换一个问题：它在跑什么，代价是什么，能不能绕开"
 写完 s5 后**出声念一遍**——"一个真实的人会对朋友这么讲吗？像不像装深刻？"念着别扭就是浮夸，删。
- **判别清单（ 浮夸比喻在 s5 里的进化版）**：本类是 （自造比喻）的下一代，专攻"s5 把机制包装成高级概念"——AI 写 s5 时最爱把"机制"和"生物进化"装进"程序库/视角/工具/读人方法/工程师"这一族高级名词里，结果越装越装。**真正的判断标准**：念出来朋友听到的第一反应是"哦是这样"还是"你这在装啥"。

### 类别 16 · 内容空洞、无逻辑因果链、堆砌无价值内容
- **表现**：整段读完"前言不搭后语、全是 AI 腔、读不懂、没逻辑"，每一句单独看"词都干净"但拼起来没有因果推进——不是顺着"因为…所以…"递进，而是把一堆不连贯的词条堆在一起；每节不点"回答什么日常问题"，每段不停在"对读者有什么用"，读者读完"跟我没关系、学它干啥、毫无价值"。
- **根因**：把"词干净"当成"写好"，写完自觉"没禁词"就放行，但没检查整段有没有因果链、有没有落回读者价值。这是 全清了之后**更高一层的失败**——不是某句话造词，是整体没逻辑、没价值。
- **预防（对应闸门步 16）**：写每段前先定"这一节要回答什么日常问题"（如"父母催婚/同事攀比的冲动，书里怎么解释"），让读者一上来知道"跟我有关"；每段用"因为…所以…"顺着因果讲、收尾落回"对读者有什么用"（如"看清了，判断权回到你手里"）；写完自问"删掉这段，读者的理解缺了一块吗"——不缺就是堆砌，删。

### 类别 17 · 核心概念全书从未定义清楚
- **表现**：通篇用"机制"却不先给一句大白话定义，读者读到结尾不知"机制到底是什么"；整节讲一个新概念（如 s3 讲"机制"、s4 讲"冲突"）不先点明"它指什么"就展开，读到一半还在猜这个词是啥。
- **根因**：默认读者已经懂"机制/冲突/广义适合度"这些词，或把这些词当"常识术语"带过，没意识到对第一次读卡的人它们需要一句大白话定义。
- **预防（对应闸门步 17）**：每个核心概念第一次出现，紧跟一句大白话定义（"机制就是'场景 → 行为'的固定连接""冲突就是两方进化利益不一致时起的拉扯"）；整节讲一个新概念时，节首必须先定义再展开；定义不造词（用 / 禁词之外的大白话）。自检："读者读到这节一半，能说出这个核心概念指什么吗"——说不出就是定义句没写或写在太后面，前移。

> **最深的根因（类别 1-17 的共同源头）**： 全写了，但**生成时是"写完自觉觉得干净"，没把核查当成一道强制、可见的闸门**。grep 正则又永远滞后（"越传越广"漏了、"无主语精简句"漏了、"s5 三条同一句话"语义漏了、"机制视角"漏了、"程序库/可拆解的来历"漏了）——所以同一类问题换个字又冒出来。治本是下面这道"逻辑核查十七步"，它抓的是 grep 抓不到的语义问题，而且**必须逐节跑、必须把表贴出来**。
