## 〇·样式使用三铁律（违反一条必翻车）

| # | 铁律 | 违规后果 |
|---|------|---------|
| **铁律 1** | **禁止自造 class**。白名单外的新 class 一律视为违例。白名单新增要登记、并标注来源书和使用场景。 | 自造样式经常跟父级或现有规则"打架"，出来四种边框/三种背景的杂乱效果。|
| **铁律 2** | **复用别书样式须整段带 CSS**。复用前先 grep 源书的 CSS 段和实际 HTML 例子，整段复制到自己书 CSS 里（必要改类名加书前缀），不许只搬 HTML 结构名。| 影响力 v19 翻车：以为 `.vs` 通用，没复制源 CSS 直接用，结果跟 `.col.new` 互冲。|
| **铁律 3** | **派生 class 覆写须穷举父级全部 CSS**。派生新类时先 grep 父级类的所有规则，把可能继承来的 `border / background / border-radius / padding / 字号 / 颜色` 全部列出，逐条覆写。**要么全清零、要么全保留**——半清半留必漏。| 影响力 v22 翻车：`.vs.s4` 没覆写父级 `.vs .col:first-child{border-right:2.5px dashed}`，出来三种边框（dashed / solid / none）。 |

## 一·视觉对比四级优先级（HTML 怎么"看起来不一样"）

> **视觉区分只有一个动作：拉对比度**。需要分主次时，按下表顺序挑载体。**可同时叠加，但同一个层级内优先级如下**：

| 优先级 | 载体 | 视觉影响 | 适用场景 |
|--------|------|---------|---------|
| **L1** | **背景色** | 最强（决定眼睛第一停留 0.5s） | 主块 vs 次块（如机制 vs 应用）|
| **L2** | **边框样式**（实/虚/粗细） | 中（边框决定"是不是被强调"）| 主块带框，次块无框（如 .gc 红边框 vs .vs.s4 无边框）|
| **L3** | **圆角度**（rx 0/8/14） | 中（圆角决定"是不是更突出"） | 主卡圆角 14px，次卡直角 0 |
| **L4** | **字号/字色**（红 vs 黑） | 弱（决定最后 0.1s 扫读）| 标题红、文本黑；标题字号 25-29，正文 21-23 |

> **判别口诀**：读者第一眼分得清主次吗？能在 3 秒内扫出"这块是该详读的、那块是该略过的"？能 → 通过；不能 → 拉 L1 背景对比。
>
> *已写进 MEMORY.md 的 RC61。*

## 二·核心结构件白名单（按"用得多+经常混"分 7 组）

> 每条写：用途 + 关键 CSS（父级 + 子件 + 颜色变量）+ 不要做什么 + 出处书 + 出处节。

### 🔴 1. 概念卡组（s4 单机制展开用，5 种选 1）
| 名称 | 用途 | 关键 CSS | **何时用** | **不要用** | 出处 |
|------|------|---------|----------|----------|------|
| **`.concept` + `.chead/.cnum/.cmeta/.cname/.cone/.cbody` + `.cline`** | 单机制纵向展开（含编号+短引+一句话+多段+斜杠归纳） | 卡片 `2.5px solid var(--line)` 直角；`.cname` 29px accent 红；`.cbody p` 23px ink；`.cline` accent-soft 底+左 4px 红 | 内容多、需要层层说理（3 段 prose + 关键归纳）| 一个段落能讲清的小概念硬套 → 撑大| 纳瓦尔/影响力/进化心理学 s4 |
| **`.ccard` + `.ctitle/.ctag/.cfig/.cdesc`** | 紧凑型图标卡（含图标 SVG + 一段说明） | 卡片 `2.5px solid var(--line)` 圆角 14；`.ctitle` 25px accent 红；`cfig` SVG；`.cdesc` 18px muted | 一句话能讲清、想配图增强记忆的概念 | 复杂多段机制硬塞进 ccard → 撑破文字 | 纳瓦尔 s4 / 国富论 s5 / 人类简史 s4 / 孙子兵法 s4 |
| **`.tcard` + `.thead/.tname/.tfig/.tdef`** | 表格型分类卡（含编号 + 标题 + 短图 + 一句话） | 类似 .ccard 但更紧凑 | 进化机制分类、需要并排 3-6 个对照的 | 想展开多层因果 → 装不下 | 进化心理学 s4 |
| **`.abc-box` + `.abc-letter/.abc-name/.abc-text/.abc-arrow/.abc-cap`** | ABC 理论专用卡（A→B→C 因果链 + 注解） | 内嵌 `.abc-flow` 三段块 | 书里作者明确用 ABC 模型（A→B→C）讲机制 | 不是 ABC 模型 → 硬套 → 走样 | 这就是人性 s4 |
| **`.story-part` + `.sp-num/.sp-body`** + `.timeline/.tnode/.dot/.ty/.tt` | 故事/时间轴卡（含分段时间点 + 时间轴） | 故事段落按 `story-parts` 容器堆叠 | 作者用时间线/事件链讲发展过程（人物传记/历史事件）| 抽象机制 → 硬套 → 走样 | 达芬奇传 s4 |

> **选择口诀**：
> - **7 张机制展开有详有略 → `.concept`**（影响力典型）
> - **5-6 个机制一图一概念 → `.ccard` 系列**（纳瓦尔典型）
> - **3-6 个分类需要并排对照 → `.tcard`**
> - **A→B→C 因果链 → `.abc-box`**
> - **故事时间线 → `.story-part`**

### 🔴 2. 对比双栏组（4 种选 1，**重要！经常混**）
| 名称 | 用途 | 关键 CSS | **何时用** | **不要用** | 出处 |
|------|------|---------|----------|----------|------|
| **`.vs`**（核心=误区 vs 正解） | 同一概念，左"常见误区"右"作者正解" | 容器 grid `1fr 1fr`，gap 16-22；左 `.col` + 右 `.col.new` accent-soft 浅红底+红 tag；`.vt` 28px accent 红；`.vd` 23px ink | 作者**推翻某事并重定义** | 单纯错 vs 对 / 防 vs 用 → 走错模板 | 纳瓦尔 s2 / 影响力 s4 改前（已撤）|
| **`.vs.old`**（s5 用=错 vs 对） | 同一行为，左"错误做法"右"正确做法" | 跟 `.vs` 视觉相同 | s5 延伸应用、给你"做错 vs 做对"两套行为 | s4 作者核心机制（那是 `.vs` 范畴）| 纳瓦尔 s5 / 影响力 s5 / 国富论 s5 / 这就是人性 s5 |
| **`.vs.s4`**（影响力 v21 自创，应用对照） | 应用层对照，左"怎么不中招"右"怎么用它影响别人" | 容器 grid 双栏 14px gap；左右一致 8% 棕灰底；`.vt` 23px accent 红；`.vd` 21px ink；**全无边框**| 已有 .gc 红框讲机制，下一层要讲"用法"延展 | 没理解父级 `.vs` 就覆写 → 出来三种边框 | 影响力 v21-v22 |
| **`.mini-vs` + `.mcol/.mt/.mp`** | 弱化小对比（左灰右浅红，左 `.mcol` 右 `.mcol.good` accent 红框） | 容器 14px gap；左 8% 棕灰底；右 8% accent 浅红底+2px accent 红边 | 父级 `.vs` 太重，需要更轻量的对比 | 单栏能讲清的事拉双栏 → 撑破 | 纳瓦尔 s4 / 进化心理学 s4 |

> **选择口诀（最关键！）**：
> - s4 作者重定义某概念 → `.vs`
> - s4 机制卡里的延伸应用对照 → `.vs.s4` 或 `.mini-vs`
> - s5 错 vs 对/防 vs 用 → `.vs.old`
> - 卡内子条目小对比 → `.mini-vs`

## 三·移动端断点规范（@media 必要）

每本书必带 2 段断点（已有纳瓦尔 s4 模板）：

```css
/* 中屏：≤900px *核心卡片变 2 列 */
@media (max-width:900px){
  .core-cards,.grid4{grid-template-columns:repeat(2,1fr)}
}

/* 手机：≤720px *双栏对比合并成单栏，破折号边改破折号底 */
@media (max-width:720px){
  .vs,.vs.old,.vs.s4,.mini-vs,.abc-flow{grid-template-columns:1fr;gap:10px}
  .vs .col:first-child{border-right:none;border-bottom:2.5px dashed var(--line)}
  .mini-vs .mcol.good,.vs.s4 .col.new{border:2px solid var(--accent)}
  .wrap{padding:32px 16px 70px}
  .bigq{font-size:40px}
  .sec-title{font-size:34px}
  .tab{font-size:17px;padding:6px 10px}
}
```

## 五·反模式速查表（看到这些征兆立即回头修）

| 征兆 | 错在哪 | 怎么修 |
|------|---------|--------|
| 一段 `.vs` 单独用、左右内容都不显眼 | 用了 `.vs` 但放错位置（s4 该用 `.vs.s4` / `.mini-vs`）| 替换为本表二级 |
| 一段 prose 全是大文字、没结构件 | 严重违反"prose+结构件双轨" | 加 `.pt` / `.quote` / `.example` / `.cline` |
| `.vs` 内 `.col` 有 dashed / `.col.new` 有 solid / 外层有 box-shadow | **派生覆写没穷举**——同块出来 2-3 种边框 | 全部 `border:none` 重置 |
| `.column-grid-3` / `.custom-banner` / `.card-fancy` / 任何自造类 | **白名单外违规** | 删除，本表 7 组里挑一个 |
| 同节（如 s4）所有卡都用同一模板（如全是 .vs） | **视觉无区分**——主次一锅炖 | 主卡用 `.concept`/`.ccard`，次卡用 `.vs.s4`/`.grid4`/`.quote` 交替 |
| 在 7 张机制卡里塞 7 张 .quote | **冗余堆叠**——quote 该讲完一段才出 | 减到 1-2 张，或改用 `.cline` 嵌入卡内 |
| 卡标题红色 30px、正文红色 21px | **整卡都红**——L1 失效 | 标题红/正文黑（.vd 一律 ink）|
