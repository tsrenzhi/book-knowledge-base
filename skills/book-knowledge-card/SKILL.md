# 书籍知识卡片（Book Knowledge Card）

## Overview

把一本"读完才知道好在哪"的书，蒸馏成一张**小白打开就懂**的可视化网页卡片：顶部「书名 + 作者·出版年 + 全称 + 一句红色钩子大字（bigq，标杆《国富论》《纳瓦尔宝典》《孙子兵法》都有）」，**不写"书讲什么"副标题**——"书讲什么"由第一个 section（书籍定位）承担。下面用白板手绘风讲清"这本书到底在说什么、对现在的我有什么用"。气质是"朋友给你讲书"，不是学术 PPT。

交付物为**正常滚动网页 HTML**（非 9:16 竖屏、非 PPT），浏览器直开、可编辑、可导出、可演示。

## 核心样板（不可覆盖 · 强制预读）

本 skill 的视觉与语感基准，由**两本标杆卡片**共同定义，**做新书前必须先 Read 这三本、对齐它们的结构再动笔——不准凭记忆从零"创作"样式**（这是富爸爸穷爸爸 17 轮反复翻车后立的头号铁律：每次 AI 凭记忆写样式必错，读标杆抄标杆才稳）。

1. **`cards/na-wa-er-bao-dian/纳瓦尔宝典-知识卡片.html`** → **核心内容（s4）结构最全的母版**。6 张 `.ccard` 速览 + 6 张 `.concept` 编号大卡，大卡里 `.vs` / `.levels` / `.example` / `.cline` 各种组合都用过。**任何"核心内容怎么排、先框还是后展开"的疑问，先翻它**。
2. **`cards/guo-fu-lun/国富论-知识卡片.html`** → **标准六段骨架母版**（s1 书籍定位 → s2 现实矛盾(old) → s3 两套旧观念(.vs old) → s4 核心主张(points+quote) → s5 核心内容(先 ccard 框后 concept 展开) → s6 核心价值(.vs old+points)）。Tab 命名风格、`.vs old` 用法、SVG 现金流图坐标都以它为基准。

> ⚠ **强制预读纪律（富爸爸 17 轮复盘立）**：每做一本新书，第一步不是写代码，而是 `Read` 上面 ① 纳瓦尔宝典（重点看 s4 核心内容）+ ② 国富论（看 s1-s6 骨架）。**样式问题 90% 来自"没读标杆就开写"**— 答案：skill 早有标准样式，问题在 AI 没去读。从今往后：写前不 Read 两本标杆 = 违规。

- 出其他书：文件名另起（如 `思考快与慢-知识卡片.html`），不碰 `cards/guo-fu-lun/` 与 `cards/na-wa-er-bao-dian/` 下已有的标杆卡片。
- 结构可因书而异，但视觉规范、语言铁律、四块必含内容必须对齐标杆水准。

## 何时用 / 与相邻 skill 的区别

- 要**可视化网页卡片**（小白可读、能演示）→ 用本 skill。
- 要**纯文字读书框架文档**（速读卡 + 七节深度）→ 原用 `book-reading-framework`，但该 skill 已于 废弃；纯文字结构化梳理现在直接产出到 `你的书籍库/` 知识库（见下节）。
- 要**任何主题的结构化白板手绘逻辑图**（不限于书）→ 用 `whiteboard-sketch-logic-map`（本 skill 的视觉默认沿用它的暖红规范）。
- 要**提炼一本书的 2-4 个可迁移短关键词**（用于跨书关联）→ 用 `book-core-points`（它读你产出的卡片 HTML 的 `<b>` 词 + 内容，提炼可迁移关键词，喂给图谱）。
- 要**把全部书建成可交互「知识图谱」力导向图** → 用 `book-knowledge-graph`（消费 graph.json，本 skill 每做完一本就增量更新它，是它的强制上游）。
- 要**端到端跑通「拉书 → 提要点 → 建卡 → 建图谱」全流程** → 用 `book-knowledge-workflow`（总控 SOP，编排上面三个 skill + 三个流程脚本）。

## 卡片 ≠ 文档（动笔前先想清身份）

知识卡片**不是**把读书笔记 / 公众号文章 / 飞书文档搬进网页，而是对原内容的**可视化重构**：

- **文档**：线性阅读，可以大段展开、靠上下文慢慢铺垫，读者一行行读下去。
- **卡片**：扫读为主，每个模块独立成立又彼此咬合，读者是"跳着看、一眼抓重点、顺着转折读懂逻辑"。

所以同一份素材进卡片要**重新组织**——把大段 prose 拆成对比框 / 编号列表 / 关键词标签 / 例子，把隐含的**转折与因果显式画出来**，而不是原样贴。原话的完整连贯表达由你的原始笔记保留；卡片只负责"让人一眼懂结构、看到对比、顺着转折读完不跳脱"。这条身份纪律的详细写法见 [references/content-spec.md](references/content-spec.md) 的「表达三铁律」。

## 分类纪律：不许自作主张改大类

书的 `category` / `subcategory` 不是我可以凭感觉写的，必须以用户已经定好的分类为准：

- **权威来源**：`书单数据源.md`（书单 + 15 个大类）。做书前先查这本书归哪一类，卡片的分类就写哪一类。
- **若 CATALOG 里没有**，先按 `graph.json` 的 `meta.categories` 15 个大类候选，**必须向用户确认后再写**，不许自己拍脑袋。
- **禁止事后改分类**：比如《通往奴役之路》在 CATALOG 里明确归「经济与商业」，就不能因为它讨论自由/政府就写成「哲学思辨」。哈耶克是经济学家，这本书是政治经济学，不是政治哲学。
- **subcategory 可以留白**：如果 CATALOG 只给大类没给小类，`subcategory` 写 "" 或不写，不要硬编一个看起来顺眼的。

这条写进卡片分类与 `graph.json` 节点，保持一致。

4. 判定口径：卡片呈现的是"作者的核心观点与内容"，不是"这本书的目录结构 / 引用出处批注"。所以——

 - **禁卷章指称**：`第8章` `第10章` `车里的男人` `卷一` 一律不许出现。作者观点直接陈述，读者不需要知道它落在原书哪一章。
 - **禁"书里说"类元话语**：`书里举了` `书里称为` `书里点破` `书里点明` `书里的观点`（全书可视化卡里）全部删掉，直接写成陈述句。例外：单知识点学习卡「书里的观点 vs 我的理解」是用户自定的对照格式，不在此列。
 - **禁出处批注**：`书里原话（序言）` `作者的原话是（第X章）` `先定义清楚` 这类标签删掉；真要引原话，只保留双引号内的一句，不标章节 / 不出处 / 不加"原话"属性词。
 - **禁外部来源指涉**：`公众号` `从你公众号` `你那篇公众号` 一律不许出现——用户给的公众号 / 笔记 / 划线是组织素材，不是卡片里要点名的东西。
 - **标题用规范词**：核心内容节必须叫"核心内容"，不得写"核心道理""核心观点""核心机制"。

4. 自检顺便过一遍：bigq 是不是读者真在问的核心问题（不是书里某句金句）、hero 有没有副标题 / 解释框、第一节是不是"书籍定位"。这三条和上面的 grep 是一套，缺一不可。

## 🔴 根因纪律：先锚定，再下笔（治本，不止禁词表）

> **为什么这一节必须存在**：上面「交付前硬闸门」是**治标**——它靠一张越加越长的禁词正则去扫。但 进化心理学卡片反复挨骂证明：**禁词表是打地鼠，打不完**。用户每次抓一个词（"滑入""预先装载""是不等于应该""一棵主干"），我就加一个词；但我的**生成逻辑没改**，于是下次又吐出同一类的新变种（"预先装配""跟着进化走不跟着时代走""用应该去压制机制"）。——**根因不是词，是我的生成过程在'造'**。这一节是治本：把"不造"写进生成动作本身，而不是等写完了再扫。

### 一、六大根因（为什么会造词 / 造金句 / 造比喻）

| # | 根因 | 表现 |
|---|---|---|
| | **内容真实性只有"写后扫"，没有"写前锚"** | 我凭模糊记忆自由写，写完才 grep 禁词；此时编造已成型。一旦有新花样就漏网 |
| | **夹生当读透（"生磁的逻辑有问题"）** | 对书只有模糊印象，写时从记忆推 → 推 → 编。理论的真表述不会，就自造压缩句替代 |
| | **把"信息密度感"误当成"真实术语+大白话"** | 不确定时用"机制=倾向""预先装载""滑入X"这种压缩伪严谨句假装深刻 |
| | **追求"金句感/对称感"而非"把事说清"** | 造对仗/格言/总结式漂亮话（"是≠应该""一棵主干+分支""跟着X走不跟着Y走""用应该去压制机制"） |
| | **结构驱动 > 内容驱动（先建框再填料）** | 漂亮结构先搭好，空格子没真料就生成"合理"填充 → 编造 |
| | **每节想独立讲完整，不做全局去重** | s4 prose 重复 s3、s5 重复 s2——同句换字再现 |
| | **把"结构化"误解成"用破折号/短句切碎"** | 为凑结构件把连贯 prose 拆碎，滥用破折号当万能连接，句间缺连接词（所以/但是/而），读作字字懂但连不起来 |
| | **没把真实输入当输入** | 写前不读原书内容、不读真实读者评论、不读用户给的素材，全凭记忆+AI习惯生成 → 必造、必浮、必跑偏；用户素材不用、热评不忠实总结 |
| | **把"非核心/非作者"内容误升为书的核心观点** | 不区分"内容来源层"：把序言/译者注/不反常识的发散当全书核心塞进 s3/s4；或把本该进 s5 的延伸思考硬塞进核心 |
| | **结构驱动式堆内容、相近不合并** | 以为"内容越多越好"，机械扩卡；相似主题不合并（亲子冲突 vs 两性冲突本同属冲突理论），导致卡多、重复、读着散 |
| | **内容空洞、AI 味、无逻辑因果链** | 写完自认"词干净"就放行，但整段无因果推进、前言不搭后语、堆砌无价值内容、读着像机器报词条；读者读完"跟我没关系、学它干啥、毫无价值" |
| | **核心概念全书从未定义清楚** | 通篇用"机制"却不先给一句大白话定义，读者读到结尾不知"机制到底是什么"；新概念（如整节讲"冲突"）不先点明它指什么就展开 |
| | **没有对应原书概念的结构件绝对不画** | 借母版样式（如 .abc-flow）当"通用设计感"贴，但原书根本没有这个三步/四步概念 → 凭空造设计 |
| | **`.quote` 分级使用** | 纳瓦尔 .quote 是粗红实线大框（border:3px solid var(--accent)），仅用于 s4 重大理论点睛；每张概念卡都用 = 视觉通货膨胀，比 hero 标题还抢戏 |
| | **s4 内部子机制结构对标（附记）** | 多张概念卡都含子机制时（互惠2个+喜好4个），必须用同一结构件（.levels）列子机制，每个含"为什么会生效+例子"——视觉一致，不要一张用 prose 一张用 levels |
| | **s5 核心价值 = 外层大圆角框套整条（v13， 第十八次暴怒新立）** | s5 七条都成独立卡片（外层大圆角框包整条），序号红底白字大字、主题红字、一句话机制引言、内嵌对比子框（错误vs正确/旧vs新）、末尾收束 prose —— 跟纳瓦尔 s5「用钱投资」那张完全同款。不许裸 .lv/.levels/.mini-vs 简单堆砌。 |

| | **每张概念卡必须"递进不重复"（v14， 第十九次暴怒新立）** | 同一信息只在结构里出现一次：quote 不许放中间、tags 不许与子机制段重复、example 不许与子机制段重复、levels 不许拆"为什么会生效+例子"两段。结构固定：chead → intro → lead 机制一句 → 子机制 prose（每段机制+例子合并）→ quote 注意事项（最后）→ mini-vs 怎么用（最后） |

### 二、六条治本纪律（动笔前逐条过，不是写完扫）

- **D1 先锚定，再下笔**：每写一句，先确认它来自书里（原话 / 作者意思 / 合理引申）。**拿不准的，先去查（微信读书 / 搜索 / 书摘），不要从记忆硬编**。判定："书里真有这句话吗？" 没有 → 要么标成"我推的"谨慎写，要么删。绝不用自信语气写编造内容。
- **D2 不读透不写**：对一本书的理论/机制没有扎实把握前，不产出概念卡。先抓真实素材（章节小结 / 热门划线 / 书摘）列"要点清单"，再动笔。模糊记忆 → 查，不推。
- **D3 严禁压缩造词**：不用自造压缩短语假装严谨。严谨 = 用书里真实术语 + 大白话解释。自检："这句是不是比来源'密'？密了就是我在编，重写成大白话。"
- **D4 禁金句制造**：不写对仗 / 格言 / 总结式漂亮话。自检金句：**"去掉这句，信息少了吗？"** 只是"听起来深刻"但没新增事实 → 删。典型禁造结构：`X≠Y` / `X 不是 A，是 B` / `一棵主干+N分支` / `跟着X走不跟着Y走` / `用X去压制Y` / `从A变成B` / `把A当B`。
- **D5 内容先于结构**：先有真实素材清单，再决定结构怎么排。结构是容器，内容是王。某个空格子没真料 → 宁可少一节，不硬编填充。
- **D6 全局去重**：维护"已讲内容清单"。每个新段落必须带来**新信息或新角度**，不允许重新陈述相邻节已讲的内容。s4 的 prose 段只写"用机制看生活"的应用/反常识判断，不重复 s3+理论卡的研究内容。
- **D7 克制破折号，连贯优先**：破折号只在"真正插入补充 / 话题突转"时用，其余一律改逗号、句号、冒号，或"一是…二是…"列举。prose 正文必须写成有主谓宾、有承接词（所以/但是/而/因为/也就是说/其实）的自然段落，不得拆成互不连属的碎句。结构靠 .vs / .points / .theory-grid / .core-cards / .roadmap 这些**结构件**承载，连贯叙述交给 prose——两者职责分开，不要为"结构化"牺牲可读性。一句硬指标：单篇破折号应 < 15 处且都是真插入；超了就是 在发作。
- **D8 概念卡叙述法 = 人类简史式一段长 prose**：每张概念卡 / 每个 sub-section 的 prose 必须写成"一段连贯长 prose 一路讲到底"，**禁止**写成"远古一句 + 现在一句"两段并列、或"本能 1 / 本能 2 / 本能 3"四张并列分卡。原因是读者读并列卡片时是跳着读、抓不到机制；人类简史"金钱：信任才是它的后盾" / "想象的秩序：我们活在别人编的故事里"每张卡都是 200-300 字一路讲到结论，读起来是顺着因果链焊死的一条线。具体五条硬指标：

 1. **标题是反常识/抓核心判断型**：写"小麦驯化了智人""信任才是它的后盾"这种**一句反常识判断**作主标题；不写"男女策略不同，规律在这里"这种**标签型废话**，不写"合作、攻击、冲突、地位"这种**列举型标题**，不写"读到这儿你就能用机制视角看懂自己"这种**meta 句**。
 2. **每节 prose 2-3 段、每段 100-180 字、整段总长 250-350 字**：人类简史每张概念卡的 prose 长度区间（不能再短：沦为碎句堆叠；也不能再长：读者注意力断裂）。
 3. **连接词必须可见**：所以 / 正因为 / 但是 / 而 / 当...时 / 只有 / 也就是说——这些把因果链焊死。读者必须能"顺着读、不跳脱"。每段至少出现 1 个连接词，全节 ≥ 3 个。
 4. **至少 2 个具象例子**（抽象概念用具象例子承载）：八卦、牢笼、纸币、汽车、薯片、房贷、吸烟、过马路看手机——这种"读者一秒钟能脑补出画面的具体场景"才算例子。空话"机制在替双方算账"算不算？算日常用词，但不算具象例子——例子必须能让人脑补出画面。
 5. **收尾一句反常识判断**：每段末尾 / 每节末尾都要收一句"读者没预期到的判断"（"这不是意志力差，是六百万年演化的报警系统还在用今天的身体执行昨天的逻辑"型），不能停在"控制不住自己想吃高糖高脂"这种表层重复上。

 **绝对禁止的反面教材**（进化心理学 v1-v11 反复踩过的雷，都固化）：
 - 把一个机制切成本能 1 / 本能 2 / 本能 3 / 本能 4 四张并列分卡（每张两句话），这是 PPT 条目不是卡片叙述。
 - "远古时代...所以今天..." 套句：远古一句 + 今天一句独立并列，没有"中间出了什么事导致机制没跟上"的展开。
 - "读完这一节，你能用机制视角看懂自己"开头：meta 句，正文紧接着就讲看书之外的"自己"，内容悬空。
 - 短 prose + 长结构件拼接：每个 sub-section 末尾用"读完这一节能看懂 X"两句话收尾，所有实质内容都在 .vs 对比框 / .core-cards 五张分卡里——读者读完会"字字懂，连不起来"。

 **这条立时间**： ，质问"是不是连贯的话？是不是让人一下就能看懂？你再看看你写的到底怎么写的？"。根因不是措辞，是**叙述法**——并列分卡/两段并列就是 ，与 D7 互补：前者管"宏观结构（是否一路讲到底）"、后者管"微观句式（是否碎句断句）"。

- **D8.5 s4 主结构 = N 卡 + N 段平铺（治 .5）**：上一版 /D8 我只在"s4-1~4 那层 sub-section 里做人类简史式连贯写法"，但用户骂的真实问题更上层——**s4 主结构本身就该是平铺**：N 张理论卡 + N 段连贯长 prose 一路讲到底。**禁止在 s4 主结构里再嵌 sub-section**：不允许再有 `<!-- 生存/择偶/群居/统一 -->` 这种 4 段 sub-section 块，每个里面再叠 `sub-title / sub-desc / vs 对比框 / 嵌入 ccard / prose`——这种嵌法让叙述散在不同子节里、读者读完会"字字懂连不起来"。
 - **正确结构**（参照人类简史 s4 真实样子）：`sec-title + 1 句 sec-sub + N 张理论卡 / 概念卡平铺（标题+反常识 tag+SVG+一句话） + N 段连贯长 prose 平铺（每段开头红色<b>反常识判断</b>，无 sub-title 切分）`。
 - **判断口诀**：写 s4 前先打开人类简史 s4 看一遍——它是什么样子，s4 就做成什么样子。**绝不是**"理论卡 + 4 个子节"，**只是**"理论卡 + 6 段长 prose 平铺"。
 - **禁止嵌套四件套**：① sub-title 层级标题（如"生存：恐惧机制"），② sub-desc / .col 嵌套对比框，③ sub-section 内嵌 .core-cards 五张分卡（如把"互惠利他 / 攻击 / 性嫉妒 / 杀妻 / 地位"嵌进"群居"子节），④ 每个子节末尾的"读完这一节..."meta 段。这些全删，全压平到主结构里。
 - 与 D8 互补：D8 管 prose 微观叙述（一路讲到底），D8.5 管 s4 主结构（不许嵌子节、不许嵌对比框、不许嵌小 ccard）。

- ** 把"连贯"误解成"纯文字墙"**：上一版按 D8/D8.5 把 s4 做成"6 张理论卡 + 7 段纯 prose 平铺"，矫枉过正——结构全删，变成文字墙。用户要的是**人类简史的"连贯叙述" + 纳瓦尔宝典的"结构呈现"叠加**：prose 负责连着说（读起来像人讲故事），结构件负责把重点拎出来（读者一眼抓到机制）。纳瓦尔宝典 s4 的真实样子 = 顶部 6 张小概念卡（地图）+ 下面 6 张大概念卡，每张大卡内是「编号圆点 + 红字概念名 + 灰字 cone（核心对比）+ 一段连贯 prose + 结构件（编号列表/两栏对比/关键词标签/例子框/强调框）」。
 - **D9 纳瓦尔式概念卡结构**：每张概念卡 = `编号 + 红字概念名 + 灰字 cone（核心对比/一句话，不重复正文首句） + 一段连贯 prose（人类简史式，2-3 句讲机制，不超长） + 结构件拎重点`。结构件从以下选 1-3 种：`.levels`（编号列表，如从理论推出的 N 个现象）、`.mini-vs`（两栏对比 A vs B）、`.tags`（关键词标签）、`.example`（例子框）、`.cline`（强调框/公式/两套机制）。
 - **两层地图 + 展开**：s4 顶部保留 N 张理论速览卡（tcard / core-cards，浓缩定义+提出者+关键变量），下面 N 张 concept 大卡逐一展开（prose + 结构件）。对照纳瓦尔宝典的 core-cards + concept-list 两层。
 - **绝对禁止**：① 纯 prose 墙（整节只有文字无结构件）——本轮犯的错；② 纯结构件堆叠无叙述（ 早期犯的错）；③ cone 与正文首句重复（纳瓦尔宝典 cone 是核心对比不是定义复述）；④ 一处只加一次（如"亲代投资不对称"在卡①定义，别在别卡当口号重复）。
 - **与 D7/D8/D8.5 互补**：D7 管微观句式（不碎句），D8 管 prose 一路讲到底，D8.5 管 s4 主结构平铺不嵌子节，D9 管"平铺的每张卡内要有结构件拎重点"——四者合力 = 连得起来、也看得清重点。
 - **判断口诀**：写 s4 前打开纳瓦尔宝典 s4 看一遍——它每张概念卡长什么样（编号+红名+灰cone+prose+结构件），s4 就做成什么样。标杆优先级：人类简史教"怎么连着说"，纳瓦尔宝典教"怎么用结构拎重点"。

 - ** 把"主线骨架"写成"研究几类问题"、把"核心内容"写成"研究细节"**：s3 不是"研究几类问题"列表，s3 是**作者的核心论断清单**——一句话能概括的判断（"谁投入越多谁就越挑剔""情绪过度敏感=宁误勿漏"），对应一类日常困惑。s4 prose 不能长篇讲研究数据/调查方法/学者（"跨 37 个文化测了一万人""Hamilton 的答案")——这些都是研究过程细节，不是结论。读者要的是"为什么是这样"的结论，不是"怎么得出这个结论"。
 - **D10 主线骨架=结论金字塔 + 概念卡 prose 去研究细节**：
 - s3 主线骨架**用纳瓦尔宝典 s3 的 `.points` 统一样式**：每条 = `编号圆点 + 加粗红名（如"机制的本质。"）+ 一段直写 prose`，像纳瓦尔宝典"① 积累专长。专长指的是……"那样直接写。**绝对禁止**：① 自创样式（如 roadmap / rm-row / "论断 N：机制的本质"标签框）；② 单列"作用：…""为什么：…"标签（把"为什么"自然融进 prose 直写，不贴标签）；③ 单列"核心论断：/核心判断："前缀。标题 = "作者的核心观点"（像纳瓦尔宝典 s3「纳瓦尔破局」直接列 1/2/3/4），不再写"作者到底研究了哪几类问题"。
 - s4 顶部理论卡标题 = 结论型（如"情绪为什么总是过度敏感"），**不带学者名（Trivers/Darwin/Hamilton）**——读者熟知的常识才写（如"DNA"）；不带元标签（"书中核心比喻"）。
 - s4 概念卡 prose 主体 = 讲"为什么是这样"，**不写**：跨 N 个文化 / 测了 M 人的研究设计、Barrow/Hamilton/Trivers 等学者名（除非该理论家名是机制名一部分）。可以写"9 个月孕期加多年哺乳"这类事实描述，但不要写研究方法。
 - **绝对禁止**（治本）：① s3 rm-row 写成"问题→研究→理论"研究过程；② s3 写"怎么得出的"段落；③ s4 顶部卡带学者名（除非普及常识，如"DNA"）；④ s4 顶部卡带"书中核心比喻"等元标签；⑤ s4 prose 出现"跨文化测了 / 研究 / 实验 / 调查 / 学者：..."这类研究过程描述。
 - **判断口诀**：写 s3 前先列一句话核心论断（不是"研究什么问题"），先有结论再配论证；写 s4 prose 前自问"这段在讲为什么还是讲怎么研究"——讲研究的全砍改结论。**标杆**：
 - 纳瓦尔宝典核心观点 = "积累专长/善用杠杆/相信复利/把自己产品化"——一句话判断；
 - 人类简史核心观点 = "认知革命/农业革命/科学革命"——一句话判断。
 - **进化心理学应该是**："心理机制=为解决适应性问题设计的程序"/"谁投入越多谁就越挑剔"/"合作靠互惠、竞争靠同性"/"情绪过度敏感=宁误勿漏"/"心理学所有分支都是进化论的影子"。

- ** 卡片文字口水/AI-造词**：卡片是科学读物的可视化，**"账本必须算清 / 混水摸鱼整张网就崩 / 识别欺骗者让你远离只蹭不付出的人 / 在心里盘算 / 表征"这种口水 AI 造词不是人话**；**"性别差异的总开关 / 投入不对称 → 挑剔不对称"这种 AI 装深刻的标签词也是**。读者要的是严谨平实的科学语言，不是 AI 腔。
 - **D11 严谨科学语言、禁口水/AI-造词**：
 - ① 写每句前问"这是严谨科学语言还是 AI 腔"——AI 腔（账本/算账/盘算/混水摸鱼/全归我/识别欺骗者远离只蹭不付出的人 等）一律改大白话或严谨术语。
 - ② AI 装深刻标签（总开关/决定性变量/核心命门/底层密码/底层逻辑 等）禁——直接陈述事实，不包装。
 - ③ 学术 jargon（表征/机制/适应性/亲缘系数 等）可以保留，但首次出现要给一句大白话解释；不能只丢 jargon 让读者自己猜。"表征"→"评估"，"机制"→具体机制名，"亲缘系数"→"基因相同比例"。
 - ④ 速览卡（s4 顶部 tcard）文字要"一眼抓结构"——每张 tdef 一句话即可，不展开论证，**不堆具体例子**（孔雀尾巴/程序员 等放 concept 卡），不写"由此推出/→ 决定"箭头式。
 - ⑤ 概念卡（concept cbody）prose 要严谨连贯，避免"账本/算账/盘算/全归我/总开关"等 AI 拟人化或装深刻的口水词。
 - **绝对禁止**（治本）：① AI 拟人口水（账本/算账/盘算/混水摸鱼/全归我/识别欺骗者远离只蹭不付出的人 等）；② AI 装深刻标签（总开关/决定性变量/核心命门/底层密码/底层逻辑 等）；③ 只丢 jargon 不解释（表征/机制/适应性 等首次出现要给大白话）；④ 箭头式总结（由此推出/→ 决定/→ 根源）；⑤ 速览卡堆具体例子。

- ** 卡片文字不通人话**：上一版 只禁了"AI 拟人/装深刻/jargon 不解释/箭头总结/速览卡堆例"，但用户 又揪出新一族毛病——**"句子是完整了但是不像人会说的话"**：① 速览卡 tdef 精简到没主语（"投入越多越挑剔，越少越广撒网" → 哪一方？谁挑剔？）；② cone 写得抽象没归到具体主体（"父母想平分，子女想独占" → 谁想平分？想平分什么？）；③ prose 段落用模糊连接把因果堆一起（"烟感不等确认才响，宁可误报……"一长串 → 应该是"烟雾报警器…响。**因为**漏报代价大，误报只是白忙活。**所以**宁可误报不能漏报。**这就是**：宁可错杀不要放过" → **先把机制点出来，再说代价，再说推理，最后给结论，每一步用连接词断开**）。这些都是"完整但不像活人"的句式问题，不是 已管的范围。

 - **D12 一句人话铁律（治 · 引自 `说人话` skill 「人话特征正反清单 + 改稿最小手术铁律」）**：

 **一、人话 8 个正向特征（写每段逐条对齐）**：
 1. 冗余即味儿：口语重复、filler、半截卡壳（"我觉得应该是这样的，我觉得应该那这样的"）、一正一反（"并不是…而是…"）都是真声，不是废话，**保留**。
 2. 具体名词和场景：用"错的人 / 大量时间感情 / 吃同事的瓜 / 老板画的饼"这种能放画面的词，不悬空。
 3. 情绪态度外放：带轻蔑（"不过是个假象"）、带斩钉截铁（"该止损时就得及时止损"）。
 4. 口语尾缀和标记：啊、的话、了吧、呢、嘛——活人的呼吸感，**保留不删**。
 5. 节奏逗号停顿："但是，这句话，"式主语后 / 转折处逗号，是说话的自然停顿，**保留**。
 6. 立场绝对化不稀释："只有一条""永远不可能"一个刃，不加"虽然但是"。
 7. 不端着不上课：典故随口带出（"这不就那句…嘛"），不单独供起来当升华。
 8. 连接词保留不抽干："的 / 了 / 是 / 会 / 却 / 只"全留，不抽成骨架，否则像机器人报数。

 **二、AI 不是人话的 4 个根因（写完逐条自查，命中即改）**：
 1. **把"改稿"等同于"提纯/缩短/工整"** → 用户让"优化 / 检查"，AI 默认动作是"更短更干净更对称"，正好和活人感反向。翻车例：把"努力工作，出卖自己的时间，是不可能致富的"改成"靠…你永远不可能致富"。
 2. **为"钩子感"硬加假转折** → "反而 / 却"无脑塞，但"舍不得花钱→难脱贫"是同向因果不是反差。
 3. **抽象大词悬空 + 权威替代痛点** → 用"通透 / 新认识 / 更深理解 / 含金量"糊弄，或"名人推荐"代替"你能治啥"。
 4. **把口语重复当错误删掉** → 训练目标"去冗余"与"活人感来自重复"正好相反。

 **三、改稿最小手术铁律（最重要 · "不动"是有条件的）**：
 - **A. 成熟稿**：当"检查 / 优化 / 分析"对象已成型，**默认一字不动**，只做两种手术：① 真·错别字 / 漏字（"的 / 地"混用、"常说得"→"常说的"）；② 真·卡嘴病句（断句逗号劈开句子）。其余原声、原节奏、原重复、原断句习惯全部保留。
 - **B. 薄稿**：补全场景——**主动用用户嗓音**填充：第一优先级从 IMA 调旧认知，加真实案例 / 具体场景 / 把论点展开，但**绝不趁机精简成 AI 工整腔**。语气、节奏、口语习惯、重复强调全部模仿用户。
 - **自检口令**："一个真实的人会对朋友这么讲吗？"——会，留；不会（像 PPT / 报告 / 机器生成），删或改。

 **四、本 skill 当前阶段专属"说人话"硬口径**（治 的本卡特化）：
 1. **速览卡 tdef / 概念卡 cone 必须"一句人话 + 有主语"**：每句都要能答出"谁，想/能/会/做什么"。❌"投入越多越挑剔，越少越广撒网"（无主语）、❌"愿帮谁，看基因上有多亲"（主语暗）、❌"父母想平分，子女想独占"（主语和宾语都简省）、❌"宁可误报，不能漏报"（主语暗）。✅"雌孔雀投入大，所以它必须挑；雄孔雀投入小，所以它可以广撒网"、✅"你愿不愿意帮一个人，看他跟你基因上有多亲"、✅"父母想把资源均分给所有子女，子女想独占全部资源"、✅"宁可误报，不能漏报"（这个本来就模糊对错，按）。
 2. **prose 因果链用"因为…所以…这就是"分步骤断开，不要一长串连写**：✅"烟雾报警器不是等着火了以后才响，而是在冒烟的时候就响了。**因为**漏报的代价是烧掉房子，误报的代价只是白忙活一场。**所以**，宁可误报，也不能漏报。**这就是**：宁可错杀，不要放过。"→ 三步：现象（什么时候响）→ 推理（漏报 vs 误报代价）→ 结论（宁可误报）+ 一句机制命题。❌"烟感不等确认才响，宁可误报，也不能漏报，漏报代价是烧房子，误报只是白忙活——宁可错杀不要放过"→ 三步糊成一句，看似严密但读着像机器报词条。
 3. **每句要有"主体"，不写零主语残句**：被字句、缺主语的并列结构、"X 是 Y，X 是 Z" 式标签化句法 → 全改成"谁 + 做什么 + 为什么"。每个 tdef / cone 写完后问自己"这句话去掉了谁？谁在做这件事？没说就是坑"——找不到就重写。
 4. **写作时不要"为了结构化牺牲人味"**：tdef / cone 这种一句话速览的场合，宁可一句完整判断 + 一个具体例子（"雄孔雀的大尾羽不是为了活命，是为了被雌孔雀选中"），也不要"投入越多越挑剔，越少越广撒网"这种伪精炼——读者乍看"对仗、工整、有结构感"，实际读完不知道谁挑剔谁广撒网。
 5. **prose 段落里"X，是 Y"式缩句要拆开**：❌"更多基因传给后代，胜者的特征在种群中越来越普遍"（"胜者的特征"是哪个？"越来越普遍"到底是什么趋势？没主体）→ ✅"更多基因传给后代，胜者身上那些在同性竞争中胜出的特征，在种群里也越来越多"（但保留"更多基因传给后代"也可以，因前文已点明"胜者"是"同性竞争中胜出的一方"，但更好是"胜出那方的特征在下一代身上越来越多"，让"特征"是"什么特征"更明确）。

 **绝对禁止**（治本）：
 1. tdef / cone 写无主语精简句（"X 是 Y" "A → B" "X 多 Y 多"）
 2. prose 把因果链 / 现象 + 推理 + 结论糊成一长串不断句
 3. 用"X 不是 Y，是 Z"代替具体展开（ 已治，此条协同复核）
 4. 把"具体的谁"压成"普遍的趋势/特征/机制"——读者读完不知道说的是谁

 > **本节来源**： ，总结出"不全等于不通"—— 把"该禁的词"禁得差不多了，但 D11 的"严谨科学语言"误升级成"机械工整语言"；下一轮必须用"说人话" skill 的 8+4+改稿铁律兜住。具体先行落地：tdef / cone 加主语（"雌孔雀挑剔是因为它投入大"），prose 用"因为…所以…"分句（烟雾报警器那段）。这一步是治 的本卡特化，不是替代 。

- ** 没把真实输入当输入**：上面 管"写出来别造词/别浮夸/别跑偏"，但用户第三次暴怒点出更前置的根——**我压根没把真实输入当输入**：不读原书、不读真实读者评论、不读用户给的素材，就凭记忆+AI习惯生成，于是"胡编乱造"。
 - **D16 写前输入闸门**：每次出书/改卡，**动笔前必须先把四类真实输入采齐、读完、内化**（详见 [references/input-pipeline.md](references/input-pipeline.md)）：
 1. **原书内容**（最高优先级）：`/book/info` + `/book/chapterinfo` + `/book/bestbookmarks`（全站热门划线 = 书里真实最狠的话）+ 用户自己划的 underlines/笔记。**章号/层级/最狠话必须来自真实返回，禁凭记忆编造**。
 2. **微信读书公开点评**：`/review/list` 真实返回——看真实读者怎么聊、哪些点最戳人、语气多接地气（人话活样本，对抗 AI 腔）。
 3. **豆瓣热评**：`WebSearch`/`WebFetch` 真实返回——跨平台验证读者共鸣点，补微信读书视角盲区（同样是得人话样本）。
 4. **用户已整理好的素材**（最高优先级·直接采用）：用户给的笔记/公众号/口述/成稿，**基本直接用**（原样或最小改写，不另起一套、不"润色"成 AI 工整腔）；零散想法→组织成用户自己的话，不偷偷换成我的表达。
 - **忠实总结规则（.2）**：热评/豆瓣/网络素材是"内部参考 + 人话校准"，不是可直接抄的交付物，需"做一定的总结"再内化；**总结必须忠实原意、不漂移、不加油加醋、不把读者观点伪装成作者观点**—。
 - **写前检查口令（全 YES 才许动笔）**：①原书内容拿到了？②微信读书点评读了？③豆瓣热评采了？④用户素材用上了？⑤四类交叉核对过？⑥热评总结忠实原意？**任一 NO → 先去采，不许动笔。** 这道闸门在"硬闸门 grep（一）"和"逻辑核查闸门（四）"之前——没输入，后面全白搭。
 - **D17 来源分层铁律**：写之前先给每个内容点定"层"，层错了全错：
 - **书里作者真传达的意思（正文/理论/结论）→ 进 s3 主线骨架 / s4 核心理论卡（作者的核心观点）**。例如"女人重资源地位非拜金""外婆比奶奶更愿带孩子（亲缘确定性）""进化无目的""收益>代价才被留"都是书里内容，进 s4/s1。
 - **书里没有、是热评/延伸出来的好思考 → 进 s5 核心价值（延伸思考）**。例如"石器时代大脑 vs 现代社会"是延伸反思，进 s5。
 - **序言/译者注/不反常识的发散 → 既不进 s3/s4 核心，也不硬塞 s5**。只有"确实很反常识、能带来思考"的发散才可进 s5，且明确标注是延伸、不代表作者观点。
 - 自检一句："这句话是巴斯在书里说的，还是我/读者在序/热评里说的？" 答不出属于哪层 → 先定位再写。
 - **D18 结构优先于数量**：内容不是越多越好，是"结构化梳理好"才好。相近主题**合并**、不机械扩卡：
 - **合并判据**：①看内容多不多（短就合并，不单独立卡）；②看跟谁更相近（归到最近的那类）。
 - 例：亲子冲突 + 两性冲突 同属"两方进化利益不一致 → 冲突"，合并成一张「冲突理论」卡，而非各立一张。
 - 反例（曾犯的）：把"中国序言贞洁"单列为跨文化核心结论 → 既非作者正文、又该归的层错，已删。
 - 自检："这节能和上一节合并吗？合并后信息丢了吗？没丢就合并。"
 - **D19 每段要有可见的"逻辑因果链"推进**：卡片不是词条陈列，是顺着因果一步步讲到结论。每节写完自问"读者读完能复述出这条因果链吗"——不能就是 在发作。具体五条硬指标：
 1. **每节开头先给"这一节要回答什么日常问题"**：不写"下面讲 X 机制"，写"比如父母催婚、同事攀比的冲动，书里怎么解释"——让读者一上来知道"跟我有关"。
 2. **因果链用"因为…所以…"分步断开**，不堆不连贯的内容：每个判断后面跟"为什么"（代价是什么 / 机制怎么来的），读者能顺着读、不跳脱。学孙子兵法"道天地将法"那种递进——一层推一层，不是并列罗列。
 3. **每段收尾一句"对读者有什么用"的判断**：不停在机制描述上，要落回"所以你下次可以…"。——没落"用"就是 。
 4. **禁"堆砌无价值内容"**：每写一段先问"这句话给读者带来了新理解或新方法吗"，没有就删。宁可少一节，不硬凑。
 5. **自检口令**："删掉这段，读者的理解缺了一块吗？" 不缺 → 这段是 的堆砌，删。
 - **D20 核心概念先定义再展开**：通篇用到"机制 / 冲突 / 广义适合度"等概念前，必须先用一句大白话点明"它指什么"，再展开。具体三条：
 1. **每个核心概念第一次出现，紧跟一句大白话定义**：如"机制就是'场景 → 行为'的固定连接""冲突就是两方进化利益不一致时起的拉扯"。定义句要能脱离书、对朋友讲得通。
 2. **整节讲一个新概念（如 s3 讲"机制"、s4 讲"冲突"），节首必须先定义**：不先定义就展开 = 读者读到结尾不知在讲什么（ 的原话）。
 3. **定义不造词**：用"场景 → 行为""两方利益不一致"这种书里本意的大白话，不造"信息加工装置""程序库""抽象本质"等 / 禁词。
 - 自检："读者读到这节一半，能说出这个核心概念指什么吗？" 说不出 → 定义句没写或写在太后面，前移。

### 三、生成前十一问（每写完一节，过一遍）

1. **这句书里真有吗？**（没 → D1/D2，查或删）
2. **这是我编的比喻 / 造的词吗？**（是 → D3/D4，删或改大白话）
3. **去掉它，信息少了吗？**（没少却"好听" → 是金句，D4 删）
4. **前面哪节已经讲过这句了吗？**（讲过 → D6，删或换角度）
5. **这句读着连贯吗？破折号 / 短句是不是把话切断了？**（是 → D7，破折号改逗 / 句 / 冒号，补连接词，连成自然段落）
6. **这张概念卡有结构件拎重点吗？**（纯文字墙 → D9，加 levels / mini-vs / tags / example / cline 之一，让重点一眼可见）
7. **s3 这条是论断还是"研究几类问题"？s3 用了统一 `.points` 样式吗，有没有自创样式或单列"作用/为什么"标签？**（前者 → D10，改成 `.points` 编号+红名+直写 prose；后者 → D10，砍研究过程细节改结论）
8. **s5 用了浮夸词族吗（/D15）？** 出声念"一个真实的人会对朋友这么讲吗"——"程序库/抽象本质/错配/用机制读人/工程师视角/道德牢笼"全禁；**s5 三条是不是三个不同主题+不同反常识+不同方法（/D14）**；**s5 ①是不是"生物进化的视角"不是"机制视角"（/D13）**。
9. **一句人话有主语吗、prose 因果分步了吗、tcard 标题居中了吗（/D12）？** tdef/cone 不写无主语缩句；prose 用"因为…所以…这就是…"分步；tcard 标题红字居中。
10. **这段有"逻辑因果链推进"吗（/D19）？** 是顺着"因为…所以…"层层递进、每节开头点明"回答什么日常问题"、每段收尾落回"对读者有什么用"；还是堆了一堆不连贯、无价值的词条？后者 = ，重写成因果链 + 删堆砌。
11. **核心概念（机制/冲突/广义适合度…）在展开前先给了一句大白话定义吗（/D20）？** 读者读到这节一半，能说出它指什么吗？说不出 → 定义句没写或写在太后面，前移。

> 2. 再逐节**出声读**每一段，按 7 步逐节判 PASS/FAIL——抓的是 grep 抓不到的语义问题（模糊因果、缺连接词、突然冒出的列表）。

> 4. 任一格 FAIL → 不 present，先改，改完重跑该节。
>
> 这道闸门抓的是"写完靠需求：这套失效机制：它把语义核查变成**强制、可见、逐节**的动作。进化心理学卡片首次启用即抓出 3 处历史漏网（编造 80% 数据 / SVG 残留口语标签 / 越传越广""越变越大"模糊词），证明它比事后骂可靠。

> **🔴 每次重写后必须复扫全部规则（复盘补）**：进化心理学卡片 曾把破折号压到 0，但 08-18 重写 s5/ prose 时没复扫这条，破折号涨回 42。教训：任何一段 prose 重写后，必须重新跑 grep（含破折号计数 <15）+ 朗读，不是只扫"刚改的那句"。

### 四-B、🔴 全军覆没预防清单 + 人话参照（复盘沉淀 · 执行前必过）

> 进化心理学卡片改了 27 轮，同一类问题反复犯。两份文件把 + 全部复发词族 + 强制闸门**浓缩成一份一次性给全的执行清单**，每次出书/改卡前必过：

- **[references/fc-prevention.md](references/fc-prevention.md)** —— 写前/写中/写后 15 条纪律 + 复发词族速查表（A-O 全词族，grep 必须 0 命中）。
- **[references/human-voice-refs.md](references/human-voice-refs.md)** —— 豆瓣 + 微信读书**真实读者原话**对照"AI 浮夸写法 vs 人话写法"，写 s5/概念卡的人话准绳。

> 核心认知：**禁词表是打地鼠、治标不治本**——同族新变种必漏（预先装载→预先装配、跑太快→机制在跑）。治本是"写前九问 + 出声念人话 + 写后强制跑闸门 + 贴证据"，不是再加禁词。

### 四-C、🔴 写前输入闸门（强制 · 没真实输入不许动笔）

> **这是 的落地机制，位阶高于一切"写出来再查"的纪律。**——根因不是"词"，是**动笔前压根没把真实输入吃透**。本闸门治这个：每次出书/改卡，**先采齐四类真实输入、读完、内化，才允许下笔**。

- **[references/input-pipeline.md](references/input-pipeline.md)** —— 写前四类输入的强制清单（①原书内容 ②微信读书点评 ③豆瓣热评 ④）+ 真实接口 curl 模板 + 忠实总结规则（热评不漂移、不编造）+ 写前六问检查口令。**每次动笔前必过，全 YES 才许写。**
- **四类输入的本质**：①是内容的唯一真值源；②③是"人话"活样本、用来对抗 AI 腔、校准重心与语气；④是用户已经想清楚的内容、最高优先级、基本直接用。
- **忠实总结铁律（.2）**：热评/豆瓣/网络素材是内部参考，不是交付物；需"做一定总结"再内化，但**总结不能脱离原意、不能加油加醋、不能把读者观点伪装成作者观点**——否则等于编造。
- **与"输入即素材，不是交付物"节的关系**：那节管"采到的素材怎么用（只内化、不当交付物贴出来）"；本闸门管"动笔前必须先采到（没采不许写）"。两者一前一后，合起来 = 输入纪律闭环。

### 五、交付前根因自检（代替"只扫禁词"· 新增）

> **与上面的逻辑核查闸门是同一件事的两层**：逻辑核查闸门是**强制逐节执行 + 贴证据**（治本），本节的"逐节朗读 + 语义自检"是闸门第 2 步的具体读法。两者合并执行，不是二选一。

present_files 之前，除了跑硬闸门 grep，还要**逐节朗读 + 语义自检**，专门抓 grep 抓不到的"新变种"：

- **读每句，问"这是书里内容，还是我编的？"** —— grep 不会标"预先装配"（因为它只禁"预先装载"），但你的眼睛会。凡是"读着像我在掉书袋/显得深刻"的，就是 / 的变种，当场改大白话。
- **专查"对仗/对称/格言"句式**：扫一遍有没有 `不是A是B` / `X≠Y` / `跟着X不跟着Y` / `一棵主干` 这类结构 —— 这些是 金句，grep 正则永远滞后，只能靠读。
- **专查"位置/出处"残留**：有没有"在序言/第X章/最后一章"漏网（grep 兜底，但读一遍更稳）。
- **专查"同一句换字重现"**：s2 和 s5、s3 和 s4 有没有重复论点。
- **专查"破折号滥用 / 断句感"**：通读 prose，数破折号是否过多（正常应 < 15 处且都是真插入）；句间是否有"所以/但是/而"承接；有没有"字字懂但连不起来"的碎句。这一条是用户 深夜补的——"我读了以后，我能知道这本书到底写了什么"才是可读性标准。

> **这一节的来源**： 用户就进化心理学卡片连发 9+ 张截图，从"浮夸比喻"一路骂到"造金句/造词/重复"，并要求"把底层根因找出来，不要总是禁词"。落地下一步动作：把"先锚定再下笔 + 生成前四问 + 交付前根因自检"作为**生成纪律**嵌进流程，禁词正则只做兜底，不再靠它治本。

## 必含四块（结构可灵活，这四块不可省）

1. **书籍定位**：hero 放「书名 + 作者·出版年 + 全称 + 一句红色钩子大字（bigq，标杆都有）」；第一个 section 正式讲"这本书到底在讲什么"——用红色 sec-title（如"这本书到底在讲什么"）+ 一段大白话讲清书的内容与核心判断，不展开论证。hero 不写"书讲什么"副标题。
2. **现实矛盾 / 旧观念（背景）**：这本书诞生时，社会或学界卡在哪个真实问题上；旧思路落到现实的**具体恶果**。为作者出场铺路。
3. **作者的核心内容与方法论**：全书逻辑主线，可因书调整结构（分支对比 / 时间线 / 问题→解法 / 概念树）。这是重心，每块配一个读者熟悉的例子。
4. **对读者的核心价值**：今天为什么还要读它、能拿走什么、能纠什么误区。可附"局限"一句收尾。

> 不同书结构差异很大，**不要硬套固定节数**。四块是"必出现的内容"，呈现顺序、是否拆 sub-section、用不用对比框/概念树，由书的特性决定。例：小说可偏"人物动机 vs 时代"；方法论书可偏"问题→步骤"；经济学书可偏"旧观念 vs 作者破局"。
>
> **节序硬律**：**第一节必须是「书籍定位 / 这本书到底在讲什么」**，先讲书的内容与核心判断，再引出"现实矛盾/核心误区/旧观念"。**不允许把第一节写成"一个错觉""一个误区""一种错误观念"**。可以把"核心误区"压缩进第二、三节，用 `.vs` 对比框呈现；但书的内容定位永远先于对误区的拆解。
>
> **书籍定位写法（校准）**：直白严谨、像纳瓦尔宝典那样直接陈述"书是什么 / 研究什么 / 核心判断是什么"，不绕路。具体三条：
> ① 避免"它不是讲 X，而是回答一个更底层的问题：Y"这类**模糊/废话式 framing**——直接说"它从 XX 角度研究 XX"就行，不要"回答一个更底层的问题"这种手挥。
> ② 领域 / 难题用**规范术语**（如生存、合作、择偶、育儿），不用口水化表达（"找吃的""躲开危险""挑对象"）——大白话可以，但要准确，不卖弄。
> ③ 核心定义一句话给清，核心问题单一化（见下面坑 2）。最后可加一句"一句话：……"收束（如纳瓦尔 s1 末尾"这不是一本成功学，而是一本讲清楚财富和幸福这两件事的底层逻辑的书"），让读者一眼抓到书的核心。
>
> **Hero 区硬律**：**Hero = 书名 + 作者·出版年 + 全称 + 一句红色钩子大字（bigq），到此为止。** 与标杆《国富论》《纳瓦尔宝典》《孙子兵法》完全一致（它们的 hero 都是"元信息三行 + 一句红色大字"）。**禁止在 hero 加任何形式的副标题、解释框、摘要、红字下面的展开说明**——不能把"这不是一本教你怎么选股的书……""它讲的是人与钱的关系……"这类内容塞进 hero。"这本书讲什么"是第一个 section（书籍定位）的职责，不是 hero 的。红色钩子大字（bigq）必须保留，不得删除；如果 bigq 本身已经是一个问句，hero 下面不要再跟任何回答或解释。

> **学理性书籍（学术教材/学科入门/经典理论）必含「主线骨架」+「理论/机制列表」节**。此类书的硬要求：除了四块结构外，必须有**一节显式列出"作者在全书到底研究了哪几类问题 + 解决了哪些理论"，让读者一眼看清书的骨架**。具体：
> ① s3 用**「主线骨架 / 这本书的章节地图」**这种标题（不要写成「核心主张」这种抽象节），按"问题→理论→关键机制→研究方法"四件套，每类问题 2-4 行说清作者研究了啥、用了什么理论、关键机制是什么、怎么验证。
> ② s4 开头必须列出**「N 个核心理论 / 机制」**清单（参考进化心理学 6 大理论卡：亲代投资/性选择/互惠利他/Hamilton规则/亲子冲突/烟雾报警器），每张卡 = 理论名 + 提出者 + 一句话定义 + 关键变量 + 例证。否则读者看完只看到一堆"现象"和"案例"，不知道作者真正在研究什么。
> ③ 标题和小标题必须用**机制名/理论名/作者名**（如「亲代投资：投入多=挑剔」），不要用"怕蛇不怕车"这种**反差梗/单一现象**做节标题——节标题要让读者一眼看懂"这是在讲什么理论/什么机制"，反差梗是案例不是机制。
> ④ 每个 sub-section 开头 sec-sub / sub-desc 必须**点出"作者研究的是什么、关键变量是什么、规律是什么"**，再展开论证；不要以"这一节回答一个很日常的问题"或"这一节讲讲生存"这种**框架过渡**开头——这种过渡没告诉读者任何实质内容。
> ⑤ **s4 顶部 N 张理论速览卡必须配 SVG 可视化**：每张 tcard = 标题 + SVG 图（机制对比/梯度/双向关系/进化选择，viewBox 0 0 200 120 左右，参考纳瓦尔宝典 ccard cfig 风格） + 一句话定义 + 关键变量。**视觉在前文字在后层层递进**——图让人"一眼抓到机制的结构"，文字再往下展开细节。SVG 和 tdef/tkey 文字直接重复就删文字（保留 SVG + 不重复的展开）。**做卡片前先打开纳瓦尔宝典 s4 顶部 6 张 core-cards，看它的 cfig svg 怎么画**。
> ⑥ **s4 顶部理论卡 3 列布局 + 概念卡 N 点列表必须有因果逻辑和过渡**：s4 顶部 6 张理论卡用 **3 列布局**（像纳瓦尔宝典 ccard repeat(3, 1fr)），不是 2 列——2 列每张太大太占空间。响应式：≤900px → 2 列，≤720px → 1 列。概念卡的 5 点/3 点列表必须：① **有过渡句**说清"由 X 机制，可以推出 N 个具体现象"或"维持 X 需要 N 项能力"，让读者知道这 N 点的来源和作用（不"突然冒出来"）；② **每点用"因为…所以…"完整因果链**，不"一会儿蹦一句"，不用"→ 决定""→ 反映"箭头式；③ **不堆叠学术词**（"是…的信号""反映…的能力"反复出现会拗口），用大白话直接说因果；④ **prose 不用模糊表达**——"往那个方向推""越选越夸张""越传越广"换成完整因果（"让拥有该特征的个体繁殖更成功，从而该特征在种群中越来越普遍"）。**做卡片前先打开纳瓦尔宝典看它的 3 列布局和概念展开方式**。
>
> ⑦ **s4 顶部 tcard 「标题 + 一句话简介 + SVG」三件套**。tcard = tname（标题）+ tdef（一句话简介灰字 like 纳瓦尔 ctag "投入越多越挑剔，越少越广撒网"）+ tfig（SVG）。删 tkey 当定义句、删 tfrom 当学者名。tdef 样式：font-size 19px、color muted、min-height 54px 像 ctag；**不**当"X 理论认为 Y"学术定义句写。**做卡片前先打开纳瓦尔 s4 顶部 6 张 core-cards，看它的 ctag/cfig 怎么写。**
>
> ⑧ **s5 价值=判断句，不"给"句**。每条 = 价值判断 + 一段展开（直陈读者读完应持有何种判断），**不**"给你XX"、"帮你把A变B"、不"给你的6个框架"。参纳瓦尔 s5「用钱投资而不是只消费」「管钱难在心态，不在智商」/金钱心理学 s5「钱是为了自由不是为了面子」那种直陈句式。
>
> ⑨ **prose / 对比框 / 例子框三不重复举例**。每个例子只出现一次：prose 举一个具体例讲完整因→果机制；对比框写抽象机制句（不重复举同一例）；例子框集中放社会版例（选美/肌肉/彩礼/雄鹿等）。**prose 讲机制 + 完整因→果链，对比框写抽象对比，例子框堆社会例——三个职责分开不重叠**。
>
> ⑩ **tcard/ccard 标题视觉宽度 ≤ 22**。中文按 2、英文/数字按 1 估视觉宽，> 22 算超行。超行精简为机制名（"情绪为什么总是过度敏感" → "情绪机制"），或改陈述句（去"为什么"）。**写完所有 tcard/ccard 标题横向扫一遍，超行的就改**。

> **s4 prose 段「不重复铁律」**：s4 内的 prose 段**严禁**重复 s3（主线骨架）+ 6 张理论卡里已经讲过的研究内容。具体口径：
> ① s4 内的 prose 段必须写**「用机制看清生活」类应用/反常识判断**（如"读完这一节你能用机制看懂自己/他人/职场/家庭里 X 现象"），不允许再描述"作者研究了什么、发现了什么规律"。
> ② 如果 s4 某节的 prose 段要写的内容跟 s3+6 卡已经讲过，**整段删 / 整节删**（本轮直接把 s4「亲代与亲属」整节删，因为内容完全被 s3 第 3/4 题 + 卡⑤/卡④ 覆盖了）。
> ③ s4 prose 段不允许出现"5 个反误解" / "5 个适应性问题" / "5 种能力"这种**研究目录式枚举**——这些是 s3+卡的工作。
>
> **位置指称禁**：卡片中**不允许**用「在第 X 章」「在第 X 卷」「在序言里」「在最后一章」「卷一」这类**位置指称**——只讲观点本身，不指点它在原书哪个位置。已加入硬闸门 grep 正则。
>
> **AI 造词大全**：
> ① **滑入 / 自动滑入**——这种"自动 XX"的结构是 AI 在凑字，不是人话。
> ② **预先装载的决策程序**——AI 在为"机制"造个比喻式词，禁。
> ③ **机制=倾向，要和环境共同决定行为**——AI 把两个短句硬粘成一句"X=Y，要 Z"，是废话组装，禁。
> ④ **`是`不等于`应该`**——AI 用"X 不等于 Y"造个金句，禁。**讲清机制 + 不为机制辩护**这个意思，直接说大白话"讲清楚机制，不是为它们开脱"，不要绕。
> ⑤ **一棵主干 + N 个分支** / **N 大独立话题** / **适应性问题→心理机制→行为输出**这种**框架过渡式语句**——读者要看的是内容不是框架图，禁。
> ⑥ **心理不是白板** / **不是白板**——废话，禁。
>
> **英文/公式规则**：专用英文术语（人名 Hamilton/Trivers/Darwin、术语名 DNA 等）可以用；但**英文公式 + 英文变量 + 不解释 = 必禁**——`Hamilton 规则 C<rB`、`r 越大`、`r 在排`、`C < rB` 这种"只丢公式不解读"的形式必须**用大白话同步解读**（"你愿不愿意帮人，看两件事——帮自己付的代价够不够小，对方跟你多亲"），不能只丢公式让读者自己猜。已加入硬闸门 grep 正则。
>
> **来源**：概念卡标题要一眼看懂、句式通顺、内容有实质价值。根因不是措辞，是**卡片只有案例陈列没有作者的理论骨架**。修法参考标杆卡片：用 s3 做主线骨架 + s4 概念卡做内容展开。
>
> **bigq 必须立读者真正在问的核心问题，不抢主线**：bigq（红字）应抛读者拿到这本书最想问的那个问题（如《金钱心理学》"到底什么是财富自由？"），让读者带着问题往下看，答案由正文给。书里某句金句（如"财务成功是软技能不是硬科学"）**只能作为正文里的一处原话支撑，绝不可反复提、更不可把它抬成全书主旨或 hero 主线**——否则会盖住书真正的核心问题，内容跑偏。判定标准：书里那句话是"一个支撑论点"还是"读者翻开书最想搞懂的那件事"？只有后者才配当 bigq。
>

> 经济不会因为消费而增长，是增长带动消费（作者原话） + 3 条大白话 pt（刺激消费/降息宽松/投资判断，每条用「政府发钱让你花，钱多了东西没多」「钱多了不会自动变出东西」「能不能真的帮你赚钱、还是只能赌后面有人出更高价接手」）+ 1 句带走的话（东西没多钱多了只是涨价，不是变富）+ 1 段局限。

> **反向参照（v3 翻车样本，已删除）**：作者原话 + 3 条 pt + `.vs` 大对比（消费者逻辑 vs 生产者逻辑）+ 1 句带走的话（问票多了还是鱼更多了）。问题：`.vs` 用了术语 + 「票/鱼」隐喻 = 拗口；「翻译到今天」段落结构 = 框架化胡编。

### 五、v5 关键修正：学习用户直白风格 ≠ 照搬短视频话术（**）

用户让 AI 去读他知识库里 9 篇原文、学他的风格，但**明确纠正**：那是写短视频脚本的风格，**书卡不能强套**。核心边界如下：

1. **可以学的（文风层面）**：句子短、不绕弯、不用抽象作词、把道理讲得普通人一听就懂、不故作高深。这是「直白」的本质。
2. **绝对不能搬的（话术/句式层面）**：
 - ❌ 「不是 A，而是 B」的硬反转开场（这是）
 - ❌ 「就拿 X 来说吧 / 拿你来说吧」之类的举例引导词
 - ❌ 口语脏话词（「」「」）、口语填充词（「说白了」「但是呢」「其实根本不是」「你想啊」）
 - ❌ 「啥意思呢？」这类口头禅式解释
3. **书卡本质是「严谨的内容讲解」，不是脚本**：内容必须准确锚定原书（真实划线/原话），可以举例，但例子要自然融入、不靠固定句式硬塞；不能为了「接地气」自编理财建议（如「每月工资 1 万先拿 2000 买指数基金」）或自造口语金句。
4. **自检一句准绳**：读一遍——如果某句话「只有用短视频口播腔才顺、换成书面讲解就别扭」，那就是话术，删掉；如果某句话「平实讲出来也清楚、不绕」，就是合格的直白。

> **标杆对照**：用户 9 篇原文（知识库 `sources/raw/0001~0009`）是「直白 DNA」的范本——多用具体场景、反常识落点、短句；但这些篇章本身是短视频脚本，**只萃取文风、不萃取句式**。

## 传记类专用结构（人物传记）

人物传记与普通方法论/经济学书不同：**读者最想看的是"这个人一生到底做了什么、为什么能成"，而不是"他在批判哪个旧观念"**。所以传记卡片**不套**"旧观念→破局"四块套路，改用下面这条时间线主轴：

1. **书籍定位**：照常（hero + 第一节"这本书到底在讲什么"），但定位要说清"这是谁、作者想通过他讲什么"——不是讲一本艺术史，而是讲一个好奇的人怎么活完一生。
2. **他一生的成就（身份 + 成就合并呈现）**：不要先罗列身份、另起一节再讲成就——这会把一个活人切成两块。正确做法是：中间放人物肖像小图，周围散落身份标签（画家/雕塑家/建筑师/音乐家/工程师/解剖学家/地质学家…），下面直接接带图成就卡片（绘画、人体解剖、工程发明、自然洞察、舞台与公共工程、笔记方法），用公共域/书中图片呈现关键作品（如《蒙娜丽莎》《最后的晚餐》《维特鲁威人》、飞行器手稿、解剖图）。
 - 标签统一风格：全部用**空心红框、红色文字、大圆角**，不要某个标签用实心红底；不要只高亮"画家"而把其他压暗。
 - 肖像图不要有内边距、背景层或双层边框——直接贴原图，最多加一层细边框。
 - 作品图必须真实可加载。**优先下载到本地 `assets/` 目录**，HTML 里直接引用本地路径。如果 sandbox 网络受限下不到本地，才允许使用稳定外链——但**严禁用 `onerror` 回退外链**（会造成先闪裂图再加载的糟糕体验）。禁止用 SVG 感叹号占位。
 - **图片必须按原比例完整显示**：成就卡片/时间线配图禁止用固定高度容器 + `object-fit: cover` 强行裁切成统一尺寸，否则竖图、横图、方图都会被截得面目全非。正确做法是容器高度自适应，或用 `object-fit: contain` 完整呈现；允许卡片高度不一致，不能为了"整齐"牺牲画面信息。
 - **图片必须与名称/说明严格匹配**：叫什么就配什么图。《维特鲁威人》必须配那个方圆中的人体比例图，不能配《三王来朝》；"胎儿解剖图"必须配子宫/胎儿研究手稿，不能配一般人体躯干解剖。下载后必须肉眼核对，张冠李戴比没图更糟。
 - **成就区布局要紧凑，别堆满大图**：不要把五六幅作品全部做成大尺寸画廊。竖版代表作可以缩小成 80~100px 小图，放在肖像两侧当视觉点缀；下面精选 2~4 幅最具代表性的作品用卡片呈现即可。避免某一张竖版画占据过大空间、破坏整体节奏。
 - **代表作只精选 3~4 张，禁止重复展示**：别在肖像两侧放一遍、下面画廊又放一遍同一张图。整个第二节最多出现一次《维特鲁威人》、一次《蒙娜丽莎》、一次《最后的晚餐》。精选 3~4 张最具代表性的名作/手稿就够了（如达·芬奇：蒙娜丽莎、最后的晚餐、维特鲁威人、飞行器手稿），其余研究手稿在时间线节点里提一句即可，不必在成就区反复贴图。
 - **成就区有效布局（已验证）**：人物肖像居中；身份标签云围绕肖像（上/中/下三行，标签红框空心红字、大圆角、无动效）；4 张代表作小图分列肖像左右两侧（左 2 张、右 2 张），竖版约 120px、横版约 190px，按原比例完整显示，上下用 `space-between` 贴边排布，caption 居中对齐。这个布局既信息密集又不拥挤，已被用户确认可用，传记卡直接复用。
3. **时代与处境（背景）**：他出生的时代给了什么土壤、他身上哪些"异类"身份反而成全了他（达·芬奇的私生子/左撇子/素食/易分心，在文艺复兴反而不被框死）。用书里真实背景，不脑补。
4. **一生关键时间线（核心内容，传记专属新模块）**：用 `.timeline` 竖线 + `.tnode` 圆点，按年份串起 6~10 个关键节点，每个节点必须按**故事结构**呈现，而不是信息罗列。每个节点固定拆成四步并编号：
 - **① 背景**：当时是什么情况；
 - **② 冲突/困境**：他遇到了什么难题、阻碍或选择题；
 - **③ 行动/转折**：他做了什么来应对；
 - **④ 结果**：最后怎样——只写事实，不写"教训"/"启示"/"人生哲理"。
 节点必须来自真实生平（微信读书章节目录/年表），禁编造年份。文字要少用大段散文，多用短句，多用"所以""但是""于是""结果""后来"等连接词，让读者能直接拿这段去讲成小故事。
 
 **特别注意**：
 - 第 ④ 步只写客观结果，不要写"这提醒我们……""真正的……不是……而是……""一个人……决定了他能……"这种 AI 腔大道理。
 - 不是每个节点都要硬编故事。去世、辗转谋生、没拿到项目等平淡节点，直接用几句陈述句讲完即可。
 - **时间线节点视觉必须统一**：所有节点共用同一个 `.tnode` 卡片样式，平淡节点也带左侧圆点，并用 `.ty`（年份/阶段）+ `.tt`（标题）+ `.plain-body`（陈述文字）的结构。禁止让"故事节点"和"平淡节点"出现两套不同的边框/标题/圆点样式，否则读者会误以为它们不是同一时间轴上的内容。
 - **时间线节点内不再重复配图**：如果第二节已经把代表作/手稿展示过，时间线里就不要在每个节点下再塞一遍小图。前面配图、后面讲故事，各司其职；重复贴图既占空间又没增量信息。
 - **故事结果要写完整，别只写到创作完成就停**：如果一个作品后来还有关键命运，必须带一句。例如《最后的晚餐》不能只写"颜料剥落"，还要写它后来经历战争、被改成马厩、二战时教堂被炸、画面震裂、几代修复师反复修补，今天我们看到的是残作；《蒙娜丽莎》不能只写"去哪都带着"，要点明"一拖十四年、改了又改、到死都没交给委托人"这个拖延结果。
5. **从他身上能学到什么（核心价值）**：**不要刻意拆成"思维方式 / 行为习惯"两块**——读者能自己区分，硬拆反而割裂。直接列 6~8 条能学到什么（达·芬奇来自作者最后一章"创造力密码"的清单：保持好奇、求知欲、一手信息、敢于质疑现有的结论、跨学科、拖延也有反面价值、记录习惯与独处），每条用书中原话支撑，正文直接陈述即可。时间线和学到什么之间不再单独设"跨领域成就"节——相关内容已合并进第二节。
6. **局限与提醒**：他自己的遗憾（拖稿/大量未完成）、后世心理分析脑补的提醒、传记是"他人眼中的他"。收尾点一句对普通人的最大提醒。

> **传记内容硬律（本轮）**：
> - **用书中高频原词，不得擅自改词**：书里通篇用什么词，卡片就用什么词。例：达·芬奇全书核心是"好奇 / 好奇心"，绝不可自作主张改成"惊奇"等近义词再当成概念标签——"惊奇"只可作书中原话引用（如"对日常现象感到惊奇的能力"），不可另立概念。任何"这个词书里没这么写、是我觉得更顺"的替换，一律禁止。
> - **时间线要故事化，不堆时间点**：每个节点不只写"XX年画了XX"，要写清前因后果、能讲成小故事（如蒙娜丽莎：为画微笑去停尸房解剖脸部肌肉、一画14年带去法国改到死从未交付；最后的晚餐：钻研光学制造视觉错觉、颜料剥落又经历战争轰炸和修复）。读者要的是能拿去讲的细节，不是背年表。
> - **句子要带连词，别写成断句清单**：少用"为了……；为了……""他去街上观察愤怒、怀疑、恐惧、忠诚各种脸"这种硬邦邦的并列。多用"为了……，他就……""而且……""可……""于是……""结果……""后来又……"这些口语连接词，让话能顺顺当当读出来，像讲故事而不是背条目。
> - **禁用生造书面词**："成说""迭代""赋予""追""远古"这类词要换成大白话。写完读一遍，如果自己这辈子都没听身边人这么说过，就改掉。
> - **禁止"书里写""原文写""书中提到"等元话语**：引用书中原话，要么直接加引号（如"列奥纳多的研究方法植根于实验、好奇心"），要么用作者名/"作者提出"（如"艾萨克森写：……"）。绝不允许出现"书里写：""原文写：""书中提到：""书里还有一句"这类把"书"当客体的外部指涉——用户给的书内容是用来内化的素材，不是卡片正文里要被点名的对象。
> - **传记仍必须遵守全局硬律**：Hero 不写副标题、第一节必须是书籍定位、bigq 立读者真问题、禁卷章指称、交付前 grep 闸门照扫。时间线节点、"学到什么"的具体点、身份/技能清单，全部来自微信读书真实内容（章节目录/年表/热门划线/bestbookmarks）与真实书评，不凭空编造。`.timeline` / `.tnode` / `.ccard` 的 CSS 已含在 `assets/template.html` 与《列奥纳多·达·芬奇传》样板，直接复用即可。

## 🔴 传记卡必死红线清单（基于《达·芬奇传》12 轮复盘 · 动笔前逐条过）

> 这 22 条是做传记卡时**反复踩、用户反复怒**的坑。每一条都是"必死红线"——不是建议，是交付前必须逐条自检、0 违例才许 present 的硬约束。它们散落在上面各节，这里汇总成一张表：动笔前扫一遍、写的时候对照、交付前再扫一遍。**最容易犯、最招骂的是第一类（内容/语言），尤其是第 2 条"元话语"——达芬奇传里反反复复犯，根因就是 grep 闸门正则漏了这些词，现已补进「交付前硬闸门」正则（`原文写|书中写|书中提到|成说`）。**

### 一、内容 / 语言类（最容易犯、最招骂）

1. **不得擅自改词**：书里通篇用什么词，卡片就用什么词。达·芬奇全书核心是"好奇/好奇心"，绝不可自作主张改成"惊奇"等近义词另立概念（"惊奇"只可作书中原话引用）。任何"书里没这么写、我觉得更顺"的替换一律禁止。
2. **禁止"书里写/原文写/书中提到"等元话语**（🔴 头号反复翻车点）：引用书中原话，要么直接加引号（"列奥纳多的研究方法植根于实验、好奇心"），要么用"作者提出/艾萨克森写"。绝不允许出现"书里写：""原文写："「书中提到：""书里还有一句"这类把"书"当客体的外部指涉。用户给的书内容 / 划线 / 热评 / 公众号笔记，是**给我内化后重新组织语言**的输入素材，不是卡片正文里要点名的对象。引用 ≠ 标注出处。
3. **热评 / 豆瓣 / 用户公众号笔记 = 输入不是交付物**：这些只用来理解读者、校准重心、补充素材。绝不作为一节贴进卡片（不要"读者 Joe 说"），也绝不点名"你那篇公众号"。
4. **禁用生造书面词 / 拗口短语**："成说""日日""随手打通""笔记成了他一生的外脑""困住""成硕"这类书里没有、读着绕的词一律不写。写完逐句问"书里有原话吗？普通人能秒懂吗？"确定性低于 100% 的短语默认不用。
5. **句子必须带连词、不断句**：少用"为了……；为了……"硬邦邦并列。多用"为了……，他就……""而且……""可……""于是……""结果……""后来……"以及"的、了、就、而"。像讲故事，不像背词条。
6. **第④步只写客观结果，禁"教训 / 启示 / 人生哲理"**：不写"这提醒我们……""真正的……不是……而是……"。
7. **禁刻意升华 / AI 腔**：不写"答案其实很朴素""贴标签决定机会""晚年自由是有人为好奇买单""笔记成了外脑"这类书里没有的拔高。只陈述事实。
8. **"学到什么"直接用书中原话清单**：达·芬奇来自作者最后一章"创造力密码"的清单，每条挂书中原话（加引号），不自己编 8 条新说法、不硬拆思维 / 行为两块。概念名称用大白话："求知欲"而不是"追问这是什么为什么"，"一手信息"而不是"一手实验"，"记录习惯"而不是"笔记本记录"，"拖延"而不是"容忍分心"。
9. **不要刻意跨书关联**：跨书关联必须基于书中**明确对应**的概念，不能硬扯角度相通。达·芬奇的"跨界身份"和纳瓦尔"身份不单一"只是弱相关，不要写进卡片或图谱。如果两本书没有直接对应的论点，宁可 `related_books: []`，也不强行凑关系。

### 二、结构 / 故事类

9. **时间线必须故事化**：每个节点写清 背景→冲突→行动→结果，能讲成小故事（蒙娜丽莎：为画微笑去停尸房解剖脸部、一画 14 年改到死没交付；最后的晚餐：钻研光学、颜料剥落又经历战争轰炸修复）。禁"XX 年画了 XX"信息罗列。
10. **平淡节点不硬编故事**：出生、少年学画、罗马时期、赴法、去世等，直接几句陈述讲完即可，不套四步。
11. **故事结果要写完整**：作品后来有关键命运的必须带一句（《最后的晚餐》战争 / 马厩 / 二战被炸 / 修复；《蒙娜丽莎》拖延十四年、改了又改、没交付）。
12. **身份与成就合并成一节**：中间肖像 + 周围标签云 + 下面带图成就卡。绝不先罗列身份、另起一节再讲成就。
13. **"学到什么"不硬拆思维 / 行为两块**：直接列 6~8 条，读者自己能区分。

### 三、视觉 / 图片类

14. **图与名称必须匹配**：下载后肉眼核对。维特鲁威人 = 方圆中的人体比例图；胎儿图 = 子宫 / 胎儿研究手稿。张冠李戴比没图更糟。
15. **作品图真实可加载、优先本地**：下到 `assets/` 直接引用本地路径；禁 SVG 占位、禁 `onerror` 回退外链（闪裂图）。
16. **图片按原比例完整显示**：禁固定高度 + `cover` 裁切（竖 / 横 / 方全被截）。容器高度自适应或 `contain`，允许卡片高度不一。
17. **肖像完整、直接贴原图**：完整显示不截头；一层细边框，无内边距 / 无背景层 / 无双层边框。
18. **第二节不重复贴图**：代表作只精选 3~4 张（蒙娜丽莎 / 最后的晚餐 / 维特鲁威人 / 飞行器手稿），两侧 + 画廊不重复出现同一张。
19. **时间线内不再配图**：第二节已展示作品，时间线只讲故事。
20. **标签样式统一**：全部空心红框、红字、大圆角、无动效；不某个实心红底、不只红"画家"。
21. **时间线节点视觉统一**：全部用 `.tnode`（带左圆点 + `.ty`+`.tt`+`.plain-body`），禁 `.tnode`/`.plain-node` 两套样式混用。
22. **图片按原比例分别定宽**：竖版约 120px、横版约 190px，caption 居中、上下贴边排布；不统一宽度导致横竖方全一样宽看不清。

> **自检口诀（每次交付前默念）**：改了词没？写了"书里写/原文写"没？贴了热评/划线墙没？造词了没？断句了没？第④步写教训了没？图对得上名没？图裁了没？重复贴图了没？——十个"了没"全否，才许交付。

## 立场纪律：只讲书本身，不拉外部旁支（最高频翻车点）

卡片的本职是"把**这本书**的价值讲清楚"，不是"评点别人怎么讲这本书"，也不是"借书谈自己的文章/公众号"。这条是反复踩坑后的头号硬律——一旦飘出去，内容就丢了焦点、还显得浮夸。

### 0. 输入 vs 交付物：用户划线 / 热门划线 / 书评 = 输入素材，永远不准直接陈列

**这是用户反复强调的硬性纪律，必须刻在流程里：**

-"看热门划线""看这本书的划线"，是让我用这些真实内容来**理解书、校准重点、补例子**。
- **绝不是**把划线原句原封不动贴成一节"热门划线墙""很多人划下的句子""读者评论""划线Top10"塞进卡片。
- 卡片定位是"我自己学习整理"的 visualization，不是"看别人划了什么"的展示墙。
- 所有划线、热门句、书评必须在消化后，**化为卡片自己的陈述、对比框、编号列表、关键词标签、例子**；禁止以"被划得最多""划线人数""很多人划"等理由直接陈列他人原句。
- **硬闸门已加入**：`热门划线|很多人划|划线墙|被划最多|人划过|热门书评|读者评论|划线人数`——HTML 交付前必须 grep，命中即删。

### 1. 禁引与书无关的外部旁支

不要写"市面上讲这本书多半在聊……""你那篇公众号也写到……""你的角度 / 你写的……""别人怎么样、别人说……"。这些既偏离书本身，对读卡片的人（包括自己日后回看）也毫无信息量。用户给的笔记 / 公众号 / 划线是**组织书内容的素材**，不是卡片里要被指名点出的对象——卡片里不该出现"你公众号提到"这类指涉句。

### 2. 可以融入用户观点，但必须落在书里

用户提的个人视角、理解、公众号里的判断，可以作为"组织线索"或"收尾落点"揉进内容；但**每一处都要能对应到书里的某个真实观点 / 例子 / 原话**。不能凭空引申成书里没讲的东西（如把书没写的"女生爱买包"当结论），也不能把书里没有的浮夸表述安到书上。
- **抓书的核心内容，不堆叙事**：重点放在"这本书到底讲了什么、为什么火、对读者有什么用"，而不是铺垫别人怎么解读、背景罗列一大堆却说不清重点。
- **不夸大、不虚浮**：用具体机制 + 例子 + 书里原话说话，不堆 AI 味虚词（如"几乎没动过你的内部配置""像一面镜子照出……"这类要换成书里的真实表述或具体例子）。
- **少写元话语**：卡片不是批注，不要反复出现"书里原话（序言）点题""书里点破""书里点明""书里说要……"这类提示。直接把原话化为正文，或仅在极必要时出现一次"作者的原话是"；主体内容应当是直接陈述和判断，而不是"书里写了什么"的二次搬运。
- **自我校验一句话**：写完每一节问自己——"这句话是书里的内容 / 原话 / 合理引申，还是我飘到书外去了？"凡是飘出去的，删掉或收回书内。

> 单知识点学习卡另有规定：书里的观点与「我的理解」是**严格分开**的两块（见该节），那是"自用笔记"的场景；而本知识卡片（全书可视化）是面向读者的"书的内容重构"，立场必须锚定书本身，不把用户个人感想当正文。

## 语言铁律（最高优先级）

写给"没读过这本书的人"，每条都过一遍：

- **语文地基：标点与口语节奏（比 AI 套话更底层的翻车点 · 最高频返工源）**：AI 写中文最隐秘的错不是夸张比喻，而是**按术语逻辑断句、不按人说话的节奏断句**——读着"每句语法都对，但就是不像人话"。这是整轮迭代里用户反复抠的最底层问题（逗号、连接词"就"、句号硬断），每次交付前必须逐句朗读自检：
 - **句号别硬断连贯句**：两处讲的是同一件事的延续 / 递进 / 顺承，就该用逗号连成一句，不要硬用句号断开让读者"咔"一下重启。✅"越往下**就**越基础，人在满足底层的需求后就会……"是一个顺承整体；❌"越往下越基础。人在满足……"用句号一刀切断，断气、生硬、像词条罗列。
 - **口语递进句必带"就"**：凡是"越X越Y""只要X就Y""一X就Y"这类口语递进结构，"就"一个字不能省——"越往下**就**越基础"漏"就"读着就拐、别扭；"底层不满足上层就塌"同理。
 - **自判标准**：母语者顺口是第一标准，不是语法正确。读完某句觉得"停顿不对 / 接不上 / 像机器报词条"，就是标点或连接词错了，当场改顺——不要想"语法没错就放着"。
 - 这条与「连接词必须显式出现」「完整句禁碎句」是同一件事的三个角度：节奏（标点）、黏连（连接词）、完整（禁碎句）。三者都要过。
 - **双重否定/病句自检（每次写否定句必过）**：句子里出现"没/不"这类否定词时，先按"双重否定表肯定"把整句翻译一遍，确认不是在说反话、不是在造病句。❌"没人会失去理智"="没(人)(失去)理智"=双重否定→肯定"所有人都是理智的"，既不像人话、也歪曲原意（书原意是"别轻易评判别人不理性"，绝非"人人永远理性"）。写之前先问：这句否定到底要表达什么？如果否定堆出荒谬的肯定，就换正面说法（用"别轻易说…/在XX看来都合理"），或直接去掉否定。
- **大白话、用具体例子**：抽象概念必须配一个读者生活里见过的例子（工厂打螺丝、水便宜钻石贵），不堆术语。
- **禁用抽象词/AI 造词**：禁"增进福祉""托起整体""底层框架""民生困境""撬动认知""自发出清"这类端着或空泛的词；抽象概念不用具象动词/拟人比喻（"财富长出来""动力锁死"）。直接说机制+例子。
- **用大白话、禁用 AI 禁词/缩词**：知识卡片是给活人看的，不是写论文。严格执行 [references/ai-banned-words.md](references/ai-banned-words.md)。特别记住："嗜甜"是 AI 禁词，一律改"喜欢甜食"；"追"必须写成"追求"；"换物"必须写成"换东西"；标题和正文都写完整，不省略。读者一眼能懂、朗朗上口优先。
- **完整句，禁碎句/断句**：禁用"标签：词"当句子（如"财富的来源：分工"），必须写成完整判断句（"财富来源于社会分工"）。每句有主语、谓语、结论，不堆超短句让读者补主语。
- **连接词必须显式出现（句子级）**：每段至少带"所以/但是/而不是/比如/原因是/结果就是/也就是说/于是"等连接词；读完卡、跳、断处就地改顺。
- **板块之间必须承上启下（板块级 · 最高频翻车点）**：上一个板块收尾，不能直接"咔"一下跳到下一个板块的新逻辑。要在收尾或开头用一句明示两条逻辑怎么接——顺接（"讲完作者怎么看 X，接下来自然要问：普通人能拿来做什么？"）/ 转折（"上面说的是原理，但落到现实很多人卡在第一步——"）/ 悬念（"讲到这你多半会想：具体怎么开始？这正是下一节"）。新概念第一次出现，先在上一句铺垫"它指的是…"，不凭空冒出。
- **举例必须说完整因果**：不能只抛例子没下文，要交代"比如…，原因是…，所以…"。禁"很出名""众所周知"等默认读者已知的话。
- **禁用引用性元话语（第X章/第X卷/小节名/页码/书里原话标注/公众号来源/正如书里所说）**：卡片呈现的是"作者的核心观点和内容"，不是"这本书的目录结构"或"我读了什么资料"。禁止出现"第8章/第10章""车里的男人""书里原话（序言）点题""书里点破""书里点明""正如公众号所说"这类把读者注意力引向原书某处或外部来源的元信息，也禁止用"先定义清楚""书里原话"这类批注式标签。直接陈述观点，偶尔引用原话时只保留双引号内的一句，不标章节/出处/原话属性。
- **正常叙述中的"书里"可以保留**："书里举了一个扣针工厂的例子""作者提出了"这类不带引用指向、只是叙事口吻的表述，不属于禁用范围。关键区分：这句话是在**陈述内容**（可保留），还是在**标注出处/章节/来源**（必须删）。不要一棍子打死所有"书里"。
- **少用卷章指称**：尽量不用"卷一/卷二/第一章"这类需要前置知识的指称，直接说内容；必须用时要先说明"书中第一部分讲的是…"。
- **禁用论文式过渡词**：不要写"这正好接上…""由此引出…""反观…""落脚到…"这类学术写作里的过渡表达。同一主题内直接一句人话说完，跨主题时只用"所以/但是/也就是说/换个角度看"这类口语连接词。
- **对比框必须嵌入相关内容，不单独开一节"关键对照"**：凡有对照（旧 vs 新、A vs B、看见 vs 真实），直接放在对应概念下方，不要攒到末尾单列一节"关键对照"。对比是论证工具，不是独立章节。
- **核心价值不写"带走""作手册""理心"等 AI 腔**：总结节直接说"几个最值得记住的点"，每点是一句完整判断；禁用"它最该带走的三点""这本书写的是'理心'，不是'作手册'""知足、存钱、留容错"这种标签化缩句和 AI 造词。
- **引用书里原话加双引号**；解释原话用大白话，禁"这句话被反复高亮""用户不理解"这类莫名其妙的话。
- **禁止强行造 AI 味金句**：不编造书中没有的对仗/比喻式"金句"来"升华"（如"金钱只是财富的衣服，劳动才是财富的血液"）。没有原话支撑的排比、拟人、格言体一律不写；想强调观点，用具体例子或一句大白话说清。
- **禁用噱头/狠话**：卡片是陈述书里的重点，不是做营销标题。禁写"最狠的判断""藏在最后""戳破真相""一个被低估的真相"这类吊胃口式铺垫；直接讲内容，重点靠标红/加粗呈现，不靠夸张措辞吊人。
- **最高铁律：不自己造拗口短语（本轮头号翻车点）**：任何一句话，如果书里没有对应的原话/原意，且你写完后觉得"读起来有点绕、像在掉书袋"，就**立刻换成大白话**—宁可啰嗦清楚，绝不用伪精炼。典型反面（均已踩坑）："把'人数'堆起来""宇宙里并没有它们""别把人类很厉害自动当成我一定过得好""给了合作的能力（缺主语）"。完整清单见 [references/ai-banned-words.md](references/ai-banned-words.md) 第七~十四节。自判标准：写完逐句问"书里有原话吗？没有的话普通人能秒懂吗？"确定性低于 100% 的短语默认不用。
- **《金钱心理学》整轮复盘后新增的高频禁区（都已在 ai-banned-words.md 落成具体词表）**：
 - **禁中英混杂**：中文卡片里不夹英文词（greed→贪婪、peer 压力→身边人的比较），专有名词也给中文；书里确有英文概念用中文译名。详见禁词库第九节。
 - **禁自造术语替代书里已有定义**：书里已有现成词（如"财富自由"），不许 AI 另造近义词（如"真正的富裕"）显得高级。详见禁词库第十节。
 - **禁前言不搭后语的断裂罗列**：一句话前半讲 A、突然用"因为/还能"跳到不相干的 B（如"看不出你多有钱——因为钱还在账户里，还能换成选择权和自由"），必须写成一句完整连贯的人话。详见禁词库第十一节。
 - **禁同一事实两处重复（滥竽充数）**：核心内容展开过的点，核心价值/其他节不要再讲一遍；核心内容负责论证、核心价值负责收束判断，分工不重叠。详见禁词库第十二节。
 - **禁抽象空话/标签化缩句**：总结节不写"行为比知识管用""钱是为了自由""知足、存钱、留容错"这类正确但无信息的废话，要写成带例子或机制的完整判断句。详见禁词库第十三节。
 - **禁论文式过渡词**：不写"这正好接上…""由此引出…""反观…""落脚到…"，同主题直接一句人话说完。详见禁词库第十四节。
- **因果必须顺、原因归位**：论述书里的机制时，原因要归到书里讲的机制本身，不能把现代现象倒因为果（如讲"控制不住吃高糖高脂"，因是远古稀缺下的保命本能，不是"今天超市有这种食品"）。每个"所以"前后逻辑要真接得住，不跳步、不偷换概念。
- **标题与标签写完整句**：章节标题、概念标签、对比框标题都禁用缩略/省略，必须主谓完整。❌ "只认金银是财富" → ✅ "认为金银就是财富"；❌ "市场：自由运行" → ✅ "市场可以自由运行，但也有局限性"。
- **配图不要写成文字**：图本身足以说明的，不要加"每个节点下面都配了一张示意图""上图解释了…"这类自说自话的解释句；图文重复时优先保留图。
- **图示只承载简短示意，完整逻辑交给下方 prose（新增硬律）**：概念卡 `.cdesc`、对比框 `.vd` 只写一句话核心判断或短标签，不展开例子、不塞完整因果链。例子和"为什么"的解释放到图示下方的 prose 里；图里已经用了的例子，prose 不再复述，而是讲逻辑。后续补充新内容优先加 prose，不要往图里塞。
- **颜色必须清晰可读**：旧观念/次要模块不用浅褐色，统一用深棕 `#6A6058` 或红色 `#E0432E`，确保导出长图、手机、公众号都清晰。
- **图示与文字同频**：概念图对比项保持同一描述顺序（如「水：有用·便宜」对应「钻石：用处小·贵」）；流程图必须画出可读的因果链，禁止抽象循环；图内文字分两大行、字号足够，确保导出长图不截断。
- **信息一位置**：同一事实只在一处讲透，不各处重复。
- **全书最狠的判断/核心结论，放在最后收束，不要开头就抛完**：第一节「书籍定位」只讲"这本书在讲什么"，可以点出作者的核心判断（如"社会进步了，但人本身没怎么变"），但**不要**在第一节就把"基因的进化速度赶不上文化发展的速度""进步不等于幸福"这类全书结论展开论证；这些结论要在「核心价值」或最后一节作为"读完后带走的东西"再落一次，读者才有"从了解内容到获得判断"的递进。
- **引用作者观点：区分"作者提出"与"作者认为"**：
 - **默认用 `作者提出` / `作者说` / `赫拉利说`（具体作者名）**——这表示用户**认同**该观点，是"作者说出来、我也认可"的语气。
 - **`作者认为` / `这是作者的观点`**——仅用于用户**不太认同、想保持距离**的观点，相当于"这只是他一家之言，不代表我"。
 - 简言之：同意→提出/说/具体作者名；不同意→认为/这是作者的观点。**不要反过来用。** 禁用 `书里说`/`书里还有一句`/`书中提到`（把注意力引向"书"这个外部客体，不直接）。
- **只讲书本身、不拉外部旁支**：见「立场纪律」一节。不写"市面上 / 别人 / 你公众号 / 你角度"等偏离书本身的指涉；用户观点只能作为组织线索揉进**书内**内容，不能凭空引申成书里没有的结论；重点放在书的核心内容本身，不堆无关叙事。

更细的禁忌词表、各书结构示例、微信读书调取流程见 [references/content-spec.md](references/content-spec.md)。

## 通用易漏红线（多书复盘沉淀 · 经济 / 思维认知类尤其注意）

下面这些坑在《经济学的思维方式》多轮整改里反复出现，规则层面已散落各处，这里集中一条，动笔前逐条过：

1. **作者名只在 hero / 作者列 / 引用观点时出现**：章节标题、概念小标题、正文不写"XX 的核心主张""XX 认为"——改成中性"核心主张""作者认为"。合著书 hero 写"保罗·海恩 等"即可，书名号外的章节不重复作者名。
2. **书籍定位节：先定义、核心问题单一化**：第一节必须先给书的核心定义（如"经济学是一门关于选择的学问"），核心问题只能是一个、且来自书本身，不擅自拆成"东西不够 / 钱不够 / 时间不够"多个问题，不啰嗦。
3. **概念卡只干一件事，不掺无关框**：一个概念卡只承载该概念（定义 + 本质 + 对比 + 例子），不写"做人的启发""生活感悟"这类与书无关的框；跨书联想 / 生活应用放独立模块。概念边界清晰：比较优势的例子不要混写"机会成本"（那是另一个概念卡的事）。**合并重复时金句不能丢**：用户要求把"小标签 + 正文 + 核心原则框"合成一段时，金句（如"沉没成本不参与重大决策"）必须保留进合并后的段落——合并是消冗余框，不是删观点。曾因"合并"把金句整句删掉，用户怒批，务必保留。
4. **经济 ≠ 股市（认知偏差红线）**：局限 / 应用表述按书实际视角写——微观经济学讲个人决策，局限是"不能预测宏观经济环境变化"，绝不是"不能预测股市"。不要把经济学窄化成炒股；全卡"股市"只能出现在"常见误解"节作为被反驳的反面例子。
5. **局限性 / 边界样式对齐标杆**：底部"这本书也有边界"用灰色 `.indent`（带左边竖条），与国富论 / 纳瓦尔宝典一致，不可加黑、不可改深色、不可自造比喻句。
6. **Hero 红字一句话、可一行显示**：红色钩子大字只放一句戳心判断，能一行显示完（必要时去掉句末句号防折行），不堆长句、不加副标题（副标题属于第一个 section）。书若有"天下没有免费的午餐"这种现成金句，Hero 只放最凝练的一句（如"天下没有免费的午餐，任何选择都是有成本的"，去句号防折行）；把"成本不是你花了多少钱，而是你为了这个选择放弃了什么"这类展开与定义，放到核心主张第一节——不在 hero 堆长句。
7. **配图 SVG：对称、具象、箭头对齐**：有对照的图，箭头 / 标记必须对称对齐（同 y 坐标、共用 marker）；流程图画可读因果链，不画抽象循环、不用看不懂的抽象箭头。机会成本 / 沉没成本这类抽象概念要具象成生活场景。
8. **Tab / 组件样式走 CSS class，禁止内联 style 覆盖交互态**：直接套 `assets/template.html` 的 `.tab` 写法（`.tab:hover` 变红边红字、`.tab.active` 红底白字 + 光晕）。曾因 tab 全用内联 `style=""` 把 hover / active 效果顶掉，务必避免——任何交互态（hover / active / focus）都走 class，不写内联 style。

## 素材来源（三种输入）

1. **用户给笔记/划线/核心信息** → 提炼后按四块归位。
2. **用户给部分书摘或整本框架草稿** → 按语言铁律逐句修顺、补结构。
3. **只给书名（没读过也没笔记）→ 速读模式** → 调微信读书公开接口取真实重点（见 content-spec.md 的「速读模式」流程：`/store/search`→`/book/info`→`/book/chapterinfo`→`/book/bestbookmarks`→`/review/list`）。章号/层级必须来自 `/book/chapterinfo` 真实返回，热门划线必须来自 `/book/bestbookmarks` 真实 `markText`，**严禁编造**。

> ### 🔴 输入即素材，不是交付物（最高频翻车点，本轮）
> 凡是我去抓的「微信读书热评 / 豆瓣书评 / 读者评论 / 用户自己的公众号·笔记·口述」，**全部是 INPUT（给我看的参考资料），不是 OUTPUT（给你看的交付物）**。
> - **书内热门划线（bestbookmarks 的 `markText`）** = 书的正文内容 → 可引用，加引号、归作者/书中人物。这是书本身，合法。
> - **热评 / 书评 / 读者评论**（微信读书 `/review/list`、豆瓣短评长评）= 他人观后感 → **只作内部参考**：用它判断"读者最被什么戳中、什么点最共鸣、我该把重心放哪、语气怎么接地气"。**绝不作为一节贴进卡片，绝不出现"读者 Joe 说"这种呈现。**
> - **用户给的公众号 / 笔记 / 口述** = 用作组织线索与素材 → 可融入，但**不点名"你的公众号/你写的那篇"**（那是偏离书本身的指涉，违反立场纪律），也不照搬成卡片正文；揉进书内内容去呈现。
> - **一句话铁律**：你让我去看热评/豆瓣/划线，是给我"理解读者、校准内容"用的；我呈现的卡片，只该有书本身的内容重构。把热评直接贴出来 = 把你的参考资料当成交付物，等于没干活。此条优先级高于一切"显得素材丰富"的冲动。

## 工作流

0. **🔴 写前输入闸门（强制 · 最高优先级）**：动笔前先跑 [references/input-pipeline.md](references/input-pipeline.md) 的"写前六问"——采齐 ①原书内容（`/book/info`+`/book/chapterinfo`+`/book/bestbookmarks`+）②微信读书公开点评（`/review/list`）③豆瓣热评（WebSearch/WebFetch）④用户已整理素材。**六问全 YES 才许进下一步**；任一 NO 先去采，不许凭记忆生成。这是 的落地，位阶高于一切"写出来再查"。
1. **确认输入类型并查索引**：先确认输入类型（笔记 / 书名 / 草稿）。若是书名，先看书单里有没有它；没有就按「无本地笔记模式」从微信读书/网络采内容并新建 `你的书籍库/{书名}/` 文件夹。
2. **取素材**：有笔记直接用；只给书名则跑速读模式拿真实数据（见 content-spec.md 速读流程）。
3. **定结构**：按书特性选四块的呈现方式（对比框 / 概念树 / 时间线），对照 template.html 搭骨架。
4. **写文案**：先写 Hero 红色钩子大字（bigq，一句戳心问题/判断）→ 四块正文，全程过语言铁律与「立场纪律」；只讲书本身、不拉外部旁支（禁"市面上/别人/你公众号/你角度"指涉），引用原话加引号、用大白话解释。**Hero 不写"书讲什么"副标题（那属于第一个 section）。**
5. **画概念树/箭头**（如用）：节点增减同步改 `<svg>` 的 path 与坐标，箭头沉底、不穿框、终点留 20–25px。
6. **朗读自检（逐句出声读）**：不仅要查板块之间承上启下（见 content-spec.md 表达三铁律），更要**逐句按人说话的节奏出声读**——凡读到某处"停顿不对 / 接不上 / 像机器报词条 / 漏了'就'这类口语连接词"，就是**标点或连接词错了**，当场改顺（见上面「语文地基：标点与口语节奏」条）。这是整轮迭代最高频的返工源，务必过。
7. **落盘 + 预览**：新建独立 HTML 文件（**绝不覆盖 `cards/` 下已有的标杆卡片**），写 `<项目>/.workbuddy/...` 或用户指定位置，present_files 打开预览，正文也贴关键结论。

## 导出长图规范（截图铁律）

把 HTML 渲染成 PNG 长图对外分享时，按以下铁律执行：

- **高亮 Tab 必须落在「核心内容」**：红色高亮（`.tab.active`）必须是读者重点所在的「作者的核心内容与方法论」那一块，不是「核心主张 / 破局」节。国富论里即 `#s5` 核心内容；其他书对应"四块第③块"的 Tab。原因：长图要帮读者一眼锁定重点，主张/破局只是铺垫。
- **做法**：生成一张截图专用临时 HTML（复制主文件得来），注入脚本 `DOMContentLoaded` 后强制只把目标 Tab 设为 `active`（如 `t.classList.toggle('active', t.getAttribute('href')==='#s5')`），渲染完即删临时文件，**绝不污染母版**。
- **画质**：系统 Chrome `--headless=new --screenshot`，`--force-device-scale-factor=2` 出 2x 高清；按背景色 `#FBF6F0` 检测裁剪底部空白，收尾干净。
- 若系统 Chrome 在沙箱里崩溃，可改用已安装的 Puppeteer + 系统 Chrome（`--no-sandbox --disable-gpu --disable-dev-shm-usage`），但优先复用系统 Chrome。
- 截图前建议给 HTML 注入 `.no-anim` 类（opacity:1）并移除/容错网络字体，避免动画未触发或字体加载超时导致空白图。
- 1x 轻量版可选，但**默认交付 2x**。

## 小红书多图拆分规范

如用户要把知识卡片直接发布到小红书，在单张长图之外再提供竖图拆分：

- **比例**：3:4 竖图（宽:高 = 3:4），画布 1080×1440，**默认导出 2x**（2160×2880）。
- **张数**：一般 2-4 张。把 Hero/背景/破局放第一张，核心主张+核心内容前半放第二张，核心内容后半+核心价值放第三张；内容特别少可 2 张，特别多可 4 张。**分块不是死的**：如果按「前半/后半」分导致某页太空、某页溢出，要动态调整，把价值/局限等模块挪到合适页面，让每张图都饱满且不截断。
- **顶部**：去掉网页版 tab 导航和冗余图标条。每张图顶部只保留章节标题，底部可加小页码（如「①/③」）。
- **图标/概念图分布**：概念小图、SVG 示意图必须随正文出现在对应图片里，不要全部堆在最后一张，也不要单独做个「图标区」。
- **字号必须手机可读**：拆图不是网页，用户是在手机小屏上看。标题 ≥36px，正文 ≥22px，卡片说明 ≥18px；浅灰字不要小于 18px，否则费眼。**字号、内容完整、单页不溢出三者冲突时，优先保内容完整和可读，宁可加页也不要硬压字号或删实质灰字。**
- **删冗余，保实质灰字**：拆图每一句都要有用。删除的是重复铺垫和自说自话的图注，例如「18 世纪欧洲各国追求的强国之策，反而让老百姓越过越差」「两套观念，一个只认钱、一个只认地」；但「第一/第二」下面的具体说明、概念卡解释、价值卡描述、引用白话解释等**有信息量的灰字必须保留**，不能一刀切全删。
- **两套产物的内容标准不同，别混**：**① 小红书拆图（发平台、短传播）**——只把内容讲清楚、克制。核心问题用「一个国家，究竟靠什么变富？」这种提问抛出就够了，**不要展开"国民财富=国家财富、不是个人存款"这类私下探讨式解读**，也删掉"当然也有局限……"这类评价尾巴，避免影响手机端阅读。**② 长图母版（学习/收藏用）**——内容要完整，局限段、背景说明、尾注都保留，**不要按拆图标准去删**。两者互不污染：改拆图不碰母版尾注，改母版也不把拆图的删减逻辑带进去。
- **卡片收紧**：卡片高度按内容自适应，不要预留大段空白。左右对比卡、概念卡、价值卡都紧凑排布，让整图饱满。
- **SVG 文字不漂移**：手写体 SVG 在部分渲染环境（如 Ardot）里文字位置容易偏。拆图建议直接用 HTML + CSS + SVG 画好后用 Puppeteer/Chrome 截图，字号、坐标、对齐都更可控。导出时禁用缓存、等待字体加载或做好 fallback，同一套 CSS 连跑两遍验证，避免字体未加载导致尺寸漂移或截断。
- **霞鹜文楷不用伪粗体**：霞鹜文楷这套字体只有 Regular 一个字重，CSS 里写 `font-weight: 700` 会让浏览器强行合成粗体，结果某些字（如"矛盾"）会异常加粗、颜色变深。标题和强调全靠**字号大小 + 颜色对比**来分层，整页统一 `font-weight: 400`。
- **SVG 节点大小一致、颜色克制**：流程图/概念图里同类节点必须一样大，不要某个框突然变窄或变形。颜色不要为区分而硬换，同一流程的节点尽量用一种主色，避免视觉零碎。
- **母版同步**：拆图里改动的样式（如「资源分配」框等宽同色、霞鹜文楷不用伪粗体）要回写长图母版（若本仓库未含，可跳过），避免母版和拆图版本不一致。
- **长图母版字号也要 PC 可读**：母版不是只给手机看，PC 端正文建议 ≥22–25px、章节标题 ≥34–40px、概念卡说明 ≥18px。可按拆图版的放大逻辑整体上调一档，避免 PC 端看正文还费劲。**但顶部 Hero（书名、作者、全称、核心问题、tab 导航）不要同比例放大**，避免 tab 换行、头重脚轻；把放大预算留给正文内容。
- **风格一致**：拆图沿用原长图的纸张色、霞鹜文楷字体、暖红强调色、手绘边框，保持视觉统一。封面的视觉体系见下方「小红书封面设计」专节（封面用思源黑体而非手写体，且必须嵌入实体书封面图）。
- **交付**：每张图单独导出 PNG，命名如 `<书名>-小红书-图1.png`。

## 小红书封面设计（与拆图同交付线）

封面目的：0.3 秒让人停下来，且一眼知道是"哪本书、什么视角"。它和拆图是同一本书的两件交付物，视觉体系保持一致，但封面的任务是"钩子 + 识别"，不是把书内容铺出来。

**协作分工（重要）**
- 用户：提供这本书的**实体书封面图片**（高清正封），并确认主题方向。
- AI：基于书的核心内容**想出 2–3 个标题方案**（锚定书真核心，见下），用户选一个后落地成设计。

**标题铁律（踩坑后的硬规则）**
- 标题必须**从书的真核心长出来**，不能从热点痛点库硬拽一个流行焦虑再贴书名（例：把"越努力搞钱越穷"安到《国富论》上 = 标题党，已被否）。正确钩子应是书里真实存在的反常识 / 真问题，如国富论的"金钱就是财富吗？"——它开篇就在批判"金银=财富"。
- 标题用**提问或反常识陈述**最稳，并给出明确价值承诺（如"一分钟读懂《国富论》"）。
- **不做"书的目录页 / 简介页"**：不堆"社会分工 / 看不见的手 / 政府边界"这类内容条目，也不放学术长问句。

**版式（极简，三要素）**
- 实体书封面图 = 视觉主角之一，居中或偏下摆放，让人一眼认出书。
- 主标题：书核心相关的强钩子（如"金钱就是财富吗？"），红色 `#E0432E` 强调，约 100–110px。
- 副标题：价值承诺（如"一分钟读懂《国富论》"），墨色 `#201914`（**别用浅灰，信息流缩图后看不清**），约 55–60px。
- **克制**：不放顶部品类标签、不放底部作者背书长句、不放大段解释。信息流里图很小，字必须少而大。

**视觉 / 技术**
- 画布 1080×1440（3:4），**默认 2x 导出 2160×2880**。
- 背景纸色 `#FBF6F0`；可加一块浅暖色大圆弧 `#EFE0D8` 托住书图，破除"飘在白纸上"的空旷感（v3 验证有效）；顶部可加一条极细红短线 `#E0432E` 做锚点。
- 字体用思源黑体（Source Han Sans CN），单一字体；强调靠字号 + 颜色分层。
- 工具：Ardot 直接做（封面用思源黑体可控，无需手写 SVG）。资源图先 `register_assets` 拿上传 URL，再 `upload_images` / `batch_edit` 填 IMAGE fill。
- 导出后**立即**下载 2x PNG（签名会过期，别隔太久再下）。
- 可复用母版（Ardot 文件）：`714138355415683`（《国富论》封面定稿，含书图 + 红标题 + 浅暖圆弧），新封面以它为版式参考，但**内容必须按新书重做**。

## 单知识点学习卡（个人自用 · 极简）

用途：用户**自己读书学习 / 做笔记**用，一张卡只钻书里的**一个观点或方法论**，不是发平台。和拆图（短传播）、长图母版（全书的广度）、封面（钩子+识别）是**不同交付线**：学习卡追求"深度 + 自用"，要**极简**，不要社媒那套传播装饰。

**信息块（最小集，四块）**
1. **书名 + 基本信息**：仅「书名·作者·年份」一行，轻量；**不放封面大图、不放品类标签**。
2. **观点主题**：一句话标签（如「劳动分工」），**不是钩子句、不是「全书第一命题」这类过度修饰**。
3. **书里的观点**：必须是**书里的原文/原话**，带出处（章/节），给可信度；**不要把用户自己的感想、转述、理解放在这里**。如果不确定原文，宁可写「待补原文」+ 出处，也不能编造。
4. **我的理解**：放用户自己话 + 真实认知（可带跨书关联思考），这是个人壁垒，要写**深**，不是浅翻译。用户没给时留待填口，不要替用户编。

**可选**：**关联 / 对比** —— 和其他书里相近或相反的观点做对照笔记（留白即可，自用卡常在这里串联多本书）。

**明确禁止**（踩坑后硬规则）
- 禁钩子句（如「为什么有人一天只干一件事反而赚得最多？」）、禁场景举例、禁金句区、禁互动/CTA、禁「全书第 X 命题」等修饰、禁顶部品类标签、禁底部署名长句。
- 一句话原则：**只留「书名 + 基本信息 + 书里的观点 + 我的理解」，顶多加关联/对比**。其余都是废装饰。

**视觉 / 技术**
- 沿用统一体系：纸 `#FBF6F0`、墨 `#201914`、暖红 `#E0432E`、线 `#6A6058`、霞鹜文楷 LXGW WenKai；单一强调色，紧凑卡片，可打印 / 夹进书里。
- 观点用浅红底 + 左红边引用块；出处小字灰；我的理解正常正文；关联区用虚线分隔留白。
- 工具：HTML 模板即可（如 `国富论-单知识点卡片-劳动分工.html`），无需 Ardot。
