# 书籍分类匹配（book-category-classify）

把任意书单（微信读书导出 / 用户手改清单 / 卡片梳理结果）准确归入 **15 大类**，边界符合大众普遍认知，并能**迭代版本（Vn→Vn+1）不丢失用户删除**。

> 本 skill 是分类逻辑的**唯一真值源**。详版边界规则在 `skills/book-core-points/references/classification_rules.md`（living document），本文件是它的可移植精简版 + **迭代纪律**（后者是 RC306 反复翻车后固化，最贵）。

## 一、何时用

- 用户给一份书单要你分类 / 校验分类
- 用户说"基于 Vn 出 Vn+1" / "重新梳理" / "上一版已经删了一些"
- 你拿不准某本书该归哪类
- 校验一份分类清单本数对不对

## 二、15 大类（一句话边界 + 标杆）

| # | 类 | 一句话边界 | 标杆 |
|---|---|---|---|
| 1 | 思维认知 | 思考/认知/思维方式/心智模型/逻辑/批判性思维/思辨方法（思考是大事，水平思考/结构化思维/心智模型/发散思维都归此） | 穷查理宝典、金字塔原理、学会提问、认知操纵 |
| 2 | 底层规律 | 大众科普·世界普遍底层规律（宇宙/生物/物理/进化/历史宏观/社会运行） | 枪炮病菌与钢铁、人类简史、时间简史、物种起源 |
| 3 | 人性洞察 | 非学术派应用向人性解码（贪嗔痴/盲从/操纵/群体），作者多为作家/商人/记者/文化评论 | 乌合之众、影响力、理解人性 |
| 4 | 经济与商业 | 如何做生意/做投资/看市场（创业/经济学/商业/金融/营销/管理/传播/广告） | 国富论、贫穷的本质、聪明的投资者、浪潮之巅 |
| 5 | 财富认知 | 你和金钱/财富的关系、搞钱心态（≠ 经济，≠ 具体投资操作） | 纳瓦尔宝典、富爸爸穷爸爸、金钱心理学、小狗钱钱 |
| 6 | 心理成长 | 心理疗愈/人格成长/自我理解（心理学/CBT/疗愈，非决策/学习） | 蛤蟆先生、自卑与超越、心流 |
| 7 | 决策避坑 | 决策陷阱/常见错误/认知偏误/风险判断 | 黑天鹅、反脆弱、灰犀牛、思考快与慢 |
| 8 | 习惯养成 | 个人日常可操作的行为设计（好习惯/复利/自律），不收行业/现象考据 | 掌控习惯、福格行为模型、微习惯 |
| 9 | 能力提升 | 可迁移技能（学习/阅读/写作/演讲/记忆/领导力/谈判） | 刻意练习、如何阅读一本书、卓有成效的管理者 |
| 10 | 人际关系与沟通 | 沟通/谈判/人际/亲密/冲突/边界 | 非暴力沟通、关键对话、强势 |
| 11 | 名人传记 | 单一人物传记（含核心方法/理念），非多人物集合 | 史蒂夫·乔布斯传、曾国藩传 |
| 12 | 成事方法 | 可迁移做事方法论/原则体系（不含商业创新/创业） | 孙子兵法、好战略坏战略、精益创业 |
| 13 | 哲学思辨 | 哲学命题/哲学史/思辨（含逻辑哲学命题），作者是哲学家归此 | 理想国、中国哲学简史、逻辑哲学论 |
| 14 | 文学经典 | 故事性统一大类（小说/散文/诗歌/戏剧/寓言），不细分不外迁 | 百年孤独、1984、卡拉马佐夫兄弟 |
| 15 | 历史 | 历史事件/人物/制度/考据史 | 史记、资治通鉴、全球通史 |

> **永远 15 类一字排开**。曾经翻车把 15 报成 13（漏算【人际关系与沟通】和【成事方法】）——再犯直接自抽。

## 三、用户三条铁律（最高优先级，压倒一切）

1. **经济归经济、财富归财富**：国富论→经济；纳瓦尔/富爸爸→财富认知；价值投资方法论（巴菲特类）→财富认知。
2. **心理边界**：心理学科应用于"心理疗愈/人格成长/自我理解"→心理成长；"非学术派应用向人性解码"→人性洞察；别把决策/学习/CBT 当心理。
3. **底层规律只收大众科普**（揭示世界普遍运行规律），不塞心理学/社会学/知识论。

## 四、四条边界铁律（实战补正 · RC306 截图纠错固化）

| 铁律 | 归哪类 | 反例/正例 |
|---|---|---|
| 理性 / 认知科学 / 创新思维 | **思维认知** | 《超越智商》（斯坦诺维奇讲理性 vs 智商）、《离经叛道》（格兰特讲原创思维）→ 思维认知；不讲商业 |
| 传播学社会经典 / 社会运行规律 | **底层规律** | 《舆论》（李普曼大众传播经典）、《娱乐至死》《想象的共同体》→ 底层规律 |
| 瘾品史 / 行业史 / 现象考据史 | **历史** | 《上瘾五百年》（烟酒精鸦片 500 年考据）→ 历史，不归习惯养成 |
| 逻辑哲学命题 / 逻辑学哲学 | **哲学思辨** | 《逻辑哲学论》《哲学研究》（维特根斯坦，哲学家）→ 哲学思辨 |

> **简单判别句（永久）**：作者是哲学家 → 哲学思辨；作者是逻辑学家/认知科学家 → 思维认知。
> 通用逻辑学/逻辑工具/批判性思维（《简单的逻辑学》《逻辑学讲义》《逻辑与批判性思维六部曲》）→ 思维认知。

## 五、六大易混雷区（拿到书先对照）

1. **思维认知 vs 决策避坑**：教"怎么思考/认知模型"→思维认知；教"避错/识别陷阱"→决策避坑。
2. **底层规律 vs 思维认知**：客观规律科普（系统论/演化/宇宙）→底层规律；思维工具书→思维认知。
3. **人性洞察 vs 心理成长**：应用向人性解码（作家/记者案例）→人性洞察；心理学/疗愈/CBT→心理成长。
4. **财富认知 vs 经济与商业**：钱的态度/搞钱心态→财富认知；做生意/市场/企业→经济与商业。
5. **成事方法 vs 经济与商业**：可迁移做事原则（孙子兵法/好战略坏战略）→成事方法；创业/创新/商业模式→经济与商业。
6. **历史 vs 底层规律 vs 文学**：历史考据/制度/事件→历史；普遍规律科普→底层规律；故事叙事→文学经典。

## 六、分类决策 SOP（拿到一本书走一遍）

1. 读书名 + 副标题 → 定大方向。
2. 看核心主题/关键词首词 → 命中某类"该入信号"≥2 个 → 归此类。
3. 两个类都命中 → 看书的**核心方法论**而非例子 → 落唯一一类。
4. 都不命中 → 查豆瓣/作者背景定性，不瞎编。
5. 拿不准 → 走第五节雷区对照，仍不确定报用户拍板。

> 文学书统一归【文学经典】，不外迁到人性洞察（故事性优先）。【思维认知】是思考总类，关键词含思考信号不该被迁走。

## 七、迭代版本工作流（Vn → Vn+1）★ 最高频翻车点

> RC306 核心教训：用户在你生成的 `data/书单数据源.md`（或旧版 `书单数据源-vN.md`）上**直接改**（删书/调类），改完就是最新真值。你出 Vn+1 必须基于改后的文件，**绝不能凭自己记忆里的旧数重写**——否则用户删的书又被你加回来，他会一遍遍重删。

**生成 Vn+1 的死步骤**：

1. **先 `Read` 当前磁盘上 `data/书单数据源.md` 真实文件**（不是凭记忆）。用户改过的就是最新。
2. **用脚本从文件抽取书名**：正则 `^\s*\d+\.\s*《(.+?)》` 逐类抽，自然继承用户所有删除。
3. **标题写的数字一律作废**：清单标题写"639""596"都不算数。**跳号 = 已删**（用户删书后序号不连续），按实际《》出现数实算。
4. **绝不补回任何用户删的书**：不翻旧数据、不瞎猜、不要求用户另建文件/给删除清单——用户在对话里贴过的最新版就是输入。
5. **15 类一字排开必数对**：生成后跑 `references/verify_count.py` 校验：类别数=15、总本数=各类之和。
6. **应用修正**：在抽出的基础上调类/排序，写新版 `书单数据源.md`（或 `书单数据源-v(N+1).md`），旧版备份到 `.pre-v(N+1)/`。
7. **回复里贴的数字先从文件实抽**，不嘴说旧数。
8. **【v8+ 新增】真重复扫描**：最终化前跑 `references/check_dup.py <书单数据源.json>`，**同 author + 短 title 是长 title 子串 + 长度差 ≤5** 必报"真重复"——典型如《思考，快与慢》v《思考》（卡尼曼）。**保留长名，删除短名**。脚本会误报系列两本（如影响力 v 先发影响力、汉书 v 后汉书），由用户拍板"系列/真重复"。

```bash
# 校验一份分类清单
python3 skills/book-category-classify/references/verify_count.py <文件.md>
# 直接从文件抽书名生成 Vn+1 的骨架（继承删除，不补书）
python3 skills/book-category-classify/references/extract_titles.py data/书单数据源.md
# v8+ 真重复扫描（重点：是否同一本被写成不同 title）
python3 skills/book-category-classify/references/check_dup.py data/书单数据源.json
```
