# 书籍知识图谱 · 使用说明（小白版）

这份说明是写给**完全没有技术基础**的人看的。你不需要会写代码、不需要碰终端、不需要配任何环境。所有作就一件事：**把一段文字发给 WorkBuddy，剩下的交给它处理。**

下面一步一步来。

---

## 一、这个技能到底是干嘛的？

一句话：把你读过的书，变成一张张能看的「知识卡片」，再把书和书连成一张「知识图谱」，让你读过的东西不再忘、还能发现书与书之间的关系。

具体解决四件事：

1. **读书总忘** —— 每本书被整理成一张可视化卡片，重点一眼看清，随时翻。
2. **书是孤岛** —— 图谱把相关的书自动连起来（比如读《穷查理宝典》会牵出《国富论》《思考，快与慢》），你一眼看到「原来这几本在讲同一件事」。
3. **主题性阅读** —— 读一本时，图谱告诉你「想搞懂这个，还得去看看那本」，顺着关联读，形成主题阅读，而不是东一本西一本。
4. **知识沉淀** —— 你后面有新感悟、新笔记，随时往里加，越用越厚，最后变成你自己的私人知识库。

---

## 二、这一大套里，包含哪几个小技能？

你装的其实是一套「组合包」，里面有四个能单独用的小技能，WorkBuddy 会按需要自动调用：

| 小技能 | 干啥用 | 你感知到的样子 |
| --- | --- | --- |
| **知识卡片** | 把一本书做成一张可视化网页卡片 | 打开一张像手绘笔记的卡片，分块讲清这本书 |
| **提炼要点** | 从一本书里抽出 2~4 个可迁移的核心关键词 | 每本书在图谱里只留最关键的几个词，不啰嗦 |
| **知识图谱** | 把书 + 概念连成一张可缩放的知识图谱 | 一个能搜、能筛选、能点书名的互动网页 |
| **总控工作流** | 把上面三步串起来，一键跑完 | 你说一句「帮我处理这本书」，WorkBuddy 全自动走完建卡→提要点→建图 |

你不用记这些名字，只要知道：**一个入口，WorkBuddy 全部搞定。**

## 四、第二步：装好后你得到什么？先学会「用」

装好之后，WorkBuddy 会**在本地给你生成一个网页文件（HTML）**，你双击就能在浏览器里打开，以后随时看。

打开后你先看到的是**示例内容**，里面已经放了 3 张做好的知识卡片做示范：

- 《国富论》
- 《人类简史》
- 《纳瓦尔宝典》

知识卡片长这样（以《国富论》为例）：

![国富论知识卡片样式](./examples/assets/国富论-知识卡片.png)

> 说明：示例网页里除了这 3 张完整卡片，还预置了 200 多本书展示它们之间的关联，让你一眼看懂「图谱长什么样」。等你拉入自己的书，WorkBuddy 会自动生成**属于你的**卡片。

### 这个网页你能干什么？（功能先讲透）

1. **搜索** —— 顶部输入框打书名或关键词，直接定位到书。
2. **按分类筛选** —— 点左侧分类（比如「思维认知」「经济与商业」「心理成长」），只看这一类。
3. **点书名跳转** —— 点任意一本书，弹出它的知识卡片，看清这本书讲了啥。
4. **双击空白回全景** —— 看累了，双击页面空白处，镜头回到整张知识图谱的全貌。

先把示例玩一遍，熟悉这几个动作，后面你自己的书进来后作一模一样。

想重新打开网页，直接跟 WorkBuddy 说：

> 提示词：帮我把书籍知识图谱网页在本地打开

## 五、第三步：怎么基于「你自己读过的书」来用？

示例看明白后，就轮到把**你自己的书**弄进来了。有两路，看你习惯哪种。

### 方式一：连微信读书（在线自动拉，最省事）

适合你平时就在微信读书里看、有划线笔记的人。

**第 1 步：让 WorkBuddy 连上微信读书**

> 提示词：帮我连接微信读书助手，拉取我读过的书

**第 2 步：拿到你的微信读书 key 发给 WorkBuddy**
WorkBuddy 会引导你授权。你也可以自己点这个地址生成 key，然后把那段 key 发给 WorkBuddy：
`https://weread.qq.com/r/weread-skills`
（打开后按页面提示生成，复制那一串 `wrk-xxxx` 发过去就行）

> 提示词：我的微信读书 key 是 wrk-xxxx（把 xxxx 换成你生成的），帮我拉取我的读书记录和划线

**第 3 步：拉完之后，让 WorkBuddy 帮你处理**
读书记录拉回来后，你不用自己整理，分三步交给 WorkBuddy：

> 提示词 1（提炼要点）：帮我把《［书名］》的核心要点提炼出来，按书籍知识图谱的格式存好
>
> 提示词 2（做卡片）：帮我把《［书名］》做成知识卡片，用国富论那种现成样式
>
> 提示词 3（进图谱）：把《［书名］》加进知识图谱，连上它相关的书

三步发完，这本书就进你的知识图谱了。

### 方式二：自己读的书（纸质书 / 没在微信读书里）

适合你读纸质书、或者想自己梳理的人。你只要把书名 + 你记的关键信息发给 WorkBuddy，由它来提取。

> 提示词：我读了《［书名］》，下面是我记的读书笔记和关键信息：（把你的划线、感想、摘抄贴在这里）。帮我提炼要点，并生成一张知识卡片，再连进知识图谱

如果你暂时没整理笔记，也可以只给书名，让 WorkBuddy 先按通用框架搭一版，你后面再补：

> 提示词：帮我把《［书名］》先做成一张知识卡片草稿，我之后会补具体内容

## 六、第四步：你要「改」的时候，怎么改？

用一阵子后，你想按自己的口味调整，也一样用「说话」完成。下面列几个最常改的场景。

**场景 1：改知识卡片的样子（每个人阅读风格不同）**
比如你不想分成四块，想换成「一句话总结 + 三个金句」。

> 提示词：把《［书名］》知识卡片的结构改成：开头一句话总结，下面只列 3 个最戳我的金句，不要分块

**场景 2：改卡片里的内容**
比如某句话你想换成自己的大白话。

> 提示词：《［书名］》卡片里第 2 点，改成「……」（写你想要的版本）

**场景 3：改书与书的关联**
比如你觉得某两本不该连、或该连却没连。

> 提示词：把《［书名 A］》和《［书名 B］》在图谱里连起来（或：在图谱里断开）
>
> 提示词：图谱里《［书名］》应该还连《［相关书名］》，帮我补上这条关联

**场景 4：删书 / 加书**

> 提示词：把《［书名］》从我的知识图谱里删掉
>
> 提示词：帮我把《［书名］》加进知识图谱（然后用第五节的方式做卡片）

**场景 5：想看 WorkBuddy 都存了哪些文件**

> 提示词：我的书籍知识图谱相关文件都在哪？帮我列一下，并告诉我哪个能改

（你手边还有一份《书籍核心要点清单》，长这样，你可以直接在里面增删改要点：）

```
《国富论》  核心要点：分工提高效率 / 看不见的手 / 自由贸易
《人类简史》  核心要点：认知革命 / 虚构故事 / 农业陷阱
《纳瓦尔宝典》  核心要点：杠杆 / 专精度 / 复利
```

上面只是示例的三行，你自己的清单会随着书越加越多，由 WorkBuddy 帮你自动维护。

## 七、最后：让它变成你自己的知识库

第一次可能只加了三五本，不用急。关键是**养成习惯**——

- 每读完一本，跟 WorkBuddy 说一句「帮我把《XX》加进知识图谱」；
- 哪天有新的感悟，跟 WorkBuddy 说「给《XX》卡片补一句……」；
- 想找某个主题的书，直接搜那个词，图谱会把相关的书都拎出来。

慢慢你会发现：原来你读过的书，早就悄悄织成了一张网。这就是「主题性阅读」和「知识沉淀」——读书不再读完就忘，而是一点点长成你自己的东西。
