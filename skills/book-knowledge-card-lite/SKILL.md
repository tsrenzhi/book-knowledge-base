# 书籍知识卡片

## Overview

把一本书做成**一张能直接看懂的网页卡片**：读者打开就能抓到"这本书在讲什么、卡在哪、作者怎么破、对我有什么用"。

产物是一个**自包含的单文件 HTML**——双击即开，不依赖网络、不需要服务器、不带任何外部请求。你可以把它丢进任何笔记、博客、网盘，或者直接发给别人。

本 skill 只做一件事：**把一本书做成一张卡片**。它不维护书单、不做多本书之间的关联、不生成索引页。产出的每一张卡片都是独立完整的。

> **独立性**：每张卡片自给自足。做完一本，跟上一本没有任何牵连；删掉哪一张，别的也不受影响。

## 核心样板（不可覆盖 · 强制预读）

动手前**必须先打开这两个文件照着做**，不要凭印象写：

- `assets/template.html` —— 版面骨架与样式白名单，**制作知识卡片就在这个文件上改**
- `assets/sample-国富论.html` —— 标杆成品，看它怎么分节

## 何时用

- 用户给了一本书（书名 / 读书笔记 / 划线 / 口述看法）→ 出一张知识卡片 HTML。
- 用户已经有卡片，要改内容或改样式 → 仍走本 skill 的"交付前自检"。

## 卡片 ≠ 文档（动笔前先想清身份）

| | 卡片 | 文档 / 笔记 |
|---|---|---|
| 目标 | 让人**一眼看懂**这本书 | 让人**读完记住**细节 |
| 篇幅 | 一屏能扫完，讲主干 | 可以长 |
| 写法 | 大白话、短句、有例子 | 可以铺陈 |

**不要**把读书笔记原样搬进来，**不要**写成长篇摘要。

## 必含四块（结构可灵活，这四块不可省）

1. **书籍定位**：hero 放「书名 + 作者·出版年 + 全称 + 一句红色钩子大字」；第一个 section 讲"这本书到底在讲什么"——用红色 sec-title + 一段大白话讲清书的内容与核心判断，不展开论证。
2. **现实矛盾 / 旧观念**：这本书诞生时，社会或学界卡在哪个真实问题；旧思路落到现实的**具体恶果**。为作者出场铺路。
3. **作者的核心内容与方法论**：全书逻辑主线，可因书调整结构（分支对比 / 时间线 / 问题→解法 / 概念树）。这是重心，每块配一个读者熟悉的例子。
4. **对读者的核心价值**：今天为什么还要读它、能拿走什么、能纠什么误区。可附"局限"一句收尾。

> **节序硬律**：第一节必须是「书籍定位 / 这本书到底在讲什么」，**不允许**把第一节写成"一个错觉""一个误区"。核心误区可以压缩进第二、三节用对比框呈现，但内容定位永远先于误区拆解。
>
> **Hero 区硬律**：Hero = 书名 + 作者·出版年 + 全称 + 一句红色钩子大字，**到此为止**。禁止在 hero 加副标题、解释框、摘要或展开说明。红色钩子大字必须保留。

**书籍定位写法三条**：

1. 直白陈述"它从什么角度研究什么"，**不要**"它不是讲 X，而是回答一个更底层的问题：Y"这种手挥式 framing。
2. 领域与难题用**规范术语**（生存、合作、择偶、育儿这类），大白话可以，但要准确、不卖弄。
3. 核心定义一句话给清；末尾可加一句"一句话：……"收束，让读者一眼抓到书的核心。

## 大白话铁律

1. **先说人话再说术语**：出现专业词，后面必须跟一句解释。
2. **一句话一个意思**，长句拆开。
3. **具体名词 > 抽象占位符**：写"彩礼""选美"这种看得见的东西，不写"某种社会现象"。
4. **不造金句、不造比喻**：书里没有的话不要编；"像一台机器"这类比喻不用。
5. **不写"我们"/"让我们一起"**：直接讲书、讲读者，不拉家常。
6. **例子要完整因果**：讲清"因为…所以…"，不"一会儿蹦一句"。
7. **同一个例子只出现一次**，不要在正文、对比框、例子框里重复举例。

## 交付前硬闸门（不扫干净不许交付）

逐条过，任何一条不过就改：

| # | 检查项 | 判 FAIL 的标准 |
|---|---|---|
| 1 | 四块都在 | 缺任何一块 |
| 2 | 第一节是书籍定位 | 第一节写成了"一个误区/错觉" |
| 3 | Hero 干净 | hero 里混进了副标题、摘要、展开说明 |
| 4 | 大白话 | 出现"其本质是""综上所述""值得注意的是"这类书面腔 |
| 5 | 无 AI 腔 | 出现"让我们一起""不难看出""在当今社会" |
| 6 | 不编造 | 书里没有的观点、数据、金句 |
| 7 | 无位置指称 | 出现"在第 X 章""在序言里""卷一" |
| 8 | 例子完整 | 有例子但没有因果链，或同一个例子重复出现 |
| 9 | 能打开 | 双击 HTML 能正常渲染，无报错 |
| 10 | 字数克制 | 全文长到需要滚很久才看完（该删就删） |
| 11 | 自包含 | HTML 里有任何外部请求（CDN 字体、远程图片、外链样式），拔网线就变形 |

## 视觉规范（白板手绘暖红 · 默认）

- 底色暖白、主色暖红，手绘感（细描边 + 轻投影），**不要**科技感/暗色系。
- **样式不许自造 class**：只能用 `assets/template.html` 里已有的 class。要新样式先去模板里找，找不到就用最接近的，不自己发明。
- 响应式：窄屏能正常看，不横向溢出。

## 交付

产物：把做好的 HTML 交给用户即可，文件名建议 `<书名>-知识卡片.html`。

回报用户两件事：① 文件在哪；② 双击就能打开，不需要装任何东西。
