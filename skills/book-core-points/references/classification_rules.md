# 15 大类分类规则（shelfCat → 15-cat + 关键词召回）

> 本文件是 `book-knowledge-graph/scripts/pull_weread.py` 与 `book-knowledge-workflow`（总控）
> 共用的分类真值。改动请同步进 pull_weread.py 的 `shelf_map` 与 `KEY_REMAP` 字典。

## 一、硬剔除（纯职业/技术/应试/漫画）

| shelfCat | 剔除理由 |
|---|---|
| 漫画-经典改编/科普漫画/治愈漫画 | 漫画作品，不是知识读本 |
| 计算机-编程设计/数据库/软件学习/图像视频/理论知识 | 纯技术手册 |
| 教育学习-考试/外语/教材 | 应试教材 |
| 生活百科-游戏/美食/体育/情感 | 生活百科 |
| 艺术-设计/绘画 | 纯艺术技法（设计心理学等经典思维书保留） |
| 书名匹配：`^半小时漫画` / `^(高考|中考|考研|托福|雅思|...)` / `^精通\s*(React|Vue|Java|Python|...)` / `^深入\s*(分布式|JVM|算法|架构)` | 应试/纯技术 |

教育-育儿整体剔除（除非作为家长认知成长，但默认剔除）。

## 三、关键词召回规则（v3 实战沉淀）

第一遍 shelfCat 映射会把"易错分"的书塞进泛类（如心理学→心理成长、思维→思维认知），
第二遍用书名关键词把这些书从泛类里**拽回正确分类**：

### 人性洞察（关键词命中任一）
影响力、乌合之众、狂热分子、怪诞行为学、冲动、说服、纵、人心、从众、人性的弱点

### 决策避坑
黑天鹅、反脆弱、灰犀牛、塔勒布、稀缺、助推、噪声、快思慢想、卡尼曼、损失厌恶、幸存者、避坑、陷阱、风险与、失控、盲点、沉没成本、心智陷阱、认知偏误

### 能力提升
会读、高效读、谈判、口才、演讲、辩论、说服力、写作、刻意练习、记忆术、自学、番茄工作法、GTD、搞定、时间管理、做事的、清单、任务管理、效率、专注力、执行力、深度工作、即兴、复盘、如何学习

### 习惯养成
原子习惯、掌控习惯、习惯的力量、福格、微习惯、坚持、睡眠、自律、日更、早起

### 财富认知
富爸爸、穷爸爸、纳瓦尔、穷查理、巴菲特、芒格、投资、财务自由、理财、指数基金、价值投资、买房、房产、股票、基金、比特币、区块链、经济学、货币、金融

### 成事方法
OKR、项目管理、管理、领导力、高效能、工作、职场、执行、经理、领导、团队、组织行为、绩效、授权、精要主义、要事第一、关键对话

### 人际关系与沟通（补充）
人际、情商、非暴力沟通、公开讲话、即兴演讲

> 关键词命中后**直接覆盖**第一轮分类。例如《稀缺》shelfCat=心理-* 第一轮归"心理成长"，
> 第二轮命中"稀缺"→归"决策避坑"。
