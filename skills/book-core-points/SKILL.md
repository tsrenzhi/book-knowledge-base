# 书籍核心要点提炼（book-core-points）

## 一、目的（必须先想清楚）

你做的事**只有一个目的**：为「书籍知识图谱」知识图谱提炼每本书的**可迁移短关键词**，让这些词成为图谱里能挂的节点，靠**共享关键词**把不同书连起来（主题型阅读）。

- ✅ 输出 = 每本书 2-4 个**短关键词**（一般 ≤8 字，原书固定并列概念如「7个习惯/6大原理」可凑满）
- ❌ 不是写书摘、不是写书评、不是列章节、不是描述内容、不是写一大段话

**一句话判据**：这个词抽出来，**换一本同主题书也对不上、但放在本书里是作者真教的可学内容** = 合格关键词。

## 二、写每本书核心要点的正向 SOP（拿到一本书就走这 6 步）

> **这一节是正向作流程，不依赖读第四节反例表。** 任何一次提炼都先走这 6 步，再回头对照第四节 RC 表查漏。背住这节，下次就不会忘怎么写。

**第 0 步 · 先查真值（该跳过的别瞎写）**
- 该书已有知识卡片（`你的书籍库/《书名》/*-知识卡片.html`）→ 直接取 `<b>` 词，不另起炉灶。
- 该书在【经济与商业】分类 → **锁定区，用户已手校真值，绝对不写不覆盖**。
- 该书在 GOLD 豁免表（`check_points.py` 内）→ 跳过。

**第 1 步 · 判定书的类型（决定首词和后 3 位怎么写）**
- **方法论型**（教你具体怎么做：沟通/谈判/演讲/写作结构/提问/习惯/时间管理/销售）→ 首词=核心主题词；后 3 位=书里**具体方法步骤**（直接列动作名，`观察`/`感受`/`需要`/`请求` 这种，不写"四步法""五原则"绕弯）。
- **思维/心理/哲学/历史型**（让你理解某个机制）→ 首词=核心主题大类；后 3 位=书里**核心机制或反常识判断**，不套方法论模型（亲密关系写`依恋类型`/`冲突修复`，不套"观察-感受-需要-请求"）。
- **故事型**（人物自传/历史叙事）→ 首词=核心主题（领导力/创业/企业管理）；后 3 位=人物观察/历史教训/管理哲学，不写方法论。

**第 2 步 · 定首词（核心主题词，必须占第 1 位，永远不撤）**
- 首词 = 这本书"真正在讲"的核心主题，让人一眼归到主题型阅读簇。
- ✅ 合法首词 = 双字主题大类：`团队管理`/`习惯养成`/`认知偏差`/`人际沟通`/`谈判技巧`/`营销战略`/`竞争战略`/`经济学`/`存在主义`/`领导力`/`个人成长`…
- ❌ 单字太宽必杀：`管理`/`认知`/`习惯`/`成长`/`思维`/`战略` —— 必须细分（"战略"→`竞争战略`/`军事战略`/`营销战略`；"认知"→`认知偏差`）。
- ❌ 不准为"差异化不撞词"把核心主题从首位撤掉（关键冲突把"沟通技巧"撤成 CPR对话法 = 反向错误，必改）。

**第 3 步 · 填后 3 位（本书独有方法/机制/视角）**
- 必须是书里**真有**的、可迁移的、读者一眼懂的具体词。
- 方法论型列具体动作；思维型列核心机制；故事型列人物观察。
- ❌ 不准生造书里没出现的委婉后缀鬼词：`CPR对话法`/`安全感循环`/`异化沟通`/`动机核验`/`情境力量`/`技能挑战匹配` —— 直接列机制名。

**第 4 步 · 数量纪律**
- **2-4 个最佳，最多 5 个**（图谱书太多，信息呈现不下）。
- 原书并列核心概念（7习惯/6原理/纳瓦尔4杠杆）可保留原数量。
- 超过 4 → 自检"只学这 N 点能学到吗"；罗列数 N>3 → 重组为核心方法名（"12种谈判策略"→`价值最大化`/`看清真实需求`/`创造交易`）。

**第 5 步 · 禁词终检（每条关键词自问 4 句）**
1. 读者**5 秒内讲得出"这条书讲了啥"**吗？讲不出=黑话（术语缩写 `BATNA`/`GTD`/`MECE`/`ZOPA` → 大白话；`复杂经济学`/`XX本质`/`XX精神` → 具体词）。
2. 是单字太宽/大词裸用吗？（`战略`/`营销`/`管理`/`沟通` 必须细分到业务域/类型）
3. 是为差异化编的词吗？（书里没出现的=鬼词，删）
4. 同系列书超过 3 本？只留最经典 1 本（搞定 I/II/III/全集 → 只留《搞定：无压工作的艺术》1 本）。

**第 6 步 · 主题型阅读视角收口**
- 首词是连接锚点：同首词的书自然聚成主题簇（营销战略 / 价值投资 / 存在主义 / 行为经济学）。
- 交付前跑 `check_points.py --md`，非锁定区应 0 违规；品牌/人名残留必须为 0。

## 三、关键词顶格铁律（ · 最高优先级，压倒一切细节）

> 这一节是关键词提炼的硬规则。**任何一次提炼都必须先过这一节，再看过节四/五的 RC 细表。**

### 3.1 结构公式（每本书 2-4 词的标准骨架）

```
第一词 = 主题大类（这本书归到哪个"主题型阅读簇"）
第二/三词 = 本书独特视角 / 可学的方法论（抽象关键词）
```

- **第一词必须是领域/学科级主题词**，让人一眼知道"这本书跟哪个方向强相关"——这是主题型阅读的连接锚点。
 - 经济商业常用：经济学、竞争战略、营销战略、广告学、商业模式、消费主义、创业、财政、全球化、金融、货币政策、贸易、企业管理…
 - 财富认知常用：投资、价值投资、行为经济学、消费心理、自我关怀、原生家庭、复利、被动收入、财富自由、认知偏差…
 - 成事方法常用：领导力、团队管理、企业管理、战略、OKR、执行力、销售方法、服务、学习法、时间管理、决策、教练…
 - 思维认知常用：逻辑思维、批判性思维、决策、认知偏差、专注、创造力、心智模型、类比、系统思维、元认知…
 - 文学经典常用：孤独、命运、自由、荒诞、人性、爱情、革命、阶级、苦难、成长、权力、女性觉醒、殖民、战争、存在主义、乡土、救赎…
 - 哲学思辨常用：西方哲学、中国哲学、存在主义、理性、正义、自由、心学、伦理学…
 - 底层规律常用：社会结构、国家权力、人类进化、认知科学、复杂系统、技术本质、历史规律、阶级、制度、睡眠、人工智能、性别、传播…
 - 历史常用：明史、制度史、社会史、二战、大屠杀、日本史、中国通史、冷战…（时代/地域 + 类型）
 - 名人传记/自传：**主题优先，不写人名**——写 企业管理、领导力、创新、修身、创业、人物思想、科学精神。
- **第二/三词是本书独有、可迁移的抽象关键词**（如：长期主义、能力圈、反脆弱、护城河、五力模型、差异化定位、价值投资、双系统思维、知行合一、阶级分析、羊群效应）。

> ⚠️ **单字太宽反向错误**：第一词写 `管理`/`认知`/`习惯`/`成长`/`思维` 单字太宽——"管理"可以是管理学/企业管理/团队管理/项目管理，"认知"可以是认知偏差/思维认知，谁知道你指哪个？**必须落到双字主题词**（团队管理/企业管理/认知偏差/习惯养成/个人成长）。反过来，`团队管理`/`习惯养成`/`认知偏差`/`个人成长`/`领导力`/`执行力` 这些双字主题词是**合法第一词，绝不要当泛词删掉**——删掉它们就是反向错误（曾把《责任病毒》第一词从"团队管理"改回"管理"、把《当下的力量》改成"灵性/临在"两次翻车）。

### 3.3 为什么第一词要挂主题（主题型阅读视角）

### 3.6 一句话铁律清单（10 条正向 must，背住就不会忘）

> 用户 ~ 08-28 连打 10 轮后沉淀。这 10 条是**正向**作纪律（不是反例），写任何书前在脑子里过一遍。

1. **第一词永远是这本书的核心主题，后 3 位才是这本书独有的具体方法/机制**——二者缺一不可（核心主题词如 `沟通技巧`/`谈判技巧`/`人际关系`/`营销战略`/`经济学`）。
2. **核心主题词永远占第 1 位，不准为差异化撤掉**——撤掉=反向错误（关键冲突把"沟通技巧"撤成 CPR对话法必改）。
3. **单字太宽必杀**（`管理`/`认知`/`习惯`/`思维`/`战略`/`成长`），必须落双字主题词或业务域细分词（`战略`→`竞争战略`/`军事战略`/`营销战略`）。
4. **数量 2-4 个最佳、最多 5**；罗列 N>3 必重组为核心方法名（颗粒度=单个具体做法名级别，如 `18分钟法则`/`价值最大化`，不写"12种策略"）。
5. **术语缩写禁用**（`BATNA`/`GTD`/`MECE`/`ZOPA`/`CPR`/`LTV`/`NSM`/`KOL`/`UGC`/`PGC`）→ 译成大白话；读者 5 秒讲不出"这条书讲了啥"=黑话。
6. **方法论型书列具体动作**（`观察`/`感受`/`需要`/`请求`），不写"四步法""五原则"绕弯；**思维型书写机制**，不套方法论模型。
7. **不准生造书里没出现的鬼词**（`CPR对话法`/`安全感循环`/`异化沟通`/`动机核验`/`情境力量`/`技能挑战匹配`）——直接列机制名。
8. **用户真值优先**（覆盖=造谣）；【经济与商业】100 本是锁定区，绝不动，改必须用户显式授权。
9. **同系列超过 3 本只留经典 1 本**（搞定 4 本→1 本）；`复杂经济学`/`XX本质`/`XX精神` 这类装高深虚词禁用（要么`经济学`要么`经济思想史`）。
10. **品牌/人名/书名比喻/空话/外部标签**（`奥地利学派`/`FIRE运动`/`PayPal`/`推石上山`）一律禁。

## 五、判别标准（合格 vs 必杀）

**合格关键词 = 有信息量 + 可迁移**，两类都行：
- 可践行的品质/方法：`付出` `课题分离` `积极主动` `先支付自己` `算真实时薪`
- 可理解世界的机制/反常识判断：`优势陷阱` `贫穷陷阱` `农业是最大骗局` `知识是分散的` `钱不是财富` `看不见的手`

**必杀**（任一命中立即改/删）：
1. 孤立灵性/心理学术语：`临在` `臣服` `自卑感` `生活风格` `社会兴趣` `自我状态` `意义疗法` `观察者` `痛苦之身`
2. 泛动词（动词+抽象宾语）：`觉察情绪` `跳出思维` `不抗拒当下` `直面孤独` `接纳现实`
3. 描述型（X是Y现象/状态/职业）：`CEO是孤独职业` `巨头越优秀越完蛋`
4. 抽象类目（X本质/X意义/X精神/X要义）：`直击本质` `关系本质` `企业家精神`
5. 同义重复：同一概念换说法写2遍
6. 外部标签（流派/运动/主义/结果词）：`FIRE运动` `奥地利学派` `财务独立` `反消费主义`
7. 万金油（套另一本同主题书也对得上）：`未来30年三大力量` `AI重塑一切` `去中心化协作`
8. 书名同名+具体内容堆砌：`世界观`写`相对论与量子论`
9. 长句（>10字且带"的/了/被/靠/在"的叙述）：`科学事实会随时代被推翻`
10. **品牌/企业/人物名**：`PayPal` `麦当劳` `苹果` `英特尔` `乔布斯` `巴菲特` `芒格` `库克`
11. **书名字面/比喻当唯一概念**：`推石上山` `蚊子大象隐喻` `MEA情绪公式` `销售信`
12. **【经济与商业】分类下任何修改都是违规**：除非用户显式贴新真值授权，否则 agent / 自检脚本 / --fix 都不许动这 100 本；违者等同清单清洁彻底失败。

## 十一、最终化管线（生成图谱核心真值文件）

> 本 skill 不仅提词，也负责把"分类清单 + 核心要点"拼成**图谱最终核心真值**。这条管线在 跑通并固化，下次直接复用，别临场重写。

**输入**：
- 分类清单 `书单数据源.md`（由 `book-category-classify` 产出/迭代，含 15 类书名）
- 核心要点 `书籍核心要点清单.md`（每本带 `关键词：` / `作者：` / `类别：`）

**步骤（脚本化）**：

1. **先 `Read` 当前磁盘 `书单数据源.md` 真实文件**——用户可能已在该文件上删书/调类，改完即最新真值。**绝不凭记忆重写、绝不补回任何用户删的书**（详见 `book-category-classify` 第七节铁律）。
2. **从核心清单抽 (规范化标题 → 关键词/作者)**：逐行解析，**跳过 `## 【类别】` 类标题**（否则会把类标题误当书名导致漏抽——这是 RC 实战 bug）；作者字段用正则清掉 `（书架补充·未读·shelf=...）` 这类脏标注，保留 `[美]`/`[英]` 国别。
3. **合并进分类清单 + 去重**：按归一化标题（去括号/冒号后副标题/空格）匹配；去重是**强制前置步骤**——同书两条（如《贫穷的本质：我们为什么摆脱不了贫穷》vs《贫穷的本质》）、跨类重本（如《从 0 到 1》经济与商业 vs《从0到1：开启商业与未来的秘密》成事方法）必须合并为 1 条（关键词取并集、作者留更全者、类别按 classify 铁律拍板）；匹配不上先模糊（clean 后包含关系）再 grep 确认是真没有还是解析漏了。** 实战：漏去重会被用户一眼识破**。
4. **类内相关性排序 = "奠基经典优先 + 相关性相邻"**（不跨类）：
 - **每类最前放 `◆ 奠基经典（重要性优先）` 块**：curated 该领域公认奠基/标杆书（如经济与商业前 4 = 国富论/资本论/就业利息和货币通论/通往奴役之路），**绝不让新书（如《繁荣与停滞》）顶到最前**。
 - 其余按"子主题簇"相邻：经济与商业分 5 簇（经济学理论经典 / 金融与投资 / 创业与创新 / 营销广告传播 / 管理与领导力，按重要性排簇序）；其余 14 类用"共享关键词"贪心聚类，簇内按作者/书名。
 5. **输出**：
 - 人读 `书单数据源.md`：每本书 `数字. 《书名》｜作者：X｜关键词：a、b、c`（含速查表 + 避用清单 + 15 类逐本）。
6. **校验**：跑 `book-category-classify/references/verify_count.py` → 15 类 / 总=各类之和 / 0 缺作者 / 0 空概念；JSON 条数 = 文件本数。

**产物定位**：关键词写进 `书单数据源.md`（分类 + 关键词）——**这就是图谱的输入**。改完跑 `book-knowledge-graph`（`scripts/rebuild_clean.py`）重建 `书籍知识图谱模板.html`。

**与其他 skill 关系**：
- 分类判定 → `book-category-classify`（本 skill 只负责"提词 + 最终化拼接"，分类归属以 classify skill 为唯一真值）。
- 建图谱 → `book-knowledge-graph`（消费 `书单数据源.md`）。
