**当下分类规则**：

- **思维认知** = 思考总类（思维 / 认知 / 逻辑 / 心智模型 / 结构化 / 水平思考 / CBT 等）。

- **人性洞察** = 欲望 / 阴暗面 / 进化本能 / 底层生物心理（乌合之众 / 影响力类）。
- **文学经典** = 故事性统一大类，不细分。
- **经济与商业** vs **财富认知**：经济与商业管市场 / 企业 / 理论；财富认知管个人搞钱观 / 理财。
- **心理成长** vs **人性洞察** vs **决策避坑**：心理成长 = 自我疗愈；人性洞察 = 他人阴暗面 / 群体本能；决策避坑 = 认知偏差。
