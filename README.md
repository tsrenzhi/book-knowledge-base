# 书籍知识卡片

把一本书，做成一张能直接看懂的网页卡片。

打开就好懂，双击就能看。产物是一个单文件 HTML，不依赖网络、不用装环境、不带任何外部请求——你可以把它丢进笔记、放进博客、或者直接发给别人。

## 先看效果

`examples/国富论-知识卡片.html` 是成品样例，下载后双击打开即可。

它会告诉你最终交付的东西长什么样：一本书的主干、旧观念的破绽、作者怎么破局、你能拿走什么——一屏之内讲完，不是读书笔记的搬运，也不是长篇摘要。

## 怎么用

**第一步**：把 `skills/book-knowledge-card-lite/` 整个文件夹，放进你的 AI 助手的技能目录。

不同工具的位置不一样，常见的是用户目录下的 `skills/` 文件夹。放进去之后重启或刷新一下技能列表。

> **关于字体**：卡片用**霞鹜文楷（LXGW WenKai）**呈现手绘感。字体已经随包带好了，就在 `skills/book-knowledge-card-lite/assets/fonts/` 里（99 个分片，完全离线可用）——**下载下来直接打开样例卡就是正确字体，不用联网、不用额外安装**。
>
> 卡片同时写了 `src:local('LXGW WenKai')`：系统里本来就装了这字体的话优先用系统那份，没装就用包内这份。两条腿走路，不会缺字。

**第二步**：对着你的 AI 说——

> 把《书名》做成知识卡片

它会自动读资料、拆结构、写大白话、套模板、跑完交付前自检，然后给你一个 HTML 文件。

**输入可以是**任意形式：书名、读书笔记、划线摘录、口述的看法，都行。

## 目录里有什么

| 路径 | 是什么 |
|---|---|
| `skills/book-knowledge-card-lite/SKILL.md` | 技能主体，AI 照它执行 |
| `skills/book-knowledge-card-lite/assets/template.html` | 版面骨架与样式白名单，做卡片就在这个文件上改 |
| `skills/book-knowledge-card-lite/assets/sample-国富论.html` | 标杆成品，看它怎么分节 |
| `skills/book-knowledge-card-lite/references/` | 输入怎么读、内容怎么分节 |
| `skills/book-knowledge-card-lite/assets/fonts/` | 字体（霞鹜文楷，离线可用，卡片自动引用） |
| `examples/` | 成品样例 |

## 这套东西的几条硬规矩

这些不是风格偏好，是判 FAIL 的线：

- **四块必须有**：书籍定位、现实矛盾、作者核心内容、对你的价值。缺一块就不交付。
- **第一节永远是书籍定位**，不许拿"一个误区"开头。
- **写大白话**：专业词后面必须跟一句解释，一次讲一个意思，写"彩礼"不写"某种社会现象"。
- **不许编**：书里没有的观点、数据、金句一个都不能加。
- **不许自造样式**：只能用模板里已有的 class，找不到最接近的就用它，不自己发明。
- **必须自包含**：成品里不许有任何外部请求，拔了网线也得原样显示。

想改输出风格的话，改 `references/content-spec.md` 和 `assets/template.html` 就够了，逻辑不用动。
