# 书籍知识库

一个帮你把读过的书沉淀下来的电子工具：把每本书做成一张可视化知识卡片，再把所有的书连成一张可交互的关系网。读得越多，这张网越能反映你自己的阅读脉络。

## 它解决什么

- **读完就忘**：卡片把每本书的重点留下来，随时能回看，不用重新翻完整本书。
- **忘了自己之前的想法**：你当时记下的灵感、批注都留在卡片里，重读时能看见，不会又从零开始。
- **书与书是散的**：关系网让你看出哪本书在补充哪本、哪本在讲相近的话题，顺着关联接着读，知识连成体系，不会东一块西一块。

## 仓库里有什么

- `index.html`：书籍知识图谱（可交互网页），双击就能在浏览器打开。
- `assets/`：图谱依赖的 d3 库。
- `cards/`：已经做好的知识卡片（示例）。
- `skills/`：5 个 WorkBuddy 技能，用来自己搭建知识库——做卡片、抽重点、分类、画关系网、总控编排。
- `操作手册.md`：小白向使用说明，照着发一句话给 WorkBuddy 就能用。

## 怎么用

1. 装上技能：让 WorkBuddy 去 GitHub 搜「书籍知识库」开源技能即可；或者把本仓库 `skills/` 下的 5 个文件夹放进你电脑的 `~/.workbuddy/skills/` 目录。
2. 打开 `操作手册.md`，按里面的场景提示词开始加书、做卡片、看图谱。
3. 想看现成的图谱：直接用浏览器打开 `index.html`，或访问本仓库的 GitHub Pages（若已开启）。
