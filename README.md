# 书籍知识库

你读过的书，把里面的重点、你当时的感想和批注、以及书与书之间的关联，都放进一个网页里。之后你想看，打开就能看，不用把书搬在身边。

这个仓库，就是做这件事的开源模板工具。它做三件事：把一本书做成一张知识卡片，把所有的书连成一张关系网，让你能顺着关联接着读。

如果你以前用过 OneNote、Notion、印象笔记之类的工具——它是同一类东西，只是专门为读书这个场景做了更深的处理。

---

## 它最常解决的三个问题

**读完就忘。** 读完《国富论》没多久，再聊起感觉「好像读过」，但分工、看不见的手具体讲什么说不清。这套工具把一本书的重点整理成一张可视化卡片，你不用为了找一个重点重新翻完整本书。仓库里 `cards/guo-fu-lun/国富论-知识卡片.html` 就是一张现成模板，照它的样子来就行。

**书与书是散的。** 你可能读过好几本其实在讲同一件事的书，但你没把它们连起来。每本都孤立着，读得越多越散。这套工具把所有书连成关系网——哪本和哪本在讲相近的话题、哪本在补充哪本，一眼看出来。

**以前的感想丢了。** 同一本书读了好几遍，但上一遍写在边上的感想、当时冒出来的灵感，早就忘干净了。这套工具把你当时的灵感、批注都留在卡片里，重读时能看见，不会又从零开始。

## 这套工具怎么用（一条主线 + 两种产出）

先说**输入**，再说能**产出什么**，最后说卡片和图谱的关系。

### 你的输入可以是这几种

- **你自己的思考**：读一本书时记下的感想、批注、划的重点——直接发给 AI 就行。
- **直连微信读书**：如果你的书在微信读书里，让 AI 直接连上去，把这本书的核心内容抓下来当输入。仓库里的 `skills/book-knowledge-graph/scripts/pull_weread.py` 就是干这个的，也可以直接让 AI 用微信读书能力去抓。
- **只给个书名**：让 AI 自己去查这本书讲了什么，再帮你整理成卡片或要点。

### 然后有两种产出，由浅到深

**产出一（最简单）：做一张知识卡片**
一本书 → 一张能打开看的可视化卡片。把上面任意一种输入丢给 AI，说「帮我把《国富论》做成一张知识卡片」，它就出一张。仓库里 `cards/guo-fu-lun/国富论-知识卡片.html` 就是一张现成模板，你照它的样子来。

**产出二（建关系网）：建知识图谱**
想把所有书连成一张能点能搜的网，光有卡片不够，还差两步：
1. **提要点**：从书里提炼 2-4 个可迁移的「概念词」（比如《国富论》的"分工、看不见的手、国富"）；
2. **分类**：把这本书归到 15 大类里的某一类。
这两步做完，AI 才能把"概念词相同、类别相近"的书自动连上线，生成 `书籍知识图谱模板.html`。

### 卡片 和 图谱 是什么关系

- **卡片是"单片"**：一本书一张，适合精读、回看、讲给别人听。
- **图谱是"把所有卡片串起来"**：它吃的是每本书的**概念词 + 分类**，靠共享概念词把不同书连成网。
- 一句话：**先有卡片（或你的输入），再提炼概念词和分类，最后才连成图谱**。卡片是源头，图谱是结果。

## 这套工具包含哪些能力（5 个技能 / Skills）

> 下面 5 个「技能」是这套工具的核心。它们本质上是**写给人读的说明文档**（每个技能一个 `SKILL.md` 文件），任何能读文件的 AI 助手都能照着做。你不用懂它们怎么写，只要知道各自解决什么问题。

| 技能（文件夹名） | 它解决什么问题 | 它具体干什么 |
|---|---|---|
| `book-knowledge-card`（做知识卡片） | 书读完就忘、回看难、讲不清 | 把一本书蒸馏成一张**大白话、能直接打开看的可视化网页卡片** |
| `book-core-points`（提核心要点） | 书与书连不起来、跨书关联缺失 | 为每本书提炼 2-4 个**可迁移的短概念词**，靠共享概念词把不同书串起来 |
| `book-category-classify`（分类匹配） | 一本书该归哪类、分类错归、迭代时丢书 | 把任意书单准确归入 **15 大类**，边界符合大众普遍认知 |
| `book-knowledge-graph`（建知识图谱） | 看不见自己的阅读脉络、书是散的 | 把所有书 + 概念词连成一张**能点、能搜、能缩放的关系网网页** |
| `book-knowledge-workflow`（总控流程） | 不知道从哪下手、步骤零散 | 把上面 4 个技能串成一条「输入 → 建卡 / 提要点+分类 → 建图谱」的标准流程 |

> `skills/` 下的文件夹名（如 `book-knowledge-card`）是 AI 工具识别技能用的**固定 ID，不要改**；里面的说明内容全是中文，不影响阅读和使用。

## 怎么开始用（不绑定任何 AI 工具）

这套工具不绑定某一个 AI 产品。你用哪个顺手就用哪个——WorkBuddy、Claude、ChatGPT、Cursor、Cline、通义、豆包……都能用。

### 方式一：用 WorkBuddy（最省事，适合不想碰配置的人）

打开 WorkBuddy，发一句话给它：

> 「去 GitHub 上找『book-knowledge-base』这个开源项目，帮我装上」

装好后，直接看仓库里的 `操作手册.md`，把里面的话复制发给它就行。

### 方式二：用其他 AI 工具（Claude / ChatGPT / Cursor 等都能用）

这些技能文件就是普通的说明文档，任何 AI 都能读、能照做：

1. 把本仓库下载（或 clone）到本地；
2. 打开 `skills/` 文件夹，挑你需要的技能（比如想做一张卡片，就看 `skills/book-knowledge-card/SKILL.md`）；
3. 把那个 `SKILL.md` 的**全部内容**贴给你正在用的 AI，或者把它放进该工具的「自定义指令 / 项目上下文 / Skills」目录；
4. 然后像跟人说话一样下指令，比如「帮我把《国富论》做成一张知识卡片」，AI 会照着说明一步步做。

> 不需要 Python、不需要装插件、不需要联网。只有「重生成图谱」这类可选的高级操作才需要本地有 Python，但那不是必做的——普通使用直接看 `操作手册.md` 发对话即可。

## 如果你想先看看长什么样

**看一张完整的知识卡片长什么样**，用浏览器直接打开 `cards/guo-fu-lun/国富论-知识卡片.html`。不需要联网，里面的图都内嵌在文件里了。

**看一张完整的关系网长什么样**，用浏览器直接打开根目录的 `书籍知识图谱模板.html`。这是演示模板，里面装的是一份演示用的阅读清单（不是你的，只是给你看结构怎么搭）。你打开看两分钟，了解了样貌，再开始你自己的。

这两件事都不需要 AI 工具、不需要装东西、不需要联网。下载下来直接浏览器打开就是。

## 常见问题（关于怎么改、怎么定制）

**怎么换成我自己的书单？**
只改 `data/分类总览.md` 这一个文件——它本身就是模板，把里面《国富论》《人类简史》那些行，照着格式换成你的书就行。改完让 AI 基于最新的 `分类总览.md` 重生成 `书籍知识图谱模板.html`。

**卡片模板能改吗？比如加金句、加思维导图？**
能。`cards/` 里每本都是一个模板：你改对应的 `.md`（加一段金句墙、加一张思维导图、换配色都行），再让 AI 照着重新生成 `.html` 即可。卡片的长相完全由那份 md 决定。

**微信读书里的书怎么直接用？**
让 AI 连微信读书，把这本书的核心内容抓下来当输入（见上面「你的输入可以是这几种」一节），再走"做卡片"或"建图谱"。

**图谱里某本书孤零零没连上别的书？**
多半是 `分类总览.md` 里那本书的"概念词"留空了，或分类写错。回去把那一行补上概念词、改正分类就行。想看完整的维护方法，读 `如何维护书单.md`。

**技能文件夹名是英文，能改吗？**
不要改。`skills/` 下的文件夹名是 AI 工具识别技能的固定 ID，改了可能导致装不上或加载不到。里面的说明内容全是中文，不影响阅读。
