# 书籍知识库

你读过的书，把里面的重点、你当时的感想和批注、以及书与书之间的关联，都放进一个网页里。之后你想看，打开就能看，不用把书搬在身边。

这个仓库，就是做这件事的工具。它做三件事：把一本书做成一张知识卡片，把所有的书连成一张关系网，让你能顺着关联接着读。

如果你以前用过 OneNote、Notion、印象笔记之类的工具——它是同一类东西，只是专门为读书这个场景做了更深的处理。

---

## 它最常解决的三个问题

**读完就忘。** 读完《思考，快与慢》没多久，再聊起感觉「好像读过」，但具体讲什么说不清。这套工具把一本书的重点整理成一张可视化卡片，你不用为了找一个重点重新翻完整本书。

**书与书是散的。** 你可能读过好几本其实在讲同一件事的书，但你没把它们连起来。每本都孤立着，读得越多越散。这套工具把所有书连成关系网——哪本和哪本在讲相近的话题、哪本在补充哪本，一眼看出来。

**以前的感想丢了。** 同一本书读了好几遍，但上一遍写在边上的感想、当时冒出来的灵感，早就忘干净了。这套工具把你当时的灵感、批注都留在卡片里，重读时能看见，不会又从零开始。

---

## 它最终给你什么

一个能点、能搜、能缩放的网页。你加的书越多，这个库就越能反映你自己的阅读脉络，也就是一个属于你自己的「第二大脑」。

整个东西存在你电脑上，不联网也能打开。只有你主动说「帮我发布到网上」时，才会往外传到 GitHub Pages 之类的服务上。

---

## 怎么开始用

你不需要懂任何技术，不用碰代码，不用装任何软件。你只要会用 WorkBuddy 跟它聊天就行。

**第一步：装到 WorkBuddy 上。** 打开 WorkBuddy，发一句话给它：

> 「去 GitHub 上找『book-knowledge-base』这个开源项目，帮我装上」

WorkBuddy 会自己去 GitHub 上把这套工具下载下来，装到你电脑上。装好自动能用，你不用找路径、不用管文件夹放在哪。

**第二步：去看操作手册。** 装好之后，不要直接动手，去看仓库里的 `操作手册.md` 文件。那份文档按你可能遇到的所有场景列了对话示例——加一本书、找书、改分类、删书、发到网上给朋友看等等。你只要复制手册里的话发给 WorkBuddy，它就会自己干。

**第三步：随便玩。** 复制下面任一句发给 WorkBuddy，从你自己最有感觉的事开始：

- 「帮我做一张《XXX》的知识卡片」
- 「把我的微信读书书架同步进来，每本书都帮我做卡片」
- 「打开我的书籍知识图谱」
- 「《XXX》应该归到『思维认知』这一类，帮我改一下」
- 「我最近在纠结要不要跳槽，帮我看看读过的书里哪些观点能帮我想清楚」

**看一张完整的关系网长什么样**，用浏览器直接打开根目录的 `index.html`。这是演示版本，里面装的是一份演示用的阅读清单（不是你的，只是给你看结构怎么搭）。你打开看两分钟，了解了样貌，再开始你自己的。

这两件事都不需要 WorkBuddy、不需要装东西、不需要联网。下载下来直接浏览器打开就是。

## 常见问题

**我完全不懂技术，能用吗？**
能。从头到尾你就是跟 WorkBuddy 说话，不需要装软件、不需要写代码、不需要懂任何术语。

**我的书和数据安全吗？**
安全。所有内容都存在你自己的电脑上，默认不联网、不外传。只有你主动说「帮我发布到网上」时才会往外发。

**演示版的关系网，能直接用吗？**
能用，但不建议直接当你的——那是作者的阅读清单，不是你的。你应该发对话给 WorkBuddy，从你自己的书起步，让它重新生成一张属于你自己的网。

**我想看更细的对话模板**
去看 `操作手册.md`，里面按场景列了 10 条，把引号里的字复制发给 WorkBuddy 就行。
